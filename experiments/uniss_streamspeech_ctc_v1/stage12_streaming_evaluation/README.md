# Stage12: simultaneous S2ST research evaluation

Stage12 aggregates the first bilingual Stage11 audio outputs. It keeps
algorithmic source-clock latency (NCA) separate from computation-aware wall
latency (CA), counts accepted/rejected online WRITEs, records fallback use and
links every listening artifact.

This first report is intentionally a two-sample pipeline validation, not a
statistically meaningful dev score. Its purpose is to decide whether Stage13
may expose the system publicly and which warnings must be visible.
