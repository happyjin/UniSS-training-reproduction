## 5. 原因拆分：P8 的 ASR 损失来自哪里

P8 用的就是 N 的翻译模型，en2zh OBSI 的文本 BLEU 差距从 P7′ 的 −5 到 −7 缩小到 −1.3 到 −1.7。这证实 HSMM LoRA 损害了 en2zh 翻译（原因 3）。但 ASR 仍然低 0.5–3.3。按句拆分（n_over > 0 = 至少一次"停顿将至时强提交"）：

| 方向 / 组 | 有强提交：句数 / P8 vs N 文本 BLEU | 无强提交：句数 / P8 vs N 文本 BLEU |
|---|---|---|
| en2zh RealSI | 419 / −3.13 | 273 / −0.39 |
| en2zh OBSI | 735 / −2.66 | 1020 / **+2.24** |
| zh2en RealSI | 506 / −4.38 | 356 / **+0.78** |
| zh2en OBSI | 616 / −4.54 | 1418 / **+0.22** |

**结论：** 剩余的 ASR 损失几乎全部来自强提交，也就是为了不停顿而说出未经确认的词。没有强提交的句子与 N 持平或更好。强提交发生在 30%–60% 的句子上。这是这条线上停顿与质量之间真正的冲突所在。

**结论：**

3. 代价：语音延迟 D2 多 0.07–0.42 s（en2zh RealSI 最大），未过 D2 ≤ +0.05 的门槛。
