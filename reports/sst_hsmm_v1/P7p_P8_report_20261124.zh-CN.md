## 5. 原因拆分：P8 的 ASR 损失来自哪里

P8 用的就是 N 的翻译模型，en2zh OBSI 的文本 BLEU 差距从 P7′ 的 −5 到 −7 缩小到 −1.3 到 −1.7。这证实 HSMM LoRA 损害了 en2zh 翻译（原因 3）。但 ASR 仍然低 0.5–3.3。按句拆分（n_over > 0 = 至少一次"停顿将至时强提交"）：

| 方向 / 组 | 有强提交：句数 / P8 vs N 文本 BLEU | 无强提交：句数 / P8 vs N 文本 BLEU |
|---|---|---|
| en2zh RealSI | 419 / −3.13 | 273 / −0.39 |
| en2zh OBSI | 735 / −2.66 | 1020 / **+2.24** |
| zh2en RealSI | 506 / −4.38 | 356 / **+0.78** |
| zh2en OBSI | 616 / −4.54 | 1418 / **+0.22** |

**结论：** 剩余的 ASR 损失几乎全部来自强提交，也就是为了不停顿而说出未经确认的词。没有强提交的句子与 N 持平或更好。强提交发生在 30%–60% 的句子上。这是这条线上停顿与质量之间真正的冲突所在。

## 9. HSMM 训练为什么损害翻译（2026-11-24 11:40 CET，只用已有输出）

脚本 `experiments/sst_hsmm_v1/content_gap_analysis.py`，输出 `eval_outputs/sst_hsmm_v1/content_gap_analysis.json`。对比 P7′（HSMM Thinker 出内容）和 P8（N 的 Thinker 出内容，写出时机同属 HSMM）。"只在最后一读写出"的句子两者都听到了完整音频，时机不起作用，差异只来自模型。

| 方向 / 组 | 完整音频句数 | HSMM / N 模型 BLEU | chrF | 长度比（HSMM / N） | 保留英文词的句子（HSMM / N / 参考译文） |
|---|---|---|---|---|---|
| en2zh OBSI | 426 | 40.42 / 43.12（−2.7） | 32.4 / 37.1 | 1.02 / 0.98 | 2.5% / 10% / 31% |
| en2zh RealSI | 127 | 24.40 / 25.19（−0.8） | 22.3 / 21.7 | 1.07 / 1.00 | 2.5% / 5% / 4% |
| zh2en OBSI | 723 | 21.57 / 22.03（−0.5） | 48.9 / 47.7 | 1.07 / 1.01 | — |
| zh2en RealSI | 108 | 21.81 / 21.06（+0.8） | 48.8 / 48.8 | 1.03 / 1.02 | — |

1. **主因是训练目标的风格，而不是写出策略：**
   - HSMM 的 LoRA 是在 UniST 参考译文上做 teacher forcing 训练的（P1a 的 lattice 边际似然，P5′ 又训了一轮）。
   - UniST en2zh 参考译文只有 1.1% 保留英文词；原文含专名时也只有 2% 保留。
   - OBSI 参考译文有 31% 保留英文术语和专名。
   - 训练后的模型把英文专名几乎全部音译或意译成中文（保留率 10% → 2.5%）。例如参考"Hakata 湾的 Higashi-ku 地区"，N 输出"Akato 湾的 Hakasasi-kou"，HSMM 输出"阿卡托湾的哈卡萨西库尔"。
   - 这在 BLEU 和 chrF 上都按错算，所以 en2zh OBSI 损失最大（−2.7，chrF −4.6）；RealSI 参考本来就少保留英文，损失小（−0.8）。
   - 去掉标点后差距不变，说明不是标点问题。
2. **译文变长约 5%（两个方向都有），** 也与 UniST 参考译文更直白、更完整的风格一致。
3. **zh2en 在完整音频下几乎无损（−0.5 / +0.8）。** 但在部分音频下写出的句子上，HSMM 模型比 N 模型低 1.1（OBSI 24.54 vs 25.69）。这与训练时 λ_L 倾斜鼓励"在更短的音频前缀上预测参考词"一致：模型学到了在证据不足时提前猜测。
4. **与噪声无关：** clean 和 noisy 单元的损失相近，不是鲁棒性遗忘。

**改进思路：**
- **A（推荐）：冻结翻译，只训写出头。** 翻译完全用 wave17（与 N 相同），在冻结 Thinker 的隐状态上训练一个小的写出头，用同一套 HSMM 精确期望风险 lattice 训练，lattice 用冻结模型自己的发射分布。翻译质量按构造等于 N，方法的新意（语音时间轴上的 HSMM 写出 lattice 精确训练）不变，仍是一个模型。P8/P9 已经证明翻译换成 N 之后，停顿收益仍在。
- **B：训练目标不再用 UniST 参考译文。** 如果一定要训 LoRA，就把 lattice 的目标序列换成冻结模型自己的完整音频翻译，即同一模型的自训练，没有教师模型。这样训练只学"何时写"，不学新的译文风格。
- **C：只在完整音频的 token 上计翻译损失。** 让 λ_L 倾斜只作用在写出决策上，不再鼓励在短前缀上预测参考词。这针对第 3 点 zh2en 的提前猜测问题。
- **不建议：** 改 UniST 参考译文去迎合 OBSI 的保留英文风格，这等于按测试集风格调数据。
