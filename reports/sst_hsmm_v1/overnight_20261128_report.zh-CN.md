# 夜间 8 轮结果报告（2026-11-27 21:25 → 11-28 早上，CET）

完整数值表（相对 B_b 的 5 cell 平均，全部指标 + COMET）：`reports/sst_hsmm_v1/overnight_20261128_tables.zh-CN.md`
预注册：`reports/sst_hsmm_v1/prereg.zh-CN.md` change 57–64，每轮都在看到该轮任何数字之前登记。
判定规则（未改）：相对 p3hk，(i) ASR-BLEU ≥ −0.2 且 D2 ≤ −0.10 s，或 (ii) 同 D2 处比 p3hk–p3hk2 连线高 ≥ 0.2。两个方向分别判定。

## 0. 结论

1. **zh2en 有了新的最好系统：HCG v2（视野对比引导）。**
   - 相对 p3hk：ASR-BLEU +0.79，95% CI [+0.22, +1.44]；文本 BLEU +0.89 [+0.42, +1.42]；D2 −0.11 s；比连线高 +1.15。之前最好的 S1 是 +0.61。
   - 第 8 轮换了一个独立训练的标记 adapter（b1tr），zh2en 仍然有效：ASR +0.55（CI [−0.01, +1.18]，下界刚好碰到 0），文本 BLEU +0.78 [+0.26, +1.33]，D2 −0.11 s，连线 +0.89。方向一致，效果基本可以复现。
   - COMET 同样支持：HCG v2 的 zh2en ASR-COMET 比 p3hk 高 0.005。
2. **en2zh 8 轮仍没有一个方法有效。**
   - 最接近的是 HCD（token 级视野对比解码）：D2 −0.18 s，ASR −0.32，连线 +0.06。这是第一个在 en2zh 上明显降时延、且基本在连线上的方法，但没有过判定。
   - CCA +0.06、SAA 流式 +0.02、EGA −0.01，都和 p3hk 基本重合。
3. **两个可以写进论文的机制发现：**
   - **(a) en2zh 的损失是微调带来的风格漂移，不是预判错误。**
     - 构成：英文术语被音译约占 41%，书面语体约占 59%。
     - dev 上用的原始 sacrebleu 看不到这个损失，已改成官方 BLEU 并补上 G0 门槛。
   - **(b) 预判起草器的时延收益几乎全部来自"已听到内容的译文更早定型"（前缀一致），而不是提交预测出来的未来内容。**
     - E1 每读多提交约 2 个单位，其中只有 0.15 个超出 p3hk 的整个草稿。
     - 由此可知，训练期把已听到部分锚定到 base（C1、SAA），会同时去掉风格漂移和时延收益。SAA 流式测试给出了直接证据：en2zh ASR +0.09，但 D2 +0.04 s。
4. **有效的原理是"似然比视野转移"：** s = log p_base + λ(log p_P − log p_C)。
   - adapter 的风格漂移同时出现在 P 和 C 两个分支里，相减后抵消，只有"不要在截断处收尾"被转移给 base。
   - 按贝叶斯推导 λ = 1，不是调出来的参数。
   - 在 zh2en 上有效，两个 adapter 都显著。在 en2zh 上候选级实现（HCG）仍带有 adapter 的语体；token 级实现（HCD）保住了措辞，但 BLEU 小幅下降（ASR −0.32）。

## 2. 每轮的分析和下一轮的依据

**第 1 轮（B1 / B2，数据修正和只学预判）**
- B1 只改写了 1.5% 的训练行，就换回 +1.6 G0 BLEU，证实术语约定是原因之一；剩下的 −2.9 是语体。
- B2 不带标记、只在截断音频上训练，在完整音频上也会续写，G0 掉到 35.60。监控指标 KL_a 升到 0.47。
- 下一轮：在完整音频上加 KL 锚定（C1）。

**第 2 轮（C1 / HCG v2）**
- C1 的 KL_a 只有 0.023，zh2en 完全恢复（30.71 对 30.64）。但 en2zh 仍是 −1.16，因为每 token 0.02 nats 的偏移就会翻转近似并列的贪心选择，有 45% 的句子输出变了。
- 结论：训练期锚定只能缩小漂移，不能消除。
- HCG v2 不改模型，只用 adapter 两个标记下的似然比给 base 加分。zh2en 显著有效；en2zh 的候选仍是 E1 的措辞，测试文本 BLEU −2.20（参考含英文术语的句子 −5.23，其余句子 −1.35）。

**第 3 轮（SAA）**
- 按音频支持分配目标：已听到部分 KL 到 base，未听到部分对参考算 CE；参考用 B1 的术语改写版。
- G0 为 40.43，比 C1 好，但仍未过。

**第 4–5 轮（EGA / CCA，推理期把已听到和未听到拆开）**
- EGA：头部完全由 base 写，G0 完全恢复（41.33）。但 LoRA 在 base 头部之后的贪心首选几乎都是"结束"，预判尾部很短。
- CCA 用"源语音仍在继续"这个已知信息做条件化，把尾部加长了，但测试时延仍几乎不变。
- 这两轮促成了第 6 轮之前的机制分析（change 62，`en2zh_analysis/a11_draft_cmp.py`）：时延收益来自已听到部分的前缀一致，不在尾部。

**第 6 轮（SAA 流式，越过 G0，按 change 62 登记的偏离）**
- en2zh ASR +0.09，风格完全保住；但 D2 +0.04 s，时延收益消失。
- 和机制分析一致：KL 锚定的对象是只看到前缀的 base，它本身就会收尾，所以锚定把收尾行为也保留了下来。

**第 7 轮（HCD）**
- 把似然比视野转移做到 token 级：base 主导措辞，只在 P − C 差分足够大处改道。推测式实现，平均每读 1.3 轮，约 30–45% 的草稿发生改道。
- en2zh 拿到了今晚最大的时延收益（−0.18 s），BLEU 损失约 0.3，基本在连线上；zh2en 也略高于连线。两向都没过判定。

**第 8 轮（HCG v2 + B1 adapter）**
- en2zh 文本 BLEU 损失从 −2.20 缩小到 −0.99，术语收回来了；但 ASR-BLEU 不变（−0.63）。英文术语经过中文 TTS 和 ASR 之后本来就难以保留，所以术语修正对 ASR-BLEU 不起作用；en2zh 的 ASR 损失主要是语体。
- zh2en 依然有效（+0.89），说明 HCG 的 zh2en 效果和用哪个 adapter 无关。

## 3. 新颖性评估（诚实）

- **最有 ICLR 价值的是"似然比视野转移"（HCG / HCD）。**
  - 依据：贝叶斯推导 λ = 1；adapter 风格在差分中抵消；zh2en 有显著且可复现的提升。
  - 弱点：en2zh 不成立；候选级和 token 级两种实现各有短板。
- **两个机制发现属于分析贡献，扎实且新：**
  - 微调风格漂移，以及 dev 指标的盲区；
  - 时延收益来自前缀一致。
- SAA、EGA、CCA 是负结果，但可以作为支撑机制发现的消融实验：同时保住风格和时延收益，训练期锚定和推理期拆分都做不到。
- B1 是数据工程，不算新方法。
- **整体判断：** 目前可以写成"zh2en 显著提升 + en2zh 失败原因的系统分析"。要冲 ICLR 正会，最好在 en2zh 上至少有一个过判定的结果，或者把 en2zh 处理成限制条件，并给出充分的分析。
