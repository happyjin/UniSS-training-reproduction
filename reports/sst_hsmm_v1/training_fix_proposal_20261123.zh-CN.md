# sst_hsmm_v1：失败原因与训练侧解决方案（2026-11-23）

所有证据都来自已有输出：P2（dev，实测）、留出集教师强制发射的重放（CPU）、T1c 的已存输出。没有新的 GPU 运行。P2′（只改推理规则）正在跑，结果出来后补到第 5 节。

## 1. 失败原因（按影响排序，带证据）

### C1（主因）目标函数类型：边缘似然在"开新段"的决策上学会犹豫，硬决策推理就系统性地晚写

- P1a 最大化的是 log Σ_z exp(score(z))，即对所有写出时机求和。这类目标覆盖多个模式：只要每个写出时刻都有一点概率，就不会被惩罚。所以在不确定的位置，最优解是把写出概率摊开（例如每读 w = 0.3）。
- 推理是逐 token 的硬决策：w < 0.5 就等，而且按顺序决策，一个 token 等待会挡住本读后面所有 token。
- 留出集（step 2500，在第一次可写的块上）写出概率 w < 0.5 的比例：

| token 类型 | en→zh | zh→en |
|---|---|---|
| 句首第一个 token | **67%**（中位数 w 0.34） | **52%**（0.49） |
| 短语开头（标点之后） | **60%**（0.39） | **64%**（0.36） |
| 标点 | 47% | 44% |
| 新一块里的内容词 | 28% | 28% |
| 和前一个 token 同块 | 23%（0.92） | 21%（0.90） |

  犹豫几乎全部落在"什么时候开一个新段"这个决定上。正好是这些决定，决定了 LAAL（首段权重最大）和停顿（短语开头）。
- 后果（教师强制重放，排除了"模型自己的前缀"这一因素）：同一组发射，lattice 最优路径的延迟代理是 5.415，硬决策规则是 5.707（+0.29 s）。P2 实测：首次写出晚约 0.5 s，最后一读之前写出的比例 43% → 34%（en→zh）、39% → 25%（zh→en）。

### C2 代价模型与真实系统不一致

1. **Talker 的每块固定开销没有建模。** 对照的 T1c 输出：时长 ≈ 333 ms·n + **216 ms**（en→zh）、318 ms·n + **235 ms**（zh→en）。1–3 个 token 的短块每 token 414–442 ms，10 个以上的长块 335–342 ms。lattice 假设每 token 时长固定、没有开块代价：
   - 它看不到"切得越碎，积压越多"，所以会低估碎写的真实延迟；
   - 代理和实测因此对不上：阈值规则（大块）的 LAAL 形式代理预测 +1.05 s，实测只有 +0.39 / +0.48；中位数规则（碎块）的代理又可能偏乐观。
2. **延迟代价的权重不对。** lattice 对所有 token 一视同仁地罚 min(e_i, X)；D2（LAAL）只计到 τ 为止，并且前面的单位权重更大。首段推迟在 LAAL 里很贵，在训练目标里却很便宜，这和 C1 的"句首犹豫"叠加在一起。

### C3 目标的上限：倾斜后验的最优点并不比 LA2 早

- LAAL 形式代理：lattice 最优路径 3.404，LA2 3.181。
- 原因：最大似然奖励多听再写（多听一块，发射的 NLL 更低），λ_L = 0.5 的延迟项压不住这个偏好。P0c 时已经出现这个信号（没有 λ 组合满足条件）。

### C4 用的是模型自己的前缀（次要，约 0.1 s）

教师强制重放已经复现了大部分 P2 差距（重放 +0.37，实测 +0.39 / +0.48）。

### C5 结构性下限（决定门槛能定到哪里）

- 1 s 一读下，理论最早路径只比 LA2 低 0.15 s（LAAL 形式代理）。所以"D2 −0.2 s 且停顿 −30%"任何策略都达不到。
- 帕累托门槛（D2 ≤ +0.05、停顿 ≤ −25%）在代理上是可达的：
  - en→zh：理论最早点是 −0.17 s / −27%；
  - zh→en：在中位数规则（−0.33 s / −11%）和 lattice 最优路径（+0.14 s / −34%）之间。

## 2. 方案：风险一致的分段语音时间线 HSMM（Risk-consistent Segmental HSMM）

核心思想：训练时优化的，就是推理时那个确定性策略真正会产生的语音时间线的代价。三个部分各对应一个原因。

### 2.1 分段语音时间线：把 Talker 的开块开销放进 HSMM（对应 C2.1）

- 状态多加 1 位："本块是否已经开始"。
- 写出一个 token 时，如果是本读的第一个写出（开新块），积压先加上开销 b_dir，再加上 a_dir·d_i。
- a、b 必须只在训练数据上拟合：在几百条 UniST 训练行上跑一次 T1c（1 张卡约 10 分钟），再做线性回归。上面第 1 节的 216 / 235 ms 是从 dev 的对照输出拟合的，只作为证据，不进入训练。
- 这样 HSMM 的"段"就是 Talker 真正的块，碎写的代价被精确计入。仍然是精确动态规划，状态数 ×2。

### 2.2 与指标一致的代价（对应 C2.2）

- 每个 token 的延迟代价改为 LAAL 形式：(e_i − (i−1)·X/n) / τ̂，其中 τ̂ 由参考对齐的理论最早路径给出（每条样本的常数），仍然可以在 lattice 上按 token 分解。
- 停顿代价用与 NP_in 相同的定义（短语内、≥ 0.3 s 的饥饿）。

### 2.3 决策一致的训练目标：精确期望风险 + 退火（对应 C1、C3，方法的主要新意）

- 目标分成两部分：
  - **翻译**：仍然是教师强制的发射似然（在写出的那一块上），保住 BLEU；
  - **策略（等待头 + 门控）**：最小化策略自身分布下的精确期望风险

    R(θ) = E_{z∼π_θ}[ cost(z) − Σ_i log p(y_i | x_{≤c_i}) ]

    在 lattice 上用期望半环做前向–后向精确计算：无需采样，也没有强化学习的方差。
- **理论依据（可写成命题）：** 发射固定时，期望风险对路径分布是线性的，最优策略在单纯形的顶点上，即确定性策略；边缘似然 log E[exp(score)] 是凹的 log-sum-exp，最优解会把概率摊开（C1 观察到的犹豫）。所以期望风险的最优策略正好就是贪心推理执行的那个策略，训练和推理一致。
- **退火：** 策略温度 β 从 1 逐步升到 8，使 π_β 收敛到确定性策略，消除剩下的期望–贪心差距。退火时间表预先固定，不在 dev 上调。
- 因为直接优化"写出时机 × 真实代价"，而不是"边缘似然 + 弱延迟项"，也绕开了 C3 的上限：最优点由代价决定，而不是由似然偏好决定。

### 2.4 可选：自身前缀（对应 C4）

第二阶段用模型自己写出的前缀做发射（一轮自举），只在第一阶段过门槛之后考虑。

### 新意（面向 ICLR）

1. 第一个在同传策略学习中显式建模**输出语音时间线 + Talker 分段开销**的半马尔可夫模型；
2. 边缘似然与期望风险在同传策略上的"犹豫–确定性"理论分析，加上在 HSMM 上精确计算期望风险的训练方法；
3. 机制证据：犹豫集中在开段决策上（上表），以及代理–实测的校准。

## 4. 风险（如实）

- 结构性下限决定了能拿到的最好结果是"同延迟、停顿明显少"，而不是"延迟大降"。
- 翻译和策略共用一个 Thinker：期望风险里的发射项可能把翻译往"更容易早写"的方向推，ASR-BLEU 有风险。翻译项单独用教师强制似然，就是为了压住这一点。
- 开块开销是从对照 Talker 拟合的全局常数，块内的语速变化没有建模。
