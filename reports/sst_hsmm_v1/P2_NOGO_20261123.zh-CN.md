## 3. 为什么：模型学会了"晚写"，停顿减少是延迟换来的

| Thinker 写出行为 | en2zh NEW | en2zh 对照 | zh2en NEW | zh2en 对照 |
|---|---|---|---|---|
| 最后一读之前写出的字符比例 | 34% | 43% | 25% | 39% |
| 每条非最后一读的写出块数 | 1.26 | 1.79 | 1.00 | 1.74 |
| 首次写出时刻（ms） | 3264 | 2752 | 3540 | 3077 |

- HSMM 训练把"可写时等待"的概率推高：写出更少、更晚、块更大。大块连续写出 → Talker 播放中途断档少 → NP_in / NC 下降。
- 但这正是此前确认过的不变量（`laal-tail-and-silence-invariants`）：**延后写出能保住语音连续性，但必然推高 LAAL**。倾斜目标里的 λ_L = 0.5 不足以抵消停顿惩罚 + 似然本身对"多听再写"的偏好（多听后发射 NLL 更低）。
- P0c 已提示语音延迟主要由语速积压决定；本结果说明，只靠 Thinker 端的写出时机，在这个基座上无法同时降低延迟和停顿。

## 7. 原因的定量分解（2026-11-23，CPU 事后分析，只报告；`analysis_greedy_tf.py` → `eval_outputs/sst_hsmm_v1/analysis/greedy_tf.json`）

方法：在 1200 条留出上，用教师强制的发射，**重放推理时的决策规则**（每读 1 s，按顺序逐 token 判断 w = σ(ℓ + 门控) ≥ 0.5 就写，第一个"等"就结束本读；状态更新同 `e2e_si_thinker`），与 lattice 的 Viterbi 路径和 LA2 对照比较。教师强制排除了"用的是模型自己写出的前缀"这一因素。

| 留出集（pooled） | 延迟代理 (s) | 停顿 | 非最后一读写出比例 | 写出块 − gᵢ |
|---|---|---|---|---|
| LA2（对照策略，P0c） | **5.338** | – | – | – |
| λ 网格最优（P0c，均匀转移） | 5.329 | – | – | – |
| step 0：Viterbi / 贪心重放 | 5.758 / 6.271 | 0.52 / 0.14 | 17% / 5% | 1.32 / 2.02 |
| step 2500：Viterbi | 5.415 | 0.80 | 40% | 0.63 |
| step 2500：**贪心重放（= 推理规则）** | **5.707** | 0.66 | 30% | 1.11 |

**分解（相对 LA2，延迟代理）：**

1. **目标本身的上限 ≈ +0.08 s。** 训练后的 Viterbi（5.415）以及 P0c 网格里最好的点（5.329）都不比 LA2（5.338）更早。也就是说，倾斜后验这个训练目标在最理想时也只能和 LA2 持平，到不了"D2 降 0.2 s"。P0c 时已经出现过这个信号（没有组合满足条件，回退到 λ = 0.5/0.5），当时记录为风险，按预登记没有改。
2. **决策规则不一致 ≈ +0.29 s（主因）。** 同样的发射，Viterbi 路径 5.415，推理规则 5.707。原因：
   - 在 token 第一次可写的那一块，32% 的 token 写出概率 w < 0.5（19% 在 0.1–0.5，13% < 0.1）。
   - 训练时，lattice 把所有路径相加，w = 0.3 的 token 在早期也贡献可观的写出概率质量，所以目标"看起来"写得早。
   - 推理时阈值 0.5 是硬决策：w < 0.5 就等；而且按顺序决策，一个 token 等待会挡住本读后面所有的 token。于是写出被推迟、集中到少数大块（非最后一读写出 40% → 30%），停顿少了、延迟高了。
3. **剩余 ≈ +0.1 s：** 贪心重放相对 LA2 是 +0.37 s；P2 实测 D2 是 +0.39（en2zh）/ +0.48 s（zh2en）。剩余部分来自模型自己的前缀、Talker / 播放器，以及代理与真实 D2 的差别，比前两项小。

**训练确实有效，但方向不够：** 和 step 0 比，推理规则下的延迟从 6.27 降到 5.71，非最后一读写出从 5% 升到 30%。问题在于起点太晚（门控偏置初值 = ℓ 中位数，step 0 时一半可写位置低于阈值），训练没能追回到 LA2 的水平。

**译文质量：** 文本 BLEU −1.46 / −1.15（CI 接近或跨 0），ASR-BLEU +0.98 / −0.67（都不显著）。没有格式问题（无空输出、无块边界重复、双标点比对照更少），长度比 1.01 / 1.05。en2zh/a/clean 文本 BLEU −4.16 较显著，可能是 LoRA 在 UniST 参考译文上训练后风格偏移，需要 GPU 才能进一步核实，未做。

**结论：** 失败有两层原因：(1) 训练目标的最优点本来就不比 LA2 早；(2) 训练优化的是"所有路径的边缘似然"，推理用的是"逐 token 硬阈值"，两者在 w 接近 0.5 的大量位置上分歧，系统性地推迟写出。(2) 是主因，也是这类"精确边缘似然训练 + 贪心阈值推理"方法的结构性问题。λ 调参解决不了 (2)，所以不建议在这条线上调参重试。
