# voice_onset_v1：听感"突然停止"与 LAAL 的数据分析（2026-11-22 13:46 CET）

本文只分析已有的测试输出，没有跑新的模型。数据来自 `eval_outputs/mist_w3po_v1/test_robust`，比较 B_b（`B/b`）与新方法 UE_mbr（`UE_mbr/mbr`，等同于 UE_hmo）。统计覆盖 10 个主单元。

## 1. 机制（代码）

`experiments/uniss_qwen3_omni_v1/evaluation/si_infer.py` 第 3 步的做法：

- 先把所有块的 codes 拼成一条序列，**一次性解码**成连续语音；
- 再按每个块的 code 数（每个 code 20 ms），把连续语音切成若干段；
- 每段从 max(写入时刻, 上一段结束) 开始播放，段与段之间补静音，切口处不做淡入淡出。

非末块以 `<|wait_read|>` 结束，Talker 的意思是"后面还有"，不会把这一句收尾。所以切口经常落在一个音节或一个词的中间，后面接着一段静音。听起来就是"突然停止"。

### 2.2 停顿的形态

- **大多是硬切：** 75–92% 的中间停顿（>300 ms）发生在切口处仍有声音的位置，即切口前 40 ms 的能量与该段响亮水平相差不到 15 dB。
- **很少落在标点处：** 只有 10–16% 的停顿在标点后，84–90% 在短语内部。
- **新方法的停顿更长：** 停顿中位数为英→中 820 ms、中→英 780 ms（B_b 为 780 / 660 ms）；p90 为 2.4–2.5 s（B_b 为 1.7–1.8 s）。

### 2.3 新方法相对 B_b 的 LAAL 来源

- UE_b（只换 Thinker）相对 B_b 的语音 LAAL 增量，与新方法相对 B_b 的增量几乎一样，例如英→中 RealSI 带噪 +0.38 对 +0.40 s。所以新增延迟来自 Thinker 侧（UniST LoRA + CV-LA），音色方法本身贡献为 0。
- 具体表现为：
  - 文本提交更靠后，末块内容占比上升 0.07–0.13；
  - 源结束后的说话时间增加 0.3–0.9 s；
  - 输出更长，英→中 RealSI 干净每条语音 6.92 s，B_b 为 6.60 s。

## 3. 只改播放层或语速的上界估算（按已有时间戳计算，未生成音频）

| 干预 | 英→中 新 RealSI | 中→英 新 RealSI | 说明 |
|---|---|---|---|
| 把切口前移到 300 ms 内最近的静音点 | 39–48% 的硬切可修，平均推迟约 175 ms | 同左 | 其余没有静音点，需要短淡入淡出或在词边界切 |
| 非末块最多放慢到 1.25×，用来填后面的空 | 停顿 2.01 → 1.78 s | 1.50 → 1.31 s | 只减少 10–15%，单靠语速不够 |
| ≤3 个单位的非末块不单独播放，粘到下一块一起播放 | 停顿 2.01 → 0.75 s，每单位平均推迟 ≤ +0.09 s | 1.50 → 0.22 s，≤ +0.17 s | 停顿减少 60–90%；延迟按上界估算 |
| 末块加速到 0.8× 时长 | 每单位 −0.23 s | 每单位 −0.23 s | 末块在源结束之后播放，不涉及因果问题；需要验证 ASR |

关于 ASR-BLEU 与身份：这两项用的是只含语音的 wav（`asr_speech.jsonl`），所以只改播放时刻的干预（前三项中的切口与粘块）不改变 ASR-BLEU 和身份。改语速需要重跑 Talker，必须过 ASR-BLEU 硬门槛。

## 4. 结论

1. "突然停止"有两层原因：
   - **渲染层：** 一条连续的语音在短语中间被硬切，再插入静音；
   - **文本到达层：** Thinker 每 1 s 窗口只提交 2–5 个字或词，下一段要等 0.8–2.5 s 才到。
2. 这与 2026-11-16 的 TS-PA 结论一致：中间停顿由文本到达决定，只改 Talker 的目标救不回来。但停顿**放在哪里**、以及**切口是否落在词中**，可以在播放层解决。
3. LAAL 的主要成分是源结束后的末块：新方法末块占 47–67% 的内容，源结束后还要说 2.9–4.1 s。降低 LAAL 最直接的杠杆是末块语速，其次是 Thinker 更早提交（但会影响 BLEU，并受非 QABC 约束）。

## 更正（2026-11-22 14:01 CET）

第 3 节"粘块"一行的估算有误：它只删掉了被粘小块**后面**的空隙，没有把挪到它**前面**的同等静音加回来。由于首次到末次出声之间的总静音基本守恒，粘块几乎不减少停顿**秒数**，只减少停顿**次数**，并能把停顿挪到词边界或标点处。

所以"停顿 2.01 → 0.75 s / 1.50 → 0.22 s（减少 60–90%）"不成立。实际效果按停顿次数在 S0 中测量，见 `S0_S1_S2_prereg.zh-CN.md` 变更 1。

"放慢填空"一行也有同样的守恒问题：放慢只会把末块往后推。
