## 1. 模型（端到端，只训练小模块；TitaNet、BiCodec、Thinker、Talker 冻结）
- **观测：** 每 1 s 一段（与 LA2 的读入步长一致），第 k 段 = [k−1, k) s。y_k 为 TitaNet-large 嵌入（L2 归一化），r_k 为该段 RMS（dB）。
- **投影头：** y′_k = normalize(y_k + A y_k)，A 为 192×192，初始为 0。
- **每段的精度（神经发射层）：** w_k = softplus(MLP_θ([y_k, r_k]))，结构 193 → 64 → 1。
- **可微 Kalman（各向同性，闭式）：** m_t = normalize(a0·μ0 + Σ_{k≤t} w_k y′_k)。μ0 = 训练集说话人质心的均值（固定），a0 = softplus(可训练标量)。
- **开口 HMM（从左到右，前向递推精确求和）：**
  - 隐状态 g ∈ {τ, τ+1 s, …, τ+K}，K = 2 s；
  - 停止概率 h_t = σ(MLP_φ([log(a0 + Σw), t − τ, w_t, cos(y′_t, m_{t−1})]))，结构 4 → 16 → 1；
  - p(g = τ + j) = h_{τ+j} Π_{i<j}(1 − h_{τ+i})，在 τ + K 处强制停止。
- **目标（最大化期望效用）：** J = E_{p(g)}[cos(m_g, c_spk)] − λ·E_{p(g)}[g − τ]（单位 s），λ = 0.045 / s。
  - λ 取 P0 测得的"在 τ 处多听 1 s 的平均身份增益"，所以只有预期增益高于平均水平的条目才会等待。只用这一个值，不扫。
- **监督：** c_spk = 同一说话人**其他**片段的干净整段 TitaNet 嵌入的均值（归一化，排除当前片段）。这是说话人级别的标签，不是"冻结模型在干净孪生上的输出"，不属于蒸馏。

## 2. 训练数据与过程
- **训练：** `data/open_voicecond_v1/idea1/train_en`、`train_zh`（LibriSpeech train-clean-100 251 人，AISHELL-1 400 人；4 万段 6 s 片段；y = 带噪混合，s = 干净）。每个片段同时作为带噪样本（y）和干净样本（s）。
- **模拟 τ：** 按 S1 dev 底座 LA2 首次写出时刻的经验分布抽样（取整到秒，≥ 4 s 的并入 4 s）：P(1, 2, 3, 4 s) = 0.035 / 0.345 / 0.417 / 0.203。每个样本固定种子 20261121。
- **优化：** Adam，lr 1e-3，batch 256，5 个 epoch，单种子，取最后一个 epoch（不做选择）。
- **留出说话人：** `diag_en`、`diag_zh` 的 dev 划分（共 1000 段）用于 P1 检查；test 划分只报告。说话人与训练集不重叠，背景与训练相同。

## 3. P1 检查（留出 dev，带噪与干净分开报告）
- **G1 后验质量：** 在固定开口 g = τ 时，带噪样本 cos(m_τ, c_spk) ≥ cos(TitaNet(前缀 [0, τ]), c_spk) − 0.005。
  - 不通过时，部署的目标嵌入改用 TitaNet(前缀 [0, g])，开口门控照用。这一回退规则事先写定。
- **G2 机制（只报告）：** 学到的精度 w 在带噪段的均值与干净段之比；w 与 RMS / 背景强度（bvr）的相关。
- **G3 开口（只报告）：** 干净 / 带噪下的平均额外等待；J 对比"从不等待"（g = τ）。
- 另报：不加权平均、整段前缀嵌入、本模型在 g = τ 和在学到的 g 时的 cos。

## P1 结果（2026-11-21 18:45 CET，只追加）
- **嵌入预计算：** CPU，48 个进程，约 45 min；训练 4 万段（651 人），留出 2000 段（294 人）。
- **训练：** CPU，5 个 epoch，几分钟。train loss（−J）：−0.826 → −0.842。输出 `eval_outputs/voice_onset_v1/p1/train/{model.pt,summary.json}`。
- **留出 dev（1000 段，余弦为对说话人质心）：**

| 条件 | 整段前缀 TitaNet（τ） | 不加权平均（τ） | 本模型后验（τ） | 本模型 τ+1 s / τ+2 s | 学到的开口 |
|---|---|---|---|---|---|
| 带噪 | 0.7715 | 0.7358 | **0.7730** | 0.7976 / 0.8129 | 全部 j = 0 |
| 干净 | 0.8231 | 0.7933 | 0.8111 | 0.8327 / 0.8455 | 全部 j = 0 |

- **G1：通过**（带噪 +0.0015 ≥ −0.005），部署使用后验均值。
- **G2：** 带噪段 / 干净段的平均精度之比 0.98；精度与段的 RMS 相关 r = 0.50，与背景强度（bvr）相关 r = −0.04。也就是说，学到的是"按响度（语音有无）加权"，**不是按噪声加权**。
- **G3：** 留出 dev 上多听 1 s 平均只提升约 0.025，低于 λ = 0.045，所以模型学成"从不等待"（干净和带噪都是 0 s），J 与"从不等待"相同。与 P0 的结论一致。
