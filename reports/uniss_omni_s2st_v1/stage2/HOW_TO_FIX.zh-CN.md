# 怎么修 Stage 2 的退步

依据:[WHY_STAGE2_REGRESSED.zh-CN.md](WHY_STAGE2_REGRESSED.zh-CN.md)。
根因是 **Talker 在联合条件化上欠训 28 倍**,不是架构问题。

---

## 先确定上限:修好能回到哪

同一份 Stage 2 Talker 权重,走 cascade 路径已经能跑出:

| 方向 | ASR-BLEU | A.PCP |
|---|---:|---:|
| Zh→En | **24.41**(Stage 1 是 24.82) | **2.917**(2.925) |
| En→Zh | **27.89**(28.70) | 2.769(2.774) |

所以把联合路径训到位,**ASR-BLEU 有望回到 24–28 区间**,即收回那 5–6 分中的
绝大部分。这不是估计,是同一套权重在另一条路径上已经实测到的数。

## 方案 A(主方案):加大联合条件化的训练量

| 项 | 现在 | 改为 | 理由 |
|---|---|---|---|
| `MIXTURE` 的 s2st | 1.5 | **3.0** | 联合条件化份额 35.7% → 52.6% |
| `TRAIN_ITERS` | 6,000 | **18,000** | 联合样本 54.9 万 → **242 万**(4.4×) |
| Talker 学习率 | 1e-4 → 2e-5 | **5e-5 → 1e-5** | 压住"同路径下 Talker 退步 1.1–1.8 分"那一项 |
| `tts` 份额 | 1.0 | **1.0 不动** | 保住干净路径,防遗忘 |

其余不变(GBS 256、LoRA r32/α64、激活重算、全量 shuffle)。

**成本**:18,000 步 × 约 3.0 s ≈ **15 小时**。
即便如此,联合样本仍只有 Stage 1 干净样本量的 1/6 —— 这是在成本和效果之间取的
折中,不是"训到饱和"。

## 方案 B(建议前置):Talker 单独热身

Stage 2 里 Thinker 的隐状态随 LoRA 一起变,**Talker 在追一个移动的目标**。
先冻结整个 Thinker(连 LoRA 都不挂),只训 Talker 的 S2ST 任务:

- 目的:让 Talker 先适应新的输入分布,再进联合训练
- `TRAIN_ITERS` 4,000,只开 s2st + tts
- **成本约 3 小时**

做完再跑方案 A。总计约 18 小时。

## 方案 C(只在 A 之后仍不达标时考虑)

训练时就让 Talker 的文本流**从译文起读**,而不是从转写起读。

注意:假说 1 的否定实验是**不重训改推理**,它证明当前 Talker 依赖转写那一段,
但没有证明"从一开始就按译文对齐训练"不会更好。这是个真实的开放设计问题。

**不建议作为首选** —— 证据显示 Talker 从转写里取到了有用信息(拿掉掉 3 分),
而且它要改训练代码。放在 A 之后作为 A/B。

## 不要做的事

**不要换 Talker 或 codec(CosyVoice 2/3 等)。** 同一套权重在合适条件化下已
跑出 24.41 / 27.89,架构没问题。换掉要:重做 Stage 0/1/2/3、新建独立
conda 环境(CosyVoice 不在 transformers 里)、放弃 UniSS 那 32 个 global token
直通声码器的音色通路 —— 而那条通路目前**完好无损**(SIM-O ±0.01,A.PCP ±0.08)。

**不要在当前 Stage 2 上起 Stage 3。** 流式只会在离线基础上减分;而且 Stage 2
现在已低于 Stage 3 自己的 A.PCP 验收门(2.850 / 2.782 对门槛 2.9073 / 2.7889)。

## 执行顺序

```
1. 先导探针   2,000 步,新混合比 + 新学习率              约 1.7 小时
   在随机 1,000 条上测 Talker 损耗（Text−ASR）
   门:损耗应低于当前的 5.12 / 6.75
   不达标就停下重想,不要直接烧 15 小时

2. 方案 B     Talker 热身 4,000 步                      约 3 小时

3. 方案 A     联合训练 18,000 步                        约 15 小时

4. 全量评测   随机抽样选 checkpoint → 完整 CVSS-T        约 2 小时
   门:ASR-BLEU ≥ 24.82 / 28.70（即不得劣于 Stage 1）
```

## 计划文档要补的一条门

现行 Stage 2 验收是「CVSS-T Text-BLEU > 24.15 / 15.33」—— 那是旧 0.5B 基线,
Stage 2 实测 29.91 / 23.77 **轻松通过**。所以一个 6 BLEU 的退步是从一道"通过"
的门里走出去的。

应补:**每一阶段在全部 Table 1 指标上不得劣于上一阶段**,且比较必须用
全量测试集或固定种子的随机抽样,不得用排序后的前 N 条。
