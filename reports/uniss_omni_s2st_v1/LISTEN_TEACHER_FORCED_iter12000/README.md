## 怎么听

1. 先听 `_金标.wav` —— 它证明声码器、码本映射、说话人通路都正常。
2. 再听 `_教师强制.wav` —— 这是模型在**最有利条件下**(历史全对)的输出。

## 预期与事实

top-1 只有 **1.0–3.8%**,所以 `_教师强制.wav` 预计仍然不是可懂语音。
它的价值在于区分两种失败:

- 若教师强制可懂、自由生成不可懂 → 模型学会了映射,只是撑不住自己的上下文
- 若教师强制也不可懂 → 每一步的预测本身还不够好,**换任何解码方式都救不了**

## 自由生成的长度

同一检查点自由生成 16 条的码长:[3, 3, 3, 3, 3, 3, 3, 5, 5, 5, 5, 8, 11, 11, 147, 600]

金标是 136–444。用的是 Omni Talker 自己的采样默认值(温度 0.9 / top-k 40 /
top-p 0.8 / 重复惩罚 1.05),不是贪心 —— 采样也救不回来。

原因不是 eos 学错了位置:教师强制下 P(eos) 在码位置 0/1/3/10/20/中点全是 0.000,
只在真正结尾飙到 0.989。是自回归走三五步后上下文离开了训练分布。
