# E2E Simultaneous S2ST gold trajectory smoke v2

Status: **PASSED**

This is the first CPU data gate for the section-27 single-student E2E plan. It
uses 32 real rows from the immutable 15-shard Stage-A formal training manifest,
not synthetic fixtures. Eight CPU workers converted the aligned source words,
bilingual target support, micro-WRITE boundaries, and BiCodec semantic spans
into the new unified append-only trajectory schema.

## Manual sample inspection

`NCSSD_R_EN_0000000000` produces 15 monotonic events over 4,220 ms. The final
source prefix is:

```text
Hello I'm looking for a book on mindfulness Can you help me
```

The final aligned target prefix is:

```text
你好我在寻找一本关于正念的书你能帮我吗
```

All 178 target semantic codes are emitted once, contiguously, and finish before
the source-final event. Punctuation remains in `full_translation` for Phase3
replay; the event-aligned target prefix intentionally uses the forced-aligned
word-normalized form so no punctuation is invented before acoustic support.
