## 4. 判定（按预登记 §1、§2.5 的解读规则）

### 4.1 实验一（BoN-SFT，"无格"消融）

- **质量：持平**。Δ语音 = −0.14 ≥ −0.2，且 P(Δ ≤ 0) = 0.910 < 0.95，即 BoN 以 PL-EM 为参考过门槛。点估计两个种子都为负（−0.17 / −0.11），但没有达到登记的"格对质量有贡献"的线。
- **每条流延迟：持平**。每条流语音 LAAL 的 Δ = +0.021 s ≤ +0.05 s。
- **结论（登记的措辞）**：两项都持平，所以 **PL-EM 在每条流设定下的收益可由 best-of-N 蒸馏解释**。BoN 本身对 A′ 也过门槛（+0.21，P=0.001），差距归一按段 1.49 → 1.24。
- **补充（未登记，不判定）**：格的作用出现在单通道和收尾上。
  - BoN 的单通道 LAAL 比 PL-EM 高 0.44 s，两个种子同号（+0.53 / +0.35）；
  - 单通道 EndOffset 高 0.52 s，每条流 EndOffset 高 0.10 s；
  - 归一按段语音分低 0.085，差距相应大 0.085。
  - 也就是说，PL-EM 的延迟项在每条流 LAAL 上看不出来，但缩短了块长，在共享通道的排队里被放大。

### 4.2 实验二（单通道 PL-EM v2）

- **对 A′ 过门槛**：+0.34，P = 0.000。
- **单通道 LAAL 没有比 PL-EM 低 0.5 s，反而高 0.191 s**（5.832 vs 5.641），两个种子都更高（+0.22 / +0.16）。
- **判定："单通道建模有效"不成立**（登记要求低 ≥ 0.5 s 且两种子同号）。
- **质量没有代价**：对 PL-EM 的配对语音 −0.01，P = 0.57。
- **对 A′**：单通道 LAAL −1.24 s，每条流 LAAL −0.07 s，EndOffset −0.20 s，差距归一按段 1.49 → 1.28。
- **原因**：与预检一致。会议格的预算（A′ − 1.0 s）比每条流格实际达到的单通道降幅宽松，λ 只有 0.041，训练出的 talker 比 PL-EM 更保守。共享积压 token 的推理实现本身是正确的（上面的一致性检查）。
- **后续**：用户批准了修正预算的 E2′（`talker_crf_prereg_v3.zh-CN.md`），结果见 `talker_crf_results_v3.zh-CN.md`。

### 4.3 综合

- 三个 talker（PL-EM、BoN、会议格）对 A′ 都过门槛，语音 ASR-BLEU 都不降。PL-EM 仍是三者中最好的：语音分最高，单通道 LAAL 最低。
- 在每条流设定下，PL-EM 的增益主要来自 best-of-N 蒸馏，与格无关；格的价值体现在单通道 / 收尾延迟上（BoN 单通道 +0.44 s）。论文里"格"的论点应放在单通道设定。
- 显式的会议格在登记的预算下没有超过每条流格，更紧的预算见 E2′。
