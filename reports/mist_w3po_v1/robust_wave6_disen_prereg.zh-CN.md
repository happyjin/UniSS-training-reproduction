# 鲁棒第六波：音色条件的身份 / 无关属性解耦 Talker（DisenBooth 式）预登记

2026-11-19 晚（布拉格），写于任何第六波数字之前。用户："开。不算。用另外四卡开始"。用卡 4–7；主线 Fishr 在卡 0–3。约束见 memory `robust-paper-constraints`：
- 一个模型服务两个方向；
- 不用蒸馏：目标是真实语音的语义码，不用任何模型输出作目标；
- 不碰 QABC；
- 训练只用开源非测试数据；
- 一个设置，不扫参，一个 TTS 种子 20261021。

## 动机（已测）
- 第一波：音色 token 改变 Talker 时长 ±5%（Wilcoxon p ≤ 1e-7）。线性语速探针 R² 0.89，但沿它钳制只让时长变异降了 5.7%。
- 第三波 V 组：只换音色 token，D2 LAAL 就稳定变化 −0.04 到 −0.07 s（CI 不含 0）。
- 两者说明音色条件里泄漏了与身份无关的属性（语速、噪声），而且是非线性的。
- 来源：DisenBooth: Identity-Preserving Disentangled Tuning for Subject-Driven Text-to-Image Generation（ICLR 2024，arXiv 2305.03374）。

## 方法（一个设置）
- **身份分支：** c_id = σ(m) ⊙ E(g)。
  - g 是 32 个音色 token，用 Idea 1 C 编码器作用于提示得到（训练时提示随机混入非留出背景）；
  - E 是 T1c 自己的 global token 嵌入；m 是可学习的逐维 mask，初值使 σ(m) ≈ 1。
- **无关分支：** c_irr = h_ψ(提示的 log-mel)，即 4 个软前缀向量。h_ψ 是一个小型卷积 + 注意力池化编码器，只在训练时接入。
- **损失：**
  L = NLL(x | c_id, c_irr) + λ_w·NLL(x | c_id) + λ_c·InfoNCE(c̄_id) + λ_o·cos²(c̄_id, c̄_irr)
  - x 是真实目标语音的语义码；c̄ 表示在位置上取平均；
  - InfoNCE 的正例：同一说话人的另一条提示（另一句话、另一种背景）；负例：batch 内其他说话人；τ = 0.07；
  - λ_w = 1，λ_c = 0.1，λ_o = 0.1。这是 DisenBooth 的量级，固定，不扫参。
- **推理：** 只用 c_id，不接 c_irr。语速完全交给已有的块语速 token（`--speed-policy block`）。
- **可训练部分：** Talker 注意力上的 LoRA（rank 16，α 32）、m、h_ψ。BiCodec 解码器与 C 编码器冻结。
- **训练长度：** 3000 步，lr 1e-4，余弦，batch 32；只存适配器和小模块。

## 对照（同数据、同步数、同随机数）
- **T-ft：** 同一个 LoRA 只用 NLL(x | E(g)) 训练（没有 m、c_irr、λ 项）。用于分清"微调本身"和"解耦"各自的贡献。
- 另外两个参照，不训练：V1（C + T1c 原版，第三波已有）、B（原始 token + T1c，S1 已有）。

## 评测
- 同 S1 / 第三波 V 组：S1 的 LA2 文本，si_infer `--speed-policy block`，4 个 shard，种子 20261021。
- 两个方向，数据 (a) 与 (b) 的无串音子集，干净和带噪都跑。
- 指标：PESQ、ASR-BLEU、说话人相似度、D2 LAAL（主）、D1。
- 另做时长变异检验：同一条目、同一文本、同一种子，在四种音色条件下（原始 token、C、V2 的 token、干净提示的 C token）生成，计算时长变异系数。

## 门槛（解耦臂 vs T-ft，同时对 V1 报告）
1. 四种音色条件之间的时长变异系数下降 ≥ 50%（配对中位，CI 上界 < 0）。
2. 带噪 D2 LAAL：均值差 ≤ 0，且不劣于 V1 超过 0.02 s。
3. 带噪 PESQ 中位差 ≥ −0.05（对 T-ft 和 V1）。
4. ASR-BLEU 差的点估计 ≥ −0.5，且 CI 上界 ≥ 0（对 T-ft 和 V1）。
5. 相似度中位差 ≥ −0.02（对 V1）。

## 实现细节（执行者在任何评测数字之前追加）
（2026-11-19 22:40 布拉格，写于正式训练和任何评测数字之前；冒烟每臂 20 步只看 loss 量级、显存和速度）

- **数据来源：** T1c 原训练用的 UniST 分片（`data/unist_omni_v1` 只剩 README，服务器迁移后未恢复）在本机不可用。改用本机的 UniST pilot 子集 `data/processed/simul_uniss_subsecond_v1/pilot_15shard/stage_a_source`。
  - 它是同一开源语料（CC-BY-NC），共 150 万行，两个方向都有：源音频、源 GLM token、译文、目标 BiCodec 语义码。
  - 不含任何测试集（RealSI / ACL / AliMeeting / CoVoST test / 电竞）。
- **选行：** 按 sha1("20261119|w6|行号") 排序，筛选条件：
  - 2 s ≤ 源时长 ≤ 12 s；
  - 1 ≤ 码数 ≤ 600；
  - 译文非空，GLM 非空，原 global 长度为 32。
  - 每方向取 48,000 行（缓存 `eval_outputs/mist_w3po_v1/wave6_disen/rows_3000x32.json`）。
  - 每步 16 条英→中 + 16 条中→英；两臂读完全相同的行、裁剪和背景（随机数由行号和步数派生）。
- **序列：** 与 T1c 完全相同。用 `si_batch.streaming_row` 加块语速 token，或 `e2_batch.offline_row`；si 行占比 0.7，同 T1c。
  - T1c 所用的词时间索引本机也没有。si 行的分块方法：
    - 按词（英）/ 字（中）等量切成 1–4 块，码按比例切开；
    - 写出时刻 = 源时长 × 比例 + 200 ms；
    - GLM 读到该时刻减去 12 个 token 的 holdback；
    - 最后一块取剩余部分。
  - 标签：所有码和收尾 token，普通交叉熵。没有教师、没有 KL、没有 anchor。
- **提示：**
  - A = 源音频的前 L 秒，L ~ U(1, min(6, 时长))；
  - B = 同一条音频的另一段（≥ 1 s，够长时取后半段）。UniST 没有说话人 ID，所以 InfoNCE 的正例是"同一说话人、另一段、另一背景"。
  - 每个提示以 0.8 的概率混入背景：`wave1_data.mix_one`，Idea 2 背景 train 划分（非留出），BVR 分位 q ~ U(0.05, 0.95)。
  - g = C 编码器作用于 A 得到的 32 个 id。
- **实现：**
  - LoRA 为手写的线性层包装（qwen3omni 环境没有 peft），rank 16、α 32，加在 28 层的 q/k/v/o 上，参数为 fp32，底座为 bf16。
  - 学习率：LoRA 1e-4；新模块 m 和 h_ψ 用 1e-3。原因：m 初值为 3.0（σ = 0.953 ≈ 1），用 1e-4 的 Adam，3000 步内 m 最多只能移动约 0.3，等于不学。
  - 优化：AdamW（wd 0），预热 100 步后余弦衰减，梯度裁剪 1.0；每臂 2 卡，梯度手动 all-reduce。
  - h_ψ：80 维 log-mel → 2 层卷积 → 4 个查询向量的注意力池化 → 1536 维。c_irr 插在 \<end_global\> 之后。
- **冒烟（20 步）：**
  - 初始 NLL 约 4.31，两臂一致；InfoNCE 约 2.0（log 16 = 2.77）；正交项约 5e-4。
  - 速度：T-ft 约 0.4 s/步、显存 51 GB；解耦臂约 0.9 s/步、91 GB。
  - 预计单臂 ≤ 1 h，**步数维持 3000**。
- **导出与评测：**
  - LoRA 合并进 q/k/v/o。
  - 解耦臂把 global token 的输入嵌入行乘以 σ(m)，并解绑 lm_head：保留原嵌入作输出头，所以输出 logits 的含义不变。
  - 评测时只接 c_id，不接 c_irr。
  - 两项核对：导出模型与训练时前向在 5 条上的 logits 一致；LoRA 置零、σ(m) = 1 时导出模型与 T1c 等价。
  - 音色 token 用第三波 V1 的 C token 表。S1 文本、4 个 shard、种子 20261021 都与 V1 / B 相同。

## 变更：统一判定标准（2026-11-19 深夜布拉格，写于本波任何评测数字之前）
用户："指标只需要关注 bleu 值不退化，laal 不要太差，音质有提升就可以"。主判定改为下面三条同时满足，原门槛降为次要结论照列：
1. **BLEU 不退化：** 两个方向、干净和带噪，对比底座（或本波对照）：
   - 文本 BLEU：点估计 ≥ −0.3，且配对 bootstrap CI 上界 ≥ 0（不显著变差）；
   - ASR-BLEU（如测了）：同样要求。
2. **LAAL 不太差：** D2 语音 LAAL 均值差 ≤ +0.10 s。
3. **有提升：**
   - 改语音通路的方法（Talker、音色）：带噪 PESQ 配对中位差 > 0，且 CI 下界 > 0；
   - 只改 Thinker 或前端的方法：至少一个带噪单元的文本 BLEU 显著提升（CI 下界 > 0）。
