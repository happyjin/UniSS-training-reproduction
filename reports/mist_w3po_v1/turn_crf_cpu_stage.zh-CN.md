# TurnCRF CPU 阶段：非端到端预检（方案二，crf_novel_ideas.zh-CN.md §3.4 / §11）

**要回答的问题**：只用冻结 diarizer 的逐帧后验 P（`lowlat`，T×8，80 ms/帧），不接 LLM 特征，一个流式、可处理重叠的 semi-CRF 轮次层，能否比原始 P 更好地恢复参考说话人轮次？如果不能，端到端 TurnCRF 的前提不成立。

全程只用 CPU（不碰 GPU）。训练只用 AMI train 窗口，选择与评测只用 dev（`windows_dev_online.jsonl`）。没有读取 RealSI、ACL 60/60、AliMeeting。

## 1. 数据事实

**窗口文件。**
- `windows_train_online.jsonl`：28106 个窗口，127 个会议，`utts` 全为空。
- `windows_train_diar.jsonl`：其中 23742 个窗口（id 是前者的子集），带 `utts`。其余 4364 个窗口被构建脚本丢弃：3963 个有跨窗口边界的话语，401 个没有语音。
- `windows_dev_online.jsonl`：3050 个窗口，15 个验证集会议，**`utts` 全为空**。

所以 dev 的参考、以及 train 中没有 `utts` 的 4364 个窗口的参考，都需要重建。

**参考的重建。** 按 `experiments/mist_w3po_v1/data/build_windows_zh2en.py` 的规则重建：
- 取 `zh_mix_v8` 中非 hesitation、未被移除、已放置的话语，凡与窗口有重叠就收入，并裁剪到窗口内；
- 槽位直接调用该脚本的 `window_slot_map`，即窗口内对 P>0.5 做匈牙利匹配。

用全部 23742 个 train_diar 窗口核对：帧级参考 23742/23742 个窗口完全一致，`slot_win` 60495/60495 条一致。

**slot_win 的编号。** 从 1 开始：构建脚本写的是 `int(j) + 1`，所以 npy 的列号 = `slot_win − 1`。实际取值最大为 6（train）和 5（dev）。

**参考的约定。**
- hesitation 不算参考语音，与构建脚本一致：只有 hesitation 的帧标为 ∅。

- 评测指标用**未截断**的参考槽集合 R。

## 2. 模型（`turn_crf.py`）

**标签空间。** C = {∅} ∪ {k} ∪ {{k,k′}}，K=8 时 |C|=37。

**分段方式。** 分段是**极大段**：相邻两段的标签必须不同，所以给定帧标签 y，切分唯一。

**势函数。** 参数按类型和关系类型在槽之间共享。

- **内容**：u_t^c = a_type · log(∏_{k∈c} P ∏_{k∉c}(1−P)) + b_type，type ∈ {∅, 单人, 双人}。
  - 段分数是内容在段内的**求和**。§3.2 写的是段内平均；求和才能保证初始化时严格等于"独立 P"模型（在 |c|≤2 上重新归一化），这一点有单元测试。
- **时长**：d^type_q 在 q ≤ Q=50（4 s）时是自由表；q>50 时是线性尾（几何尾），斜率 = d_tail/(L−Q)。
  - 最大段长 L = 257，等于窗口上限，所以窗口内的轮次不会被截断。
- **转移**：按 11 种关系分别给势：
  - ∅→单、∅→双；
  - 单→∅、单→另一单、单→含它的双、单→不含它的双；
  - 双→∅、双→其中一人、双→另一人、双→共享一人的双、双→不相交的双。
  - 同标签之间的转移为 −∞（极大段）。
  - 另有按类型的起始势和结束势。
- **边界势**：w_enter · Σ_{k∈c∖c′} ΔP_{t,k} + w_leave · Σ_{k∈c′∖c} (−ΔP_{t,k})，其中 ΔP_t = P_t − P_{t−1} 是因果的一帧差分。
- **初始化**：a=1，b=0，其余全为 0，即严格等于"独立 P"。
- **参数个数**：semi-CRF 178 个；线性链 28 个（不含时长，另加按类型的自转移 A_self，即几何时长）。

**流式（§3.2）。**
- 前缀 τ 上，最后一段未结束：用生存势 d̄_q = logsumexp_{q′≥q}^{L} d_{q′}，并且没有结束分。
- 线性链的前缀只是去掉结束分。

**算法。**
- 批量 log Z：semi-CRF 为 O(T·min(T,L)·|C| + T·|C|²)，用 autograd 求梯度；同一遍前向就能得到所有前缀的截尾 log Z̃_τ。
- 显式前向-后向，得到帧边际 μ_t^c 和槽边际 π_t^k = Σ_{c∋k} μ_t^c。
- Viterbi。
- log Z_y：有两种算法，结果相同（有测试）：
  - 带约束的 DP，即对与 y 一致的切分求和；
  - 直接计算参考路径分（极大段下只有一条路径，训练用这个）。

## 3. 单元测试（`test_turn_crf.py`，全部通过）

8 项测试，在 K=2–4 个槽、T ≤ 6、L ∈ {2,3,4,6,8} 的随机实例上做穷举：

1. semi-CRF 的 log Z、帧边际、Viterbi（标签与分数），闭合版与截尾版都测；批量前缀 log Z̃_τ 在每个 τ 上都测；log Z_y 的显式 DP 和批量 DP 都测。实例覆盖 L<T（长度约束生效）和 q>Q（几何尾）。
2. 线性链 CRF 的同样内容。
3. autograd：∂log Z/∂u = 帧边际（闭合版与截尾版，semi 与链都测）；∂log Z/∂d = 期望段长计数（与穷举对比）。
4. 带填充的批量计算与逐条计算一致；训练损失 ≥ 0。
5. 直接的路径分 = 带约束的 DP，在每个 τ 上、含填充时都成立。
6. 当 d_q = (q−1)·s 时，线性链与 semi-CRF 完全相同。
7. 初始化时边际 = 独立 P 的 softmax。
8. 参考中出现长度 > L 的段时，Z_y 为不可能（≈ −∞）。

运行命令：`PYTHONPATH=. python -m experiments.mist_w3po_v1.crf.test_turn_crf`

## 4. 预登记（在看到任何 dev 结果之前写定并提交；每个模型只有一个设置，不扫参）

### 4.1 训练（两个模型相同）

- **数据**：train 的全部 28106 个窗口（2,220,291 帧），参考见 §1。不用 dev。
- **损失**：每个窗口的损失是 (log Z − log Z_y)/T + (log Z̃_τ − log Z̃_τ,y)/τ，即完整窗口（闭合）加一个随机右截尾前缀。
  - τ ~ U{1..T−1}，每一步用种子 (0, step) 重新抽取。
  - 对窗口求平均。没有正则项。
- **优化器**：全批量 Adam（β=(0.9, 0.999)），lr 0.05，150 步内余弦衰减到 0。
  - 一步就是对全部训练窗口完整算一遍（相当于 150 个 epoch）。
  - 取第 150 步之后的参数作为最终参数。没有早停，不在 dev 上选择。
- **semi-CRF 的固定选择**：L=257，Q=50，P 裁剪 ε=1e-4，边界特征为一帧 ΔP，float64。
- **线性链**：除去时长部分外与 semi-CRF 相同，另加 A_self。
- **资源**：semi 52 个 worker，链 36 个 worker，加上 2 个主进程共 90 个 CPU 进程，每个进程 1 个线程。
- **训练前的检查**（只用 train）：在 2000 个窗口上跑 30 步，只确认损失在下降。发现时长尾斜率参数的单步影响过大，于是把 d_tail 改成"整个尾部的总变化量"这一尺度。这是参数化上的修正，不是超参取值，并且在任何 dev 评测之前完成。

### 4.2 dev 评测（`eval_turn_crf.py`）

**范围。** dev 的 3050 个窗口，258,174 帧，15 个会议。

**系统。**
- (i) raw：逐槽 P ≥ 0.5；
- (ii) med5：P ≥ 0.5 后，在每个槽上做 5 帧中值滤波（`scipy.ndimage.median_filter`，mode="nearest"）；
- (iii) chain：线性链 CRF；
- (iv) semi：semi-CRF。

**解码。** CRF 一律用槽边际 π_t^k ≥ 0.5，阈值固定为 0.5。另外报告离线 Viterbi（chain_vit / semi_vit），只作辅助，不进入停止规则。

**离线模式。** 用整个窗口的闭合模型。

**流式模式。**
- 读取时刻为窗口内 1 s、2 s、…（小于窗长）以及窗口结束。读取时刻 r 对应的前缀长度为 ⌊r/80 ms⌋ 帧。
- 帧 t 的标签取自第一个包含它的前缀，在该前缀的后验上做判定。
- CRF 的前缀用右截尾模型；窗口结束那次读取用整个窗口的闭合模型。
- raw 是逐帧判定，流式与离线相同。
- med5 在每次读取时对当前前缀做滤波（前缀末端用 nearest 填充）。

**指标。** 都在全部窗口上汇总后计算，参考为未截断的 R。

- **轮次 IoU-F1**：轮次是某个槽的一段极大连续激活；匹配要求槽相同且 IoU ≥ 0.5，一对一，按 IoU 贪心。
- **≤1 s 参考轮次召回**：轮次长度 ≤ 12 帧（0.96 s）。
- **帧级 miss / FA / 混淆率**：DER 式分解，按固定槽位（不重新映射），除以参考的槽-帧数。
- **重叠帧 F1**：重叠帧指至少 2 个槽激活的帧。

**bootstrap。** 会议级配对 bootstrap：对 15 个会议有放回重采样 1000 次，种子 0。差值 = CRF −（同一模式、同一指标下点估计较好的那个基线）。报告差值、95% 分位区间和 P(diff ≤ 0)。

**停止规则（预登记）。**
- 流式 semi-CRF 必须在轮次 IoU-F1 和 ≤1 s 召回两个指标上，**都**高于流式 (i) 和流式 (ii)，按点估计比较，共 4 个比较。只要有一个不满足，就判定端到端 TurnCRF 的前提不成立，并如实写明。
- 4 个比较都通过时，再看 bootstrap：如果相对较好基线的 P(diff≤0) ≥ 0.05，就标注为"弱通过"。
