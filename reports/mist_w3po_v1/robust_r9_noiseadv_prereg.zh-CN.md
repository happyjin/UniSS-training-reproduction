# 鲁棒 R9：让编码器输出"看不出有没有噪声"的对抗式 LoRA（Noise-Presence Adversarial Encoder LoRA）预登记

2026-11-21 04:25 CET（布拉格）写，早于本方法的任何训练或评测数字。夜间执行者按用户授权设计。约束同 R5：只用同一批 UniST 训练数据；不做蒸馏（判别器是对抗训练的二分类器，不是教师，没有软标签或伪标签）；不用 QABC 组件；一个模型两个方向；一个设置不扫参；点估计；dev 只用 D-U + bench_dev (b)。

## 1. 动机（来自 R5、R6 的结果）
R5（梯度手术）和 R6（干净零空间）各自从不同方向保护了干净输入，结果却一致：**D-U 带噪比干净高 2.3–3.2 BLEU**。噪声本身不带信息，这说明适配器学会了"检测到噪声 → 换成训练集的输出风格"，即**以噪声存在为条件的输出偏移**。要发生这种偏移，下游必须能从编码器输出里读出"有没有噪声"。

R9 直接切断这个通道：在编码器输出上放一个判别"带噪 / 干净"的小网络，通过梯度反转让编码器 LoRA 把这一信息抹掉。下游看不出噪声，就无法以噪声为条件切换风格；同时编码器被迫把带噪输入映射到干净输入的分布上，这正是"声学不变性"。

## 2. 文献
- **Domain-Adversarial Training of Neural Networks（DANN，Ganin et al., JMLR 2016；ICML 2015 版本）：** 梯度反转层 + 域判别器，学习域不变表示。
- **新意：** DANN 在语音里多用于口音、说话人或信道的域适应；这里的"域"是"同一句话有没有噪声"，用来**阻断以噪声为条件的输出偏移**（R5、R6 观察到的新现象），对象是被冻结大模型消费的语音大模型编码器。没有看到以此为目的的先例。

## 3. 方法（一个设置）
- **代码：** `voicecond/r9_enc_train.py`：数据迭代器同 R5 / R7 / R8（每步同一批 64 个位置的带噪版和干净版）；LoRA 位置同第十七波（音频编码器 32 层自注意力 q/k/v/out_proj，rank 16，alpha 32，b 初始化为 0，fp32；文本层冻结）。
- **翻译损失：** 与第十七波 ERM 相同，在带噪批（8 个环境，其中 2 个干净环境）上算逐句平均交叉熵。
- **对抗损失：** 对带噪环境的槽位（48 / 64），分别把带噪版和干净版过一次编码器（`get_audio_features`，带 LoRA，有梯度），取编码器输出的每一帧：
  - 判别器 D：两层 MLP（d → 256 → 1，GELU，fp32），逐帧预测"带噪 = 1 / 干净 = 0"，二元交叉熵；
  - 编码器输出先过梯度反转层，系数按 DANN 原文的默认调度 λ_p = 2 / (1 + exp(−10p)) − 1，p = 步数 / 总步数（从 0 升到约 1）；
  - 总损失 = 翻译 CE + 对抗 BCE（权重 1；对抗项按带噪槽位数在全局批量里平均）。
- D 与 LoRA 用同一个 AdamW（lr 1e-4，betas (0.9, 0.999)，wd 0，余弦到 0）。其余（8 个环境、sha1 键、2300 步、全局批量 64、种子 20261119、不裁剪）同第十七波。D 不保存进最终模型。
- **卡：** 1、2、3、7（R5 交卡后），world 4，每 rank 16 条，微批量 16（失败则 8）。
- **记录（只记录）：** 每步判别器的逐帧准确率、BCE、λ、CE。
- **最终系统：** r9_wise05，WiSE α = 0.5（alpha 减半为 16），`wave17_merge.py`（不改）合并。
