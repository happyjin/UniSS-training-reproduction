## 端到端训练预登记（2026-11-19 14:15 布拉格，写于任何训练数字之前；只跑这一个设置，不扫参）

用户："开始，后四卡可以训练"。预检 A 通过后按判定进入端到端训练。

### 模型
- 编码器：从 C 初始化（`eval_outputs/mist_w3po_v1/voicecond_idea1/m2/ctrl/encoder.pt` 的 speaker_encoder、perceiver_sampler、project_in），对每个 2 s 窗口（平铺到 6 s，与预检 A 相同）输出窗口均值 u_k ∈ R^192（提示空间）。BN / dropout 用 eval 模式（与 Idea 1/2 训练器相同）。
- 精度头 h：小 MLP，LayerNorm(320) → Linear(320, 128) → GELU → Linear(128, 192)。输入为 perceiver 输出（32×128）在 32 个 latent 上平均得到的 128 维向量（stop-gradient），拼接 u_k（u_k 不截断梯度，按字面设定）。输出 α_k ∈ R^192（逐维对数精度调制）。最后一层权重和偏置初始化为 0，所以第 0 步时模型严格等于预检 A 的 C_post。
- 窗口精度：Λ_k = π_k · D_k^{1/2} G D_k^{1/2}，D_k = diag(exp(α_k))，G = inv(R_C · L/hop)，R_C 用预检 A 的 pilot 估计（`idea6_precheckA/R_C.npz`），固定不训练。
- 后验均值：(Σ0⁻¹ + Σ_k Λ_k)⁻¹ (Σ0⁻¹(μ0 + b_M) + Σ_k Λ_k u_k)，先验取自 full.npz（sha1 25aaf6cd）。闭式、全程可微；求解用 fp64，编码器 fp32。

### 数据
- 只用 Idea 2 的 train 640 条流（开放数据），不读 dev / test。u* 为 Idea 2 的干净参考（`load_refs()`，最新版本）。
- 单元 = (流, 真实说话人, `slot_for_speaker` 给出的槽位)。t 从 {2, 4, 8, 15, 30, 60} s（该说话人的语音时长）均匀抽取；单元达不到 t 则跳过。实现为拒绝抽样：均匀抽单元、均匀抽 t，不合格就重抽，等价于在合格的 (单元, t) 对上均匀抽样。
- 窗口：与 run_stream 相同的因果协议（t 对应的流时刻 tt，end + 1.04 s ≤ tt 的本槽位 π > 0 窗口）。没有任何可用窗口的 (单元, t) 也重抽（这种对的后验恒等于先验，没有梯度）——实现细节。
- 近似：可用窗口超过 48 个时均匀无放回抽 48 个，并把它们的 π 乘以 n_total/48，保持后验精度的总量级；dev 评测不做此抽样，用全部窗口。
- 抽样随机数由 (seed, step, rank) 确定。

### 损失
- L = ‖后验均值 − u*‖² + 0.1 · mean_k ‖u_k − u*‖²（第二项是窗口锚，对本次使用的窗口取不加权平均，防止编码器漂移）；batch 内对单元取平均。

### 优化
- 4 卡 DDP（卡 4–7，梯度手动 all-reduce），每卡 16 个单元/步（全局 64），3000 步。
- AdamW（weight decay 0）：编码器 lr 2e-5，头 lr 1e-3；200 步预热后余弦衰减到 0；梯度裁剪 1.0（按参数组：编码器、头分别裁剪——Idea 2 e2e 的经验，全局裁剪会让大梯度组把小梯度组压到 Adam eps 以下）；fp32；种子 20261119。
- 关闭 cuDNN SDPA 后端（`torch.backends.cuda.enable_cudnn_sdp(False)`）；非有限步保护：梯度或损失非有限则跳过更新，连续 10 步非有限则中止。
- 检查点（编码器 + 头 + 优化器）：第 0 步（只用于初始等价检查）、每 500 步、第 3000 步。

### dev 检查（只评第 3000 步的最终检查点，不做检查点选择）
- 与预检 A 完全相同的 dev 协议和单元（dev 80 条流，249 个单元），方法 E2E_post（用训练后的编码器和头重算全部 dev 窗口的 u_k、α_k，再走上面的闭式后验）。
- 门槛：60 s 时 E2E_post 相对 C_post 的配对中位数差，相对量 ≤ −10%，且按流聚类 bootstrap（2000 次，seed 20261119）CI 上界 < 0；8 s 时 E2E_post − C_post 的配对中位数差 ≤ 0。
- 附带报告：E2E_post 相对 I2_full、C_first8；α 的统计（均值、分布）；单窗口误差（训练后编码器的 u_k 对 C 与冻结编码器）。
- 训练中间的检查点（500…2500 步）在训练结束后按同一协议评测，只做记录，不参与选择。
- 实现前检查：单卡约 20 步冒烟；用第 0 步检查点在 2–3 条 dev 流上算 E2E_post，必须与预检 A 的 C_post 误差一致到 1e-4。
