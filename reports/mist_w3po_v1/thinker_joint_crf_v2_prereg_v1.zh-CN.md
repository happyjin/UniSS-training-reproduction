## 0. 为什么还值得做（以及上界在哪里）

- VE1rl + PL-EM 的每条流语音 LAAL 3.756 s，单元终点分解里模型滞后 0.56 s、检测器等待 0.76 s、排队 0.12 s、最后一块 1.81 s。VE1 训练末 500 步的后验期望（文本时间线）0.838 s·词 / 词，而它的证据标签路径只有 0.602：**VE1 实际写得比自己的标签晚**，后验在格 [e, e+1] 里有约 24% 的词放在 e+1。
- VE1 的目标里没有任何延迟项（λ ≡ 0）。J1-v2 给它加一个**语音时间线上**的期望延迟约束：后验只能在"语音期望不超过预算"的写出计划里重新分配质量。语音时间线比文本时间线多出每块开销（截距 c_v ≈ 0.34 s）和同一条流的积压，所以在同样的期望下，它偏好"早写、但不碎"的计划。
- **上界照实写**：只改分组的收益上界约 0.1 s；所以 J1-v2 能带来的语音 LAAL 下降主要来自"写得更早"，块势只决定"早写的同时少拆块"。如果 PC4 的描述项显示语音势在同样延迟下并不减少块数（原 J1 的诊断就是这样），那么 J1-v2 实质上就是"VE1 + 一个延迟预算"，报告时照此表述。

## 1. 设定（唯一）

**名称**：J1-v2。`train_crf_sft --objective joint_speech --lw-mode v2p --js-budget shift`（`--js-budget` 是新参数，只做加法；默认 `t1` 是原 J1 / T3 的规则，逐位不变）。

### 1.1 与 VE1 相同的部分
- 数据 `crf/sched_t5_merge3_w10_v1`（T5 证据时刻规则，merge3 粒度，每块约 6 词，1.0 s 读 + 窗口终点）。
- 格 v2p：每块写出读 ∈ {e_i, e_i + 1}，集合状态链、读内顺序隐变量、τ = 0.5、M 步（`set_coefs`，q 不回传梯度）。
- DART：VE1 的清单 `crf/ve1_dart_merge3_w10_v1`（模式 v2p）。
- 配方：`run_crf_v2p.sh` 的全部参数（3000 步、约 64 读行 / 步、学习率 1e-4 → 1e-5 余弦、warm-up 50、v8 merged 初始化、LoRA r32 / α64 + 投影器 + 259 个新 token 行、`--final-read-full-post 1 --feat-per-row 1 --fast-moe-bwd 1 --prefetch 1 --empty-cache 0 --tok-budget 32000 --mem-cap-gib 120`），训练种子 20261109，4 卡，只评 step_03000。

### 1.2 联合链（原 J1 §1.2–1.4 原样，格换成 v2p）
- 隐变量：写出计划（= 每个说话人的块分段）、读内顺序、每个非空块的 talker 语速类 v ∈ {0, +2}。
- 块势：φ_{k,r} = log π(v | bin(b′_k)) − λ l_{k,r}，l = Σ_{i∈B} W_i (t_r − τ_i) + W_B b′_k + (W_B + 1)/2 · D(B, v)（秒 × 词）。
- 时长 D(B, v) = a_v · chars(B) + c_v，用 T3 已拟合的 `crf/t3_talker_model_v1.json`，**不重拟**（a_0 = 56.1 ms/字符、c_0 = 336 ms；a_2 = 54.2、c_2 = 345）。
- 积压：每条流（每个说话人）一条，确定性转移，80 ms 网格，上限 8 s。**跨流排队仍不进势函数**（与原 J1 相同，主指标是每条流）。
- 精确推断：增广链（集合状态 × 积压向量）的前向-后向；每读状态数超过 4096 的窗口加粗网格（仍精确），计数报告。
- λ = 0 时，因为 Σ_v π(v | ·) = 1，联合后验的 Thinker 边缘**就是 VE1 的后验**。所以"基线"= VE1 的目标，J1-v2 与 VE1 只差 λ 的约束。

### 1.3 新的预算（唯一改动）
每个优化步，在本步的全部窗口 w 上：

T = max( Σ_w E_{q₀,w}[l] − δ · Σ_w W_w ,  Σ_w E_{q₀,w}[l | e 路径] )，**δ = 0.134 s / 词**

- q₀：λ = 0 的联合后验（Thinker 边缘 = VE1 的后验），l 在语音时间线上算；W_w 是窗口的总词数。
- E_{q₀}[l | e 路径]：把 Thinker 限制在证据标签路径（每块都在 e_i 写出，格的 0 号状态），语速类按 π，λ = 0 时的语音期望。
- λ* ≥ 0 使 Σ_w E_{q_λ*,w}[l] = T；Σ E₀ ≤ T 时不绑定，λ* = 0。求解器与 T2 / J1 相同（从 1 起加倍定界，上限 1e3 并标记，50 次二分）。
- **含义**：每一步要求后验的语音期望比 VE1 的后验低 δ 秒 / 词，但不要求比"全部按证据标签写出"更早（下限保护：标签路径是可行的，所以 T 总可达到）。
- **δ 为什么取 0.134（来自数据，只取这一个值）**：
  1. 登记的延迟线是"每条流语音 LAAL < VE1 的 3.756 s"。VE1 与 VE1-s2 两个训练种子之间，每条流语音 LAAL 差 0.134 s（3.756 vs 3.622）。比这更小的位移和种子波动分不开，所以取这个值作为要求的最小位移。
  2. 训练格上的 l / 词与评测的每条流语音 LAAL 是同一种量（每个词"说完的时刻 − 源端终点"的平均），原 J1 的 PC2 显示同一时长与积压模型重算的每条流语音 LAAL 与实际相差 −0.06 / −0.04 s、单元 r 0.99。照实说明：这只说明时间线模型可信，训练格上的期望位移与解码后的 LAAL 位移之间没有一一对应，δ 是量级上的选择。
  3. 原 J1 结果节建议过"基线语音期望的 90%"。按 VE1 末 500 步的数字估计，训练末期后验距标签路径只有约 0.24 s·词 / 词（文本时间线），10% 的语音期望大约就是全部余量，λ 会顶到上限、后验塌到标签路径（T5 式的提前，已知掉分）。所以不用比例，用绝对位移 δ，并加标签路径下限。

### 1.4 推理
- Thinker：照常逐 token 流式解码，1.0 s 一读，`decode_crf_ckpt_finalpost --final-read-post close_detect`，其余同 A′ / VE1。
- talker：读级块输入 + PL-EM（现在的默认）。talker 不训练。

## 2. "端到端"到底有多端到端（新意评估，怎样照实表述）

J1-v2 不是端到端的 S2ST 训练。被训练的只有 Thinker（文本策略）；talker 在训练中被一个**冻结的、拟合出来的播放模型**代替：每个语速类两参数的线性时长模型（a_v · 字符数 + c_v）加上每条流的确定性积压，参数从 A′ 的 PL-EM 候选上一次性拟合，之后不再更新；没有任何梯度流进 talker，也没有梯度经过 talker 的波形或时长回到 Thinker——语音时间线只通过后验 q 和对偶乘子 λ* 决定 Thinker 的交叉熵权重（EM 式），本身不可微也不需要可微。推理时系统仍是级联的：Thinker 写完一块，talker 再合成，两者之间没有共享的状态或联合解码。因此最准确的说法是"**语音时间线感知的写出计划学习**"：在训练时对 Thinker 的写出计划和 talker 的播放（语速类、每块开销、同流积压）做精确的联合推断，用后验正则（Ganchev et al., JMLR 2010）把期望的**语音**延迟约束在一个预算内。可以主张的新意只限于：(1) 输出侧的 TTS 块边界作为隐变量；(2) 块势是带每块开销和离散积压状态的播放队列延迟，在增广链上精确求和；(3) 多说话人、每条流各自播放；(4) 用对偶求解的语音延迟预算做后验正则的 EM。**不能**说"首个按语音延迟训练提交策略"（Seed LiveInterpret 2.0 的 RL 奖励含语音时长，Hibiki 用对齐感知的 TTS 构造数据），也不能说"联合训练 Thinker 和 talker"。写作时把 talker 播放模型的拟合误差（PC2）和"只改分组的上界约 0.1 s"一并报告。
