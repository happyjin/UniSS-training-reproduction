## 5. 两个正在验证的方法

### 5.1 w3dia2（`--mode w3dia2 --who-sc 0.5 --who-rbc 0`）
what / when 同 w3dia（z(cpBLEU)，无延迟项）；who token = z(cpBLEU) + 0.5 × 组内归一化的逐段说话人正确性（noC4 路径，π* 与训练集参考标签）
+ λ_rbc × RBC（=0）。动机：w3dia 的路由有效（召回 / collapse 改善）但 RBC who 模仿因果 diarizer 的错误、约 40% 组 who 优势全零，错标变差。
v8 起步、配置同 Y，50 步。训练中 ACR_who 约 0.06–0.1（w3dia 0.36–0.44）。单测 `rl/test_w3dia2.py`。
目标：错标 ≤ dia 50（2.45%），保留 w3dia 召回 / collapse 收益，文本 / 语音不低于 dia 50；对照 dia 50、w3dia 50。

### 5.2 EA-GRPO（`--mode eagrpo --lam-ev 6.31 --ev-norm center --ev-clip 1.0 --ev-clip-scaled --kl-cap 10`，β 0.1）
- 每个参考单元 u 是 G 条 rollout 共享的事件。每单元每 rollout：q = SQ_u、c = u 的段的说话人正确率（只在覆盖者上）、m = 1[覆盖]；
  **center**：e = x − mean_g（x ∈ [0, 1]，不除 std——std 除法正是 W³PO 把微小差异放大的原因）；spurious / 重复段项 = −(数/|U| − 均值)。
- 路由：u 的段 what ← e(q)、who ← e(c)、when（段起始 token、提交该段那次读的 <wait>）← e(q)；漏掉 u 时读时刻在 [u 结束, +2 s] 的 <wait> ← e(m)；
  spurious / 重复段的 what、when ← 该项。无延迟奖励。E(t) 截断到 [−1, 1]，再 × λ_ev，再截断到 ±√(G−1)（=2.65，骨干 |z| 的上界）。
- 优势 = z(cpBLEU)（与 dia 相同，所有 token）+ 上述事件项；**损失与 dia 完全相同**（token 级、单一归一化，不是 W3 模式），λ_ev = 0 与 dia 逐位相同。
- λ_ev = 6.31 来自预登记的唯一标定规则：E ≠ 0 token 上 mean|λE| = 0.5 × mean|z|（核查时 λ = 1 下该比值只有 0.079，运行会与 dia 不可分）。
- CPU 预检（`rl/precheck_eagrpo.py` → `reports/mist_w3po_v1/precheck_eagrpo.json`；2901 个 dev 窗口组，组 = 8 个已有保护版解码）：
  corr(E_when, 提交提前量) +0.010；corr(E_when, 段数) −0.264；符号一致 95.5%；λ = 1 时 mean|E|/mean|z| 0.053（全部 token）；
  E ≠ 0 token 占 67.2%（when 25.6%、who 52.1%、what 76.4%）；λ 6.31 + 缩放截断后：命中截断 1.17%（E≠0 的 1.74%），
  E ≠ 0 token 上 mean|λE|/mean|z| = 0.43（≤1 s 单元 0.81）。
- 单测 `rl/test_eagrpo.py`（参数：pre-eagrpo advantage.py、第一版 eagrpo advantage.py、加缩放截断前的 advantage.py、hyp、windows）：
  旧模式逐位不变；λ 0 == dia；std 路径 == 第一版；无 `--ev-clip-scaled` 时 == 加开关前；缩放截断公式；手工组（漏插话、错标插话）。
  旧版本文件可用 `git show <commit>:experiments/mist_w3po_v1/rl/advantage.py` 取（c3a92f52 第一版、ff0f52d8 center 版）。
  测试需要可见 GPU 才能 import 处理器（不建 CUDA context）：`CUDA_VISIBLE_DEVICES=0 python -m …`，已验证 nvidia-smi 无该进程。
  测试 hyp：`eval_outputs/mist_w3po_v1/decode/dagger_v8_online14/hyp_s0.jsonl`；windows：`eval_outputs/mist_w3po_v1/data/windows_zh2en_v1/windows_train_diar.jsonl`。
