# E10 v3 预注册：LiveInterpret 按 baseline B 的数据、超参和训练部位重训

写于 2026-11-21（布拉格时间），在任何 v3 解码输出产生之前。用户当天的决定：用 0–3 号卡训练；数据与 B 一致；只要语音能正常合成、比上一版好，就把结果加到现有电竞试听页上对比。

## 1. 为什么要 v3

上一版 E10（`e10_thinker_v2/checkpoint-1670`）的诊断见 `LOG.zh-CN.md` 2026-11-21 的三条记录。要点：

- **读写策略被训坏。** 我在转换数据时，把 B 的离线行和单说话人行展开成了“一直 wait、最后一次写完”的轨迹，指令还和流式行相同。结果在 AMI dev ≥10 s 的窗口上，只写一次的比例从 0.07 升到 0.55。
- **训练量不足。** 学习率比 B 低 8 倍，步数少 3.6 倍，也没有 O2 阶段。
- **说话人信息的注入方式与 B 不同。** 上一版是延迟后加到音频帧上，结果多说话人窗口只有 27% 输出多个标签，B 是 99%。

## 2. v3 设定（与 B 对齐）

| 项 | B | v3 |
|---|---|---|
| 数据 | O2：`e2e_gstar_bidir_v2`；联合：`e2e_gstar_stream_bidir_v2` | 同样两份文件。B 一个窗口的读取行对应一条流式记录；离线行和单说话人行每行一条记录。O2 67,682 条；联合 100,507 条不重复记录，按方向平衡到 112,308 条 |
| 阶段 | O2 2,000 步 × 64，然后联合 6,000 步 × 64 | O2 2,000 步 × 64；联合 6,000 步 × 24（一条流式记录约等于 B 的 4.5 行，每批 24 条约等于 B 的 64 行；约 1.4 遍不重复数据，B 是 1.34 遍） |
| 起点 | O2 从原始 Thinker 开始，联合阶段从合并后的 O2 开始 | S4 + 同事的 S5 adapter（合并）。联合阶段再合并 O2 adapter，并接手它的说话人投影和标签行 |
| 训练部位 | LoRA r32/α64，只加在注意力 q/k/v/o；新 token 行；`sd_proj` | LoRA r32/α64，只加在 Thinker 注意力上（全注意力层的 q/k/v/o，Gated DeltaNet 层的 in_proj_qkv/in_proj_z/out_proj），不加在 MLP 上；8 个说话人标签行；B 的 SDProjector。音频编码器和 Talker 冻结 |
| 学习率 | 1e-4 → 1e-5 余弦，warm-up 50 / 100 步 | 相同，所有参数同一个学习率 |
| 说话人流 | 每 5 个音频 token 插一个说话人 token：`SDProjector(post)`，后验只用到 t − 1040 ms | 同样每 5 帧一个、作为独立位置。KV cache 不能回头修改已输入的位置，所以第 j 块的说话人 token 放在其后验可得的那一帧（5j+5+13）之后；离线记录放在本块之后 |
| 损失 | 文本（离线行本身不训练空输出） | 文本 + 读写决策，但读写决策只计算流式记录，离线和单说话人记录的决策 loss 屏蔽 |
| 解码 | 循环保护 k=6、maxp=12，预算 25 tok/s + 50 | 相同规则（`run_e10.py --mode e10v3`）。被截掉的 token 仍留在 Thinker 的 cache 里，但不输出 |
| checkpoint | 取最后一步 | 相同，只保存 adapter |

**与 B 的实现差异（已核对，有意为之）：** 说话人 token 位置上的输入是“`<|pause:1|>` 这个 token 自身的 embedding + 投影输出”，而不是 B 的纯投影输出。原因是投影最后一层零初始化时，纯零向量进入 RMSNorm，烟雾测试中投影层梯度范数达到 2.4e16，经全局梯度裁剪后其他参数几乎不更新。改成上述形式后，梯度范数为：投影 94、标签行 34、LoRA 4.9。

**无法对齐的部分：** 没有时间 token；读写节奏为 0.64 s；Talker 与 B 不同；模型规模 4B 对 30B-A3B。

## 3. 验收（用户标准）

在现有试听页的 6 段电竞音频（gz01–03 中→英，ge01/02/04 英→中，各 5 分钟，第一个 TTS 种子）上，与上一版 E10 比较：

1. **语音能正常合成：** 没有大段拖长或重复的语音，错误窗口 ≤ 上一版。
2. **比上一版好：** `compare_demo_arms.py` 中，静音比例、只写一次的窗口占比和相邻重复片段占比都低于上一版；说话人切换次数接近 B；文本 BLEU（对照页面上自动生成的参考译文）不低于上一版。

通过就把 v3 作为第一个版本加到试听页上，同时保留上一版 E10 和 B。不通过就停下来汇报，不调参重训。

不做 AMI dev/test 评测（用户此前已停止 E10 的测评）。
