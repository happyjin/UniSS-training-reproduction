### S0-4 跨窗口上下文的实现
- 上下文 = 同一会议上一个窗口最后 N 段已提交译文，格式 `" Already translated just before this audio (do not translate it
  again): <|spk k|>text ..."`，放在用户轮指令之后；空上下文时提示与 v8 完全相同（代码中断言）。
- 偏离：上一个窗口的"最终读取"在真实系统里由关窗检测触发，最坏情况（20 s 截断窗）比下一个窗口第一次读取晚 ≤0.24 s；
  解码器用上一个窗口的完整输出作上下文，即这 ≤0.24 s 的超前。影响极小，如实记录。

**新方法：Event-Anchored GRPO（EA-GRPO，`--mode eagrpo`，新增，其他模式逐位不变）**
- 动机：dia 的唯一奖励是窗口级 z(cpBLEU)。一个 0.4 s 插话在窗口 BLEU 里约占 1%，漏掉或标错说话人几乎不改变优势，
  这正是 ov / 短插话召回 / 错标三项"训练后几乎不动"的原因。同一窗口的 G 条 rollout 共享同一段音频，STAMP 已把每条 rollout
  的段对齐到参考单元（unit_of、π*），所以可以**以每个参考话语（事件）为锚，在 G 条 rollout 之间做组相对基线**，
  不需要额外采样，再把每个事件的优势路由到造成它的 token。
- 优势：A(g, t) = z_g(cpBLEU)（与 dia 完全相同，作为骨干，保留 dia 的收益）+ λ_ev · E(t)，λ_ev = 1.0（单值，不扫）。
  每个单元 u、每条 rollout g：q = SQ_u（说话人因子取 1，漏掉为 0）；c = u 的段的说话人正确率 1[π*(spk) = u.spk]（只在覆盖 u 的
  rollout 上定义）；m = 1[覆盖]。每个事件在组内单独归一化 e = (x − mean_g) / max(std_g, FLOOR)，组内为常数时跳过——
  于是每个事件权重相同、与长度无关。
  路由：u 的段的 what token ← e(q)；who token ← e(c)；when token ← e(q)（段的起始 token；提交 u 的段的那次读的 <wait>）；
  u 被漏掉时，读时刻在 [u 结束, u 结束 + 2 s]（没有则到窗口末）的 <wait> ← e(m)（漏掉者为负）；同一 <wait> 上多个事件取平均。
  无匹配段（spurious）与重复段（≥ 一半 4-gram 已出现过，或短段文本重复）的 what / when token ← −z(该 rollout 的这类段数)，
  防止靠多生成来骗覆盖。**没有任何延迟奖励**（W³PO 的漂移来自延迟通道）。
- 实现选择：损失与 dia 相同（token 级 PPO，段内 GSPO 比率，不用 W³ 的投影比率），事件信用按 token 的 when / who / what 类别路由，
  所以 λ_ev = 0 与 dia 逐位相同，对 dia 50 的比较只隔离出事件项。不用锚点（同 dia，免去在线锚点开销）。
  训练日志新增：有非零事件优势的单元比例 `ev_units_nz_frac`、各通道平均 |E|（`ev_abs_when/who/what`）、
  ≤1 s 单元在 rollout 中的覆盖率 `ev_short_cov`。

### 2026-11-09 01:07 UTC（布拉格 02:07）：新方法方案——ECF-GRPO（事件触发的反事实"立即输出"分支）；文献、预检、预登记设置

- Dr. GRPO（arXiv 2503.20783）：组内 std 归一化把低方差组的微小差异放大——解释 W³PO 漂移；
- Rewarding the Unlikely（arXiv 2506.02355）、负样本强化（NeurIPS 2025, arXiv 2506.01347）：GRPO 只锐化已有高概率行为，罕见正确行为得不到强化；
- ExGRPO（ICLR 2026, arXiv 2510.02245）、Buffer Matters（ICLR 2026, arXiv 2602.20722）：回放罕见成功；
- C3（arXiv 2603.06859）：在决策点替换一条消息再续跑到终局，得到无偏反事实信用；CCPO（arXiv 2603.21563）：移除某 agent 的反事实边际贡献；

**方法（`--ecf-branches K`，只在 `--mode dia` 下生效；默认 0 = 与 dia 逐位相同，不消耗随机数）**
- 每步正常 rollout（G = 8）后，用 STAMP 找出每个成员漏掉的 ≤1 s 参考单元 u；分支读 r = u 结束后的第一个非最终读、且该成员在 r 的块以 <wait> 结束。
  每窗口最多 K 个分支（不同成员，种子化随机选），每个成员最多 1 个。
- **反事实分支**：复制该成员在读 r 之前的全部状态（已提交 token、ctx），在读 r 上禁止 <wait>（引擎已有的 `bar_wait`，等价于"现在把听到的都说出来"），
  之后的读照常采样到窗口末。分支只用于估值，**分支自己的 token 不进损失**（无离策略问题）。
- **信用**：Δ = q(父) − q(分支)，q = seq_cpBLEU（与 dia 的奖励相同，没有任何新奖励、没有说话人项、没有延迟项）；
  父成员在读 r 的那个 <wait> token 的优势 = z(q)（dia 骨干）+ λ·clip(Δ / σ_q, ±√(G−1))，σ_q = 组内 q 的 std（下限 FLOOR，同 z）。
  分支更好 → 父的"继续等"被压低；分支更差 → 父的等待被加强（不会一味鼓励多输出）。
- **新颖性**：C3 / CCPO 的反事实续跑用于 agent 消息；GiGPO / SPO 的步级信用依赖 rollout 自然经过相同状态；回放类方法依赖至少一次自然命中。
  ECF 的分支点由**源流上的事件**（训练集参考时间轴，只用来决定在哪里分支，从不作为奖励或模仿目标）决定，反事实动作是流式策略的 READ→WRITE 翻转，
  信用只落在该策略自己采样的控制 token 上；它能在 G 条 rollout 全部漏掉某插话时（漏掉中的 66.6%）产生信号——dia / EA-GRPO / w3dia(2) 都做不到。

**文献（6 次检索）**
- OPSD / Self-Distilled Reasoner（arXiv 2601.18734）、π-Distill（arXiv 2602.04942）：同一模型带特权信息当教师，在学生自己的 rollout 上做逐 token 蒸馏；
- RLSD / Self-Distilled RLVR（arXiv 2604.03128，NeurIPS 2026）：教师−学生 log 比只决定 token 信用的**大小**，符号仍由组相对奖励决定，w = exp(sign(A)·Δ)、截断；SDPG（arXiv 2606.04036）、MOPD（NeMo RL）同类；
- Learning by Cheating（Chen et al., CoRL 2019）与其后续（如 arXiv 2412.09149、2608.25936）：特权教师的信息若学生在测试时无法推断（不可实现），直接模仿会教出"作弊"行为；
- Future-Guided Incremental Transformer（Zhang et al., AAAI 2021）：同传里用整句教师给 wait-k 学生做 KD（监督式、隐状态蒸馏，非 on-policy、非信用分配）；
- 同传 RL（HPO arXiv 2604.21045、Hibiki-Zero arXiv 2602.11072、Seed LiveInterpret 2.0 arXiv 2507.17527）只用序列级质量 / 延迟奖励，没有特权教师或 token 级事后信用。
**方法 HiCA（Hindsight Credit Allocation，`--hica-ms Δ`，只在 `--mode dia` 下；默认 0 = 与 dia 逐位相同）**
- 教师 = **冻结的 v8 自己，但多听 Δ 毫秒源音频**（读 r 的音频截到 min(t_r+Δ, 窗口末)，已提交前缀和本块 token 都与学生相同；这正是"如果当时再等 Δ 再写"的自己，
  其音频编码正好是 rollout 里读 t_r+Δ 的缓存，不需重新编码）。学生侧用同一冻结模型在 t_r 的概率，所以 Δ_k = log π_ref(y_k | 音频≤t+Δ) − log π_ref(y_k | 音频≤t)，
  是"事后信息让这个 token 变得更可信 / 更不可信"的平稳量，不随训练漂移。
- 信用：dia 的序列优势 A = z(seq_cpBLEU) 不变，只在 token 间重新分配：Â_k = A · exp(clip(sign(A)·Δ_k, ±1))。
  好 rollout 里被事后证实的 token 多拿信用、被事后否定的少拿；坏 rollout 里被事后否定的 token 多背锅、被证实的少背。
- **可实现性**（Learning-by-Cheating 的教训）：事后知道"后面还有话"会让教师偏向"现在就说"，这在测试时不可实现 → **when 决策不重分配**（纯 when token 权重 1）；
  说话人 token 用 8 路投影分布的 Δ（在 when 位置开新段的说话人 token 只比较"选哪个说话人"，剔除"现在说不说"），内容 token 用全词表 Δ。
  没有新奖励，没有说话人奖励，没有语音项；符号永远来自 seq_cpBLEU，所以不会教出组奖励之外的行为。
- 指向：漏标 / 错标的跷跷板——覆盖了插话但标错说话人的坏 rollout 里，事后否定的是说话人 token 而不是内容，于是"说出插话"被保留、"标错"被惩罚（即交接所说的"拆分正确"联合事件，但不另设奖励）。
- **新颖性**：OPSD / RLSD 的特权信息是参考答案；这里特权信息是**源流的未来**，教师是策略自己的"延迟版本"，并按可实现性把读写决策排除在外——这是流式 / 同传 RL 里没有的（以上检索未见）。
