# 鲁棒线 v5：失败原因总结、对 v4 方案的严格审核、按"问题 → 机制"重提方案（2026-11-21 上午，布拉格）

只是分析，没有启动。数字都是测试或 dev 上的点估计。

## 1. 现在还剩下的问题（用数据说话）

### 1.1 Thinker：可救的空间有多大
- **上限：** 干净孪生输入的分数，减去带噪输入的分数（底座，文本 BLEU）：

| 测试集 | 英→中 | 中→英 |
|---|---|---|
| RealSI | +0.15（噪声不伤） | −1.65 |
| OBSI id2 | −2.39 | −1.34 |
| OBSI ood1 | −2.12 | −1.82 |

  任何抗噪方法在 Thinker 上能收回的上限，大约就是 0–2.4 BLEU。
- 测试上 Thinker 适配带来的 +2～+4，大部分是风格和长度校准，不是抗噪（v3 发现 B）。

### 1.2 Talker：V1 之后还剩什么
测试，中位数：

| 单元 | 说话人相似度：B 干净 → B 带噪 → V1 带噪 | 相似度损失收回 | PESQ：B 干净 → V1 带噪 |
|---|---|---|---|
| 英→中 RealSI | 0.419 → 0.321 → 0.379 | 59% | 3.75 → 4.02 |
| 英→中 OBSI id2 | 0.450 → 0.371 → 0.414 | 54% | 3.24 → 3.73 |
| 中→英 RealSI | 0.458 → 0.364 → 0.376 | **13%** | 3.29 → 3.81 |
| 中→英 OBSI id2 | 0.500 → 0.426 → 0.442 | 22% | 3.20 → 3.57 |

- **音质已经解决：** V1 在带噪输入上的 PESQ 已经高于底座在干净输入上的 PESQ。
- **身份没有解决：** 带噪时说话人相似度掉 0.07–0.10，V1 只收回 13–59%，中→英最差。
- V1 在干净输入上还会降低相似度：中→英 RealSI 干净 0.458 → 0.440。
- 这与 Idea 7 的发现一致：V1 是 MMSE 回归（‖φ(y) − u*‖²），估计会向平均音色收缩，"干净但更像普通人"。

## 2. 为什么失败了这么多（R1–R11 及之前）
| 原因 | 涉及方案 | 教训 |
|---|---|---|
| F1 要找的效应太小：Thinker 的抗噪上限只有 0–2.4，和 300 句 dev 的随机波动同量级 | 几乎所有 Thinker 方案 | 先量上限，再设计方法 |
| F2 监督目标带着偏移：参考译文的风格（cos(τ_noisy, τ_clean) = 0.75） | ERM、R5、R6、R7、R11 | 约束只会把偏移挪地方，变成条件式偏移（R5、R6） |
| F3 目标太弱或太宽，而这本可以用廉价诊断提前发现 | R2（整句对比太容易）、R3（子空间秩 288/1280）、R7（选中的词元一部分来自数值抖动） | 每个新方案先做 CPU / 小规模的可证伪预检 |
| F4 工程：bf16 合并把差向量吃掉 17–48%（R1、R10）；实现不等价（R4） | R1、R10、R4 | 差向量类方法用不合并的适配器部署 |
| F5 机制换了，问题没换：一直在 Thinker 上找，而那里的空间最小 | 整体 | 转向剩余问题真实存在的地方（Talker 的身份） |

## 3. 对 v4 方案（N1–N4）的严格审核：建议全部撤回
- **N1（配对特征锚定）不 novel，而且属于蒸馏：** 用"冻结模型对干净输入的输出"作为目标、训练带噪输入，就是经典的平行数据 teacher-student 适配（Li et al., Interspeech 2017，"Large-Scale Domain Adaptation via Teacher-Student Learning"，用干净/带噪平行数据）。在特征层面做也是同一范式。这正是用户不接受的蒸馏。V1 本身也属于这一范式。
- **N2（结构对齐）：** 是关系型蒸馏（RKD，CVPR 2019）的变体，同样属于蒸馏。
- **N3（外科式）：** 只是在 N1 上选层，novelty 低。
- **N4（见证加权音色码）：** V1 之后音质已经没有问题，剩下的是身份；N4 只是在几个音色码之间做融合，不解决向平均收缩，预计无效。

## 4. 按"剩余问题 → 机制 → 文献 → 预检"重提的方案

### K1. 补完唯一部分有效的 Thinker 方案：任务向量差改为不合并部署（针对 F4）
- **问题：** R1 已经去掉了风格（干净不掉、长度比回到底座），但不变性只保住一部分，而且 bf16 合并误差有 17%。
- **机制：** τ_noisy − τ_clean 不合并进权重，以两个 LoRA 适配器的形式部署（+τ_noisy，−τ_clean），差在激活上逐层计算，不受 bf16 权重舍入的影响。
- **文献：** Task Arithmetic（ICLR 2023）。我们的贡献是"只差干扰条件"的两个任务向量相减；它会自动消除条件式偏移，因为两路学到的风格相同。
- **novelty：中高**，原则是新的。
- **会不会 work：** 风格去除已经验证过。不确定的是收回 bf16 误差后，不变性能恢复多少。
- **预检：** 不用训练，只跑推理约 30 min，直接在 D-U 和 (b) 上评。
- **补充（需要训练，一个设置）：** τ_noisy 的 8 个环境里有 2 个是干净的，会冲淡噪声分量。可以另训一个只用 6 个带噪环境的 τ_noisy′，4 卡约 2.5 h。

### K2. Talker 身份：把 MMSE 音色码搬回干净音色的分布（针对 1.2 的收缩）
- **问题：** V1 是后验均值估计，向平均音色收缩，所以身份收回不足，干净时还会降低相似度。
- **理论和文献：**
  - 失真–感知权衡（Blau & Michaeli, CVPR 2018）：MMSE 估计一定会偏离真实分布；
  - Wasserstein 空间中的失真–感知（Freirich et al., NeurIPS 2021）：最优的"感知"估计 = 后验均值，再经过一个从后验均值分布到真实分布的最优传输映射；在高斯近似下这个映射是闭式的仿射变换；
  - PMRF（ICLR 2025）：后验均值，再接一个 rectified flow。
- **机制（K2a，免训练）：** 在 voicecond 训练集上估计"V1 码"和"干净码"两个分布（高斯近似），算出闭式的 W2 最优传输仿射映射 T，部署时用 T(φ(y)) 代替 φ(y)。没有自由参数。
- **novelty：** 把 Freirich 等人的理论用于"带噪提示的音色克隆"，配合可检验的预测（身份收回提高、干净时不再掉），中等。
- **重要冲突：** voicecond 线的 Idea 7 计划过第 2 步"最优传输修正"。当时因为机制检验 M2 不通过而没做；但 M2 用的指标是 PESQ，而不是身份。所以 K2 和 voicecond 线有重叠，需要用户决定归哪篇论文。
- **预检（CPU，用现有输出，先做）：**
  1. V1 码在说话人之间的散布与干净码的散布之比（Idea 7 已有"被压扁"的定性结论，要量化）；
  2. 逐条的"收缩量"与"相似度损失"的相关。相关不显著就停。

### K3. Talker 身份的训练式修正：在 V1 的目标里加入身份可辨性（针对同一问题，需要训练）
- **机制：** V1 只最小化与干净码的距离。改为距离项 + 跨说话人的判别项（同一说话人的带噪码靠近其干净码，同时远离其他说话人的干净码，即 InfoNCE / AAM-softmax 式），直接抑制向平均收缩。
- **文献：** 说话人嵌入的判别式训练（AAM-softmax、GE2E），以及 DINO 说话人编码器（arXiv 2311.09770）。
- **novelty：中低**（组件常见），但直接针对测得的问题，work 的概率比 K2 高。
- **不是蒸馏：** 目标是干净码与说话人标签，和 V1 相同，用户之前接受过 V1。
- **与 voicecond 的冲突同 K2。**

## 5. 建议
1. 先做 K1 的推理部分（30 min）和 K2 的 CPU 预检。两者都不训练，可以证伪。
2. K1 若成立，再训 τ_noisy′（6 个带噪环境）。
3. Talker 身份（K2、K3）是剩余问题真实存在的地方，但与 voicecond 线重叠，归属需要用户决定。
4. 不再在 Thinker 上开新的约束类机制（F1、F2）。
