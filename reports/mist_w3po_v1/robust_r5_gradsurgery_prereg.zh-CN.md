# 鲁棒 R5：与干净梯度正交的配对梯度手术（Paired Clean-Orthogonal Gradient Surgery）预登记

2026-11-20 23:20 CET（布拉格）写，早于本方法的任何训练或评测数字。夜间执行者按用户授权（overnight-autonomy-20261119-robust，夜间迭代规则）设计并启动。约束：
- 训练只用同一批 UniST 数据（`eval_outputs/mist_w3po_v1/wave14/data`）；
- 不做蒸馏：目标仍是参考译文，没有教师模型，没有伪标签；不用 QABC 组件；一个模型做两个方向；
- 一个设置，不扫参；先看点估计，不做 bootstrap；
- dev 只用 D-U（`devU/data`，set u）+ bench_dev (b)；不碰 RealSI / OBSI / ACL / AMI / AliMeeting / OOD-3。

## 1. 动机（v3 主线）
ERM 的 LoRA 更新同时含"对声学干扰的不变性"和"输出分布的偏移"（参考风格、领域知识覆盖）。R1 在训练结束后用两个任务向量相减 τ_noisy − τ_clean 去掉偏移分量，但两条优化轨迹在非线性的损失面上并不对齐，差向量不一定只剩不变性。

R5 把同一个想法搬到**每一步**：同一批样本的"带噪梯度" g_n 里，凡是与"同一批样本不加噪时的梯度" g_c 同方向的分量，都是不论有没有噪声都会学的东西（风格、长度、知识覆盖），把它投影掉；只沿与 g_c 正交的方向更新。一阶近似下，这样的更新**不改变干净输入上的训练损失**，也就是不去拟合参考译文的风格，只降低"带噪比干净多出来的那部分损失"。

## 2. 文献
- **Gradient Surgery for Multi-Task Learning（PCGrad，Yu et al., NeurIPS 2020）：** 两个任务梯度冲突时，把一个投影到另一个的法平面上。
- **Orthogonal Gradient Descent（OGD，Farajtabar et al., AISTATS 2020）：** 更新与需要保持的输出的梯度正交，一阶意义下不改变它们。
- 与 R1 的关系：Task Arithmetic（Ilharco et al., ICLR 2023）在参数空间做事后减法；R5 是它的逐步、一阶版本。

**新意：** PCGrad / OGD 处理的是不同任务或旧任务；这里的两个"任务"是**同一批样本的干净版和带噪版**，投影对象是"干净梯度"本身（总是投影，而不只是冲突时），目的是把"声学不变性"从"目标分布拟合"中分离出来。没有看到用配对干净/带噪梯度做手术来实现"只学不变性"的先例。

## 3. 方法（一个设置）
- **代码：** `voicecond/r5_train.py`，是 `r1_train.py`（即 `wave14_train.py`）的副本，只改一处：每步两次前向-反向。
  1. **带噪批：** 与第十四波 τ_noisy 完全相同的 64 个样本（同一 sha1 行键、同一混噪键；8 个环境里 2 个干净环境照常是干净样本），得到 g_n（跨 rank 平均）；
  2. **干净批：** 同一步同 64 行，全部不加噪（等于 R1 的 τ_clean 那一步的批），得到 g_c（跨 rank 平均）；
  3. **手术：** 把全部 LoRA 张量拉平成一个向量，g = g_n − (⟨g_n, g_c⟩ / ‖g_c‖²) · g_c（总是投影，不只冲突时；‖g_c‖ = 0 时 g = g_n）；
  4. g 交给 AdamW。
- 其余与第十四波逐项相同：LoRA 在 48 个文本层的 q/k/v/o，rank 16，alpha 32，b 初始化为 0，fp32；AdamW lr 1e-4，betas (0.9, 0.999)，wd 0，余弦到 0，2300 步，全局批量 64，种子 20261119，不裁剪梯度。
- **已知的近似：** Adam 的逐坐标缩放会破坏严格正交（PCGrad 在实践中也是把手术后的梯度交给 Adam），一阶保证只对梯度本身成立。写明，不另做处理。
- **卡：** 1、2、3、7（R1 交卡后），world 4，每个 rank 16 条，微批量 16（同 R1）。每步计算量约为 ERM 的 2 倍，预计约 6 s/步，约 3.8 h。
- **记录（只记录，不调参）：** 每步 cos(g_n, g_c)、‖g‖ / ‖g_n‖、两批各环境的 CE。
- **最终系统：** r5_wise05，WiSE α = 0.5（LoRA alpha 减半为 16），与 unist_wise05 同口径；用 `wave5_m_merge.py`（不改）合并进完整模型。

## 5. 判断规则（点估计，写定）
吸取 R2 的教训（D-U 与训练同域，ERM 在 D-U 干净上的提升本身就是风格偏移），"干净不退化"以**底座**为参照；与 ERM 的比较放在不同域的 (b) 上。对每个方向 × {u, b}（共 4 个单元）：
1. **不变性：** 差距（带噪 − 干净）不比底座差 0.3 以上（4 个单元都满足），且至少 2 个单元比底座好 0.3 以上；
2. **干净不退化：** 干净 BLEU ≥ 底座 − 0.3（4 个单元）；
3. **无输出偏移：** 干净、带噪平均的 |长度比 − 1| ≤ 底座 + 0.02，重复率 ≤ 底座 + 0.005（4 个单元）；
4. **延迟：** text LAAL ≤ 底座 + 0.1 s（8 个格子）；
5. **对 ERM（unist_wise05），只看 (b)：** 两个方向的 (b) 干净 BLEU ≥ ERM − 0.3，且差距 ≥ ERM − 0.3。
- 五条都满足记为"有效"；有效也先不跑测试，晨报里建议进入测试的方式（测试只跑一次，先补测试预登记变更）。另外报告 r5 对 r1。

### 原因分析
1. **训练统计显示投影后的更新在"牺牲干净"：** cos(g_n, g_c) 全程约 0.75，手术后梯度保留 ‖g_n‖ 的约 57%。训练批上干净版的平均 CE 从 0.86（前 100 步）升到 1.33（最后 100 步），带噪版从 0.74 到 0.79 基本不变。也就是说，与 g_c 正交的方向在 Adam 的逐坐标缩放下累积起来，系统性地抬高了干净损失（一阶正交性只对单步梯度成立，2300 步、Adam 预条件后不再成立）。
2. **偏移变成了"以噪声为条件"的：** D-U 带噪比干净高 2.3 / 3.2，与 R6 同样的现象。模型学会了区分带噪 / 干净输入，并只在带噪时输出训练集风格；不同域 (b) 干净明显下降、长度比变长，说明干净路径反而被推离了底座。
3. **与 R1 的对比：** 事后减法（R1）没有出现条件式偏移，干净 (b) 也不降；逐步投影（R5）反而两种偏移都有。说明"在优化过程中持续去掉干净方向"会把模型推向"区分噪声"的解，而不是"忽略噪声"的解。
- **结论：** R5 与 R6 从两种完全不同的机制（梯度空间 / 输入子空间）得到同一现象——只保护干净路径，风格拟合会转移到带噪路径上（条件式输出偏移）。这是 v3 主线的一个新发现，可以写进分析。下一步 R9（卡 1、2、3、7，04:29 CET 自动开始）用对抗判别器抹掉编码器输出里的"有无噪声"信息，直接切断条件式偏移所需的通道；R8（卡 0、6）从目标上限制带噪损失不低于干净损失。
