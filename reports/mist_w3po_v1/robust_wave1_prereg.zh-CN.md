依据：`robust_novel_ideas_v1.zh-CN.md`（第 2、5 节）。

## 共同规则
- **只用开源非测试数据**：CoVoST 2 的 train / validation，Idea 2 的 cvt dev 流；背景只用非留出部分（不在 `HELDOUT_BACKGROUNDS*.txt` 里）。不读 OpenBroadcast-SI test、OOD-3、电竞。
- **门槛只用真实输出指标**：输出语音的 PESQ（SQUIM）、ASR 转写 BLEU/WER、说话人相似度、时长 / LAAL。码误差不作判据。
- 每个方法只跑**一个**设置，不扫参；预检结果只决定是否进入下一步。
- Thinker = B 的 joint Thinker（joint_v8h6k merged_s06000），Talker = T1c（`--speed-policy fixed --history-ban 8`），音色正条件统一用 Idea 1 C（`voicecond_idea1/m2/ctrl/encoder.pt`），解码设置与 B 相同。

## K1：零噪声外推引导 Talker（Idea 1 Z + Idea 2 λ + Idea 5 背景锚 + 候选 A）
- **P1a 线性检验：** 约 200 个 cvt dev 条目。把说话人的干净提示与背景（该条目流的 bg.wav）按能量占比 σ ∈ {0, 0.25, 0.5, 0.75, 1} 混合，用 C 编码成音色 token。在同一段参考语义序列上做教师强制，取 Talker 每步 logit。
  - 对每步、每个词表维度，在 σ 上做一次线性拟合（以各 σ 下的均值为中心）。
  - 合并 R² ≥ 0.8 → 线性成立。同时报告二次项占比。
- **P1b 引导生成（无论 P1a 结果都跑，作为两个独立方法各一个设置）：** 约 120 个 cvt dev 条目，用带噪提示。
  - 臂 C：基线；
  - 臂 ZNE：l + w[l(g⁺) − l(g⁻)]，g⁻ 为该条目流的纯背景（bg.wav 片段，C 编码），w = σ⁺/(1 − σ⁺)；σ⁺ = (1 − λ̄)·ρ，λ̄ 为 Idea 2 λ 头在该说话人窗口上的均值，ρ 为 C 在 dev 上的码残差比（预先在 cvt dev 上算一次，固定）；
  - 臂 CFG1：同一负条件，w = 1。
  - 两个 TTS 种子。门槛（对臂 C）：PESQ 配对中位差 > 0 且 CI 下界 > 0；ASR WER 不变差（配对中位差 ≤ 0）；相似度中位差 ≥ −0.02；时长中位比在 [0.98, 1.02]。

## K2：背景对比解码 Thinker（Idea 2 λ + 候选 C）
- 数据：CoVoST 2 validation 的 en→zh 与 zh→en 各约 300 句。干净版 + 混入非留出背景的带噪版（SNR 按 OpenBroadcast-SI 的 BVR 分布抽样）；每句再配一段等长纯背景。
- **P2a：** 噪声损失 = 干净与带噪的文本 BLEU 差。英→中 < 1.0 BLEU → K2 停止。
- **P2b：** l + w[l(x) − l(x_bg)]，w = (1 − λ)/λ，λ 由 Idea 2 的 λ 头从该句窗口特征得到（截断到 w ≤ 3），只在模型认为合理的 token 上生效（自适应可信截断 0.1）。门槛：英→中收回 ≥ 40% 的噪声损失，中→英不降超过 0.2 BLEU。
- **附带：** Thinker logit 对 σ 的线性检验（同 P1a 的做法）。

## K3：话轮间隙在线自适应（Idea 5 背景锚 + 候选 D）
- 数据：同 K2 的带噪句子。模拟"同一背景先出现 3 s 纯背景间隙"。
- 做法：用间隙特征估计 Thinker 音频编码器输入层的偏移 δ = mean(间隙特征) − mean(训练静音特征)，对后续语音特征减去 δ（免训练，一个设置）。
- 门槛：带噪句子编码器特征到干净孪生特征的平均距离下降 ≥ 20%，且英→中文本 BLEU 不降。

## K4：与音色无关的语速钳制（候选 B）
- 数据：K1 的条目与音色条件。
- **P4a：** 在 Talker 中层（层数 = 总层数/2）隐状态上做线性探针预测 tokens/s（训练用 cvt train 条目，dev 上评估）。R² ≥ 0.5 → 有语速轴。
- **P4b：** 钳制 h ← h − (rᵀh − r̂)r，r̂ 取臂 B 原始提示下的预测值。门槛：不同音色条件之间的时长变异（变异系数）下降 ≥ 50%，ASR WER 不变差。

## K5：干净老师的可靠度信号（候选 E/F 的前提）
- 数据：同 K2。
- 每句计算 Thinker 在干净与带噪输入上的输出分布 KL（对干净解码序列做教师强制）。
- 门槛：Spearman(KL, 句级 chrF 下降) ≥ 0.3，且英→中的 KL 均值 > 中→英。通过后再写蒸馏（E）和可靠度读写策略（F）的预登记。

## D0：OpenBroadcast-SI dev 版（为后续完整验证准备）
- 用 `bench_build.py` 的同一套流程，换成 CoVoST 2 validation 语音和非留出背景，建 id2-dev / clean-dev 两个条件 × 两个方向。meeting id 用新前缀，不与 test 冲突。
- 在其上跑基线 B（两个种子）和 Idea 1 C，作为后续方法选择用的 dev 基线。只建数据、跑基线，不做任何选择。

## 判定
各项独立判定。通过的组合进入第二步（dev 版 OpenBroadcast-SI 上的完整系统验证）；不通过的如实记录、停止，不改设置重试。

## K1/K4 结果（2026-11-19 20:00 布拉格；卡 0–3，约 19:30–19:55 运行）

**实现（看任何数字之前定下的细节）：** 脚本 `voicecond/wave1_k1k4_prep.py`、`wave1_talker.py`、`wave1_probe.py`、`wave1_metrics.py`（d5cfdbec0 起）；输出 `eval_outputs/mist_w3po_v1/wave1_K1K4/`，日志 `logs/mist_w3po_v1/wave1/`。
- 条目：cvt dev 教师条目中有可用窗口的，按说话人轮转、译文不重复。P1a 实得 **182 条**（中→英 100、英→中 82；英→中 dev 只有 82 个不同译文，少于预登记的"约 200"），P1b / P4b / K7v 为每方向前 60 条，共 120 条（46 位说话人）。
- Talker：T1c 在 HF transformers 下 bf16 运行；采样与 si_infer 的 T1c 单块作业一致（SIGuard：期望长度、ngram 8、min_frac 0.3、重复惩罚 1.3；温度 0.7，top-p 0.8，上限 1500）。两个 TTS 种子 20261021 / 20261109；同一条目同一种子在各臂共用随机数。带噪提示 = 条目自身的混合段；B = 其原始 BiCodec token，C = Idea 1 C。
- ρ（800 条 cvt dev 一次算定）：mean‖u_C − u*‖ / mean‖u_raw − u*‖ = 11.37 / 14.77 = **0.770**。λ̄ 中位数 0.50；w_ZNE 中位数 0.62（0.26–1.28）。
- 门槛统计：每条目先对两个种子取平均，再与 C 配对；中位差的 95% CI 用 10000 次 bootstrap。WER：英文按词，中文按字（CER）；ASR 为 Whisper-large-v3 / Paraformer-zh。

**P1a（线性检验）：不成立。**
- 主指标（8192 个语义码上的 log-softmax，bf16，40,336 个码位）：合并 **R² = 0.504**（按条目 bootstrap 95% CI 0.466–0.537），二次项占比 **0.290**（一次 + 二次合计 0.793）；中→英 0.469、英→中 0.566。
- 补充：按平均概率加权 0.550；原始语义 logit 0.533；fp32 重跑 0.500（不是 bf16 数值噪声造成的）；逐条目 R² 中位数 0.547。
- σ = 0.25 时 32 个音色 token 平均已有 30 个与 σ = 0 不同；KL(σ=0 ‖ σ) 依次为 0.47 / 0.64 / 0.85 / 1.30。
- 按 5.4 节：输出空间零噪声外推缺乏理论依据。

**P1b（引导生成，对臂 C，n = 120）：两个臂都不通过。**

- 分方向的 PESQ 中位差：ZNE 中→英 +0.107、英→中 −0.037；CFG1 +0.048 / −0.004。
- 引导让语音**变短** 3.4%（ZNE）和 5.1%（CFG1），Wilcoxon p 分别为 1e-7 和 2e-10，超出 [0.98, 1.02]。

**P4a（语速探针）：通过。**
- 中层（第 14 / 28 层）在码位上的平均隐状态 → 目标文本 token/s；在 cvt train 8000 条上做 ridge（α = 10，只在 train 上用 GCV 选），在 dev 800 条上评估。
- **dev R² = 0.894**（中→英 0.852、英→中 0.930；train 0.941）。
- 这个探针在 P1b / P4b 的生成序列上，预测语速与实际语速的相关为 0.88–0.93。

**P4b（钳制，条件 {B, C, ZNE, CFG1}，n = 120）：不通过。**
- 不同音色条件之间的时长变异系数：均值 0.0614 → 0.0579，**只降了 5.7%**（95% CI −6.9% 到 +16.7%；门槛 ≥ 50%）；中位数 0.045 → 0.041。
- WER（钳制 − 不钳制）配对中位差 0.000（均值 −0.045，CI −0.155 到 +0.014），不变差。

- 钳制前的投影与 r̂ 只差 0.03–0.11（投影单位）。这条轴能**读出**语速，但钳住它并**不能控制**语速。
- 结论：K4 停止。

## K7v 结果（2026-11-19 20:00 布拉格）

**实现：** `voicecond/wave1_k7v_tokens.py`，按文档 6.3 自己实现，没有用 SEEN 的代码或选层规则。

**数据与统计量（看数前定）：**
- 特征：载入 C 权重的 BiCodec 说话人编码器，perceiver 之前的 ECAPA 帧特征，d = 1536。
- 统计量都用二阶矩，不去均值。
- Σ_g：400 条 cvt train 条目开头前 3 s 的 bg.wav，共 60,400 帧；增益与该条目带噪提示的音量归一化相同。
- 身份子空间：485 位 train 说话人的 1638 条干净提示，按提示取时间平均后去中心，取 95% 能量，**秩为 205**。
- 每条目：用本流条目前 3 s 的背景（约 151 帧）做逆 Wishart 后验，ν = d + 1 + 50 = 1587。
- Q 取 Σ̂ 95% 能量的主方向，中位数 154.5 个。

**结果：通过 |cos| < 0.1 过滤的方向数，120 个条目里全部为 0。**
- 1536 维空间里，一个随机方向与 205 维子空间的余弦期望约为 √(205/1536) ≈ 0.37，所以没有方向能留下来。
- 因此 γ 投影为空，K7v 的 token 在 120/120 个条目上与 C 完全相同。生成结果：240/240 的码长度相同，237/240 的 wav 逐位相同。
- 门槛：PESQ 配对中位差 0.000 [0, 0]，不满足"> 0 且 CI 下界 > 0"；WER、相似度、时长都等同于 C。**不通过。**
- 身份子空间"取 95% 能量"是实现时预先定的（与 Q 同一规则）。这是这个过滤规则在 d = 1536 时的结构性结果。按预登记，不改设置重试。
