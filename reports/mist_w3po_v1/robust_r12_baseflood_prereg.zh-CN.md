# 鲁棒 R12：以"冻结底座在干净输入上的损失"为逐句洪水位的编码器 LoRA（Base-Anchored Flooding）预登记

2026-11-21 06:50 CET（布拉格）写，早于本方法的任何训练或评测数字。夜间执行者按用户授权设计。约束同前：只用同一批 UniST 训练数据；不用 QABC 组件；一个模型两个方向；一个设置不扫参；点估计；dev 只用 D-U + bench_dev (b)。

## 关于"不做蒸馏"（请用户白天确认）
- 训练目标仍然只是参考译文的交叉熵；冻结底座只提供**每句一个标量**（它在干净版上对参考译文的平均交叉熵），作为损失的门槛，不提供任何输出分布、软标签或伪标签，模型不去模仿底座的输出。
- 这与 RHO-1（参考模型给出词元损失作门槛）同类，不是教师-学生蒸馏。但它确实用到了一个参照模型的数值，晨报里单独标出，请用户判断是否接受。

## 1. 动机（来自 R5、R6、R8 的结果）
- R5 / R6：只保护干净路径，风格拟合会转移到带噪路径（D-U 带噪比干净高 2.3–3.2）。
- R8：用"同一模型的干净损失"作水位，平凡解（编码器输出与输入无关）让目标为 0，第 400–500 步塌缩。
- R12 把水位固定为**冻结底座在同一句干净音频上的损失** b⁰_i：
  - 带噪输入：损失高于 b⁰ 时下降（学不变性），低于 b⁰ 时梯度反向（不允许"比底座听干净音频时还好"，即不允许学风格）；
  - 干净输入（两个干净环境）：同样以 b⁰ 为水位，模型在干净输入上比底座好就被推回，直接挡住无条件的风格偏移；
  - 塌缩不再是解：编码器输出若与输入无关，损失远高于 b⁰，会被强力拉回。

## 2. 文献
- **Flooding（Ishida et al., ICML 2020）：** L' = |L − b| + b，低于水位时梯度上升。
- **V-REx（Krueger et al., ICML 2021）：** 让各环境风险相等。
- **新意：** 洪水位不是全局常数，而是"冻结底座在配对干净输入上的逐句损失"；它同时规定了不变性（带噪降到干净水平）和无偏移（任何输入都不超过底座的干净水平）。没有看到先例。

## 3. 方法（一个设置）
- **代码：** `voicecond/r12_enc_train.py`（`r8_enc_train.py` 的副本），只改水位：
  - b⁰_i：干净版前向时**关闭全部编码器 LoRA**（即冻结底座），no_grad，逐句平均交叉熵；
  - CE_n,i：带噪批（第十四 / 十七波批次，8 个环境含 2 个干净环境）在当前模型上的逐句平均交叉熵；
  - L_i = |CE_n,i − b⁰_i| + b⁰_i，**全部 64 个位置都参与**（干净环境的槽位也参与，此时比较的是"当前模型 vs 底座"在同一干净输入上）；全局批量平均。
- 其余同第十七波：LoRA 在音频编码器 q/k/v/out_proj，rank 16，alpha 32，b 初始化为 0，fp32；AdamW lr 1e-4，余弦到 0，2300 步，全局批量 64，种子 20261119。
- **卡：** 0、6，world 2，微批量 32（失败则 16、8）。
- **记录：** 低于水位的句子比例（按环境）、CE_n、b⁰。
- **最终系统：** r12_wise05，WiSE α = 0.5，`wave17_merge.py` 合并。
