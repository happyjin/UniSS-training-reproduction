# R3：限定在噪声子空间里的编码器适配 预登记

2026-11-20 21:45 CET 写，早于 R3 的任何数字。方法来源：`robust_analysis_and_ideas_v3_20261120.zh-CN.md` 第 3 节 R3。用户已同意 R1–R4 开跑。

约束：
- 训练只用同一批 UniST 数据（`eval_outputs/mist_w3po_v1/wave14/data`）；
- 不做蒸馏：目标是参考译文，没有教师模型；
- 不用 QABC 的组件；
- 一个模型同时做两个方向，只跑一个设置；
- 不用任何测试数据或测试留出背景。

## 1. 动机（一句话）
第十七波的编码器 LoRA 同时学到了"对噪声的不变性"和"UniST 的译文风格"：训练集里从未被抽中的条目也 +12.49，测试上出现退化重复。R3 只允许 LoRA 改变编码器表示里噪声主导的方向，让它没有通道去学风格。

## 2. 噪声子空间（每个 LoRA 模块单独估计，写定）
- **位置：** 对第十七波的 128 个 LoRA 模块（音频编码器 32 层 × self_attn 的 q_proj / k_proj / v_proj / out_proj），在**该模块的输出空间**（1280 维）里估计子空间。投影作用在同一个空间里，维度一致：
  - q/k/v：注意力的查询、键、值空间；
  - out_proj：残差流。
- **数据：** UniST 训练行（wave14/data），每个方向取 1000 条，按 sha1("20261120|r3sub|row|<dir>|<k>") 选择，共 2000 对。
  - 每条做干净版和带噪版。带噪版的环境按 k 在 music / crowd / sfx 之间轮换；混音照抄第十四、十七波训练 Sampler 的做法：Idea 2 背景索引的 train 划分，BVR 取 OpenBroadcast-SI BVR 值的 U(0.05, 0.95) 分位，单位 RMS，0.02 s 渐变，限幅；随机数用 sha1("20261120|r3sub|mix|<dir>|<k>")。
  - 训练时 Sampler 用的键是 "20261119|w5m|..."，这里的键与之不同。
- **统计量**（同一条音频的干净版和带噪版帧数相同，逐帧对齐）：
  - 底座模块输出 y_c（干净）、y_n（带噪）；
  - Δ = y_n − y_c；
  - Σ_Δ = E[ΔΔᵀ]，Σ_c = E[y_c y_cᵀ]（帧级、不中心化，同 K7 的二阶矩口径）。
- **选方向（替代 SEEN 余弦过滤的写定规则）：**
  - 解广义特征问题 Σ_Δ w = λ (Σ_c + εI) w，ε = 1e-6 · tr(Σ_c)/d；
  - 保留 λ > 1 的方向，即沿该方向噪声扰动的能量超过干净信号的能量，等价于 K7 中 Wiener 增益 γ > 0.5；
  - 对保留的 w 做 QR，得到正交基 Q_m（1280 × r_m）。
- **为什么不用 SEEN 的"与每个语义特征向量 |cos| < 0.1"：** 第一波和第三波的 K7 在残差流上，按这条规则每层平均只保留 0.28 个方向。原因是语义特征向量覆盖了 95% 的迹，在 1280 维里维数很高，任何方向与其中某一个的 |cos| 几乎都会超过 0.1，规则退化。广义特征值规则保留了 SEEN 的本意（选噪声主导、语义贡献小的方向），而且有自然阈值 λ = 1，不需要扫参。这一改动写在任何数字之前。
- **秩：** 由数据决定，不设上下限、不调。r_m = 0 的模块在训练中等价于不加 LoRA。

## 3. 训练（只有一个区别）
- 同第十七波：
  - 编码器 q/k/v/out_proj 的 LoRA，rank 16，alpha 32，fp32 适配器；
  - UniST 数据，8 个环境，Sampler 的 sha1 键相同；
  - 2300 步，全局批量 64，world 2（卡 0、6），每个 rank 32 个槽；
  - AdamW 1e-4，余弦调度，种子 20261119；
  - 损失是翻译交叉熵，大模型的文本层全部冻结。
- **唯一的区别：** 每个模块的 LoRA 增量 Δh = s · B A x（s = alpha/rank）改为 Δh ← Q_m Q_mᵀ Δh，等价于有效增量权重 ΔW_m = s · Q_m Q_mᵀ B A。
- **最终系统：** r3_wise05，即 WiSE α = 0.5（alpha 减半，同第十七波）。

## 4. 合并与核对
- 合并：W' = W + 0.5 · s · Q Qᵀ B A（bf16 写回），其余张量与发布版逐字节相同（沿用 wave17_merge 的自检）。
- 前向等价核对：对若干模块，用随机输入 x 比较 x W'ᵀ 与 x Wᵀ + 0.5 s · x (Q Qᵀ B A)ᵀ，最大相对差应在 bf16 舍入量级（< 1e-2）。

## 5. 评测（点估计，用户要求先不做 bootstrap）
- **数据：**
  - UniST 同域 dev（`eval_outputs/mist_w3po_v1/devU/data`，set u，干净 / 带噪各 300 句 × 两个方向）；
  - bench_dev (b)（`wave2_S1/data` 的 b 部分）；
  - (a) CoVoST 只作参照。
- **系统：**
  - r3_wise05（新）；
  - 对照 base（底座 LA2）、enc_wise05（第十七波）。
  - 在 devU 上，base 和 enc_wise05 由本链新跑；(b) 上直接复用 wave2_S1 和 wave17/eval_enc_wise05 的 Thinker 输出。
- **只跑 Thinker：** si_thinker_stream，la2，w1。
- **指标：**
  - 论文口径 text BLEU（去标点、t2s、按字切分）；
  - 带噪 − 干净的差距；
  - 长度比（系统长度 / 参考长度，论文口径分词后）；
  - 重复率：译文长度超过参考 3 倍的句子比例；
  - text LAAL（按块的写出时间计）。
- **判断规则（点估计，写定）：** 相对 enc_wise05，在 devU 与 (b) 上同时满足：
  1. 差距不变差；
  2. 干净 BLEU 不降；
  3. 长度比更接近 1；
  4. 重复率不升。
  - 四条都满足，记为"有效"，再考虑 bootstrap 和测试；否则如实记录。
