## 3. 主线：把声学干扰变量边缘化的同传（Nuisance-Marginalized Simultaneous Translation）
**统一视角。** 噪声和串音是与内容无关的声学干扰变量 n。理想的提交决策是对 n 做边缘化：

  p(y | x) = ∫ p(y | x, n; θ(n)) p(n | x) dn

现有系统在三个地方忽略了 n。三个方法各补一处：

| 层面 | 现有做法的问题 | 方法 |
|---|---|---|
| 参数 θ(n) | 一个固定的 WiSE α 对所有噪声水平折中 | **NCWI**：按 p(n \| x) 的估计取期望效用最大的插值系数 |
| 决策（提交） | LA2 只看时间上相邻的两次草稿，噪声诱发的错误会被两次一致地认同 | **CV-LA**：在多个声学视角上求一致，即对 n 做蒙特卡洛边缘化 |
| 表示（在哪里适配） | LoRA 全在 LLM 层，学抗噪的同时也记住了句子 | **感知层 LoRA**：只适配音频编码器，抗噪而不记忆 |

- V1 音色和 T1c 属于语音侧的系统部件：V1 已通过 PESQ 门槛。它们放在系统部分和附录，不作为主要贡献。
- 主要贡献：上面的统一框架和三个对应方法；可以写成定理或命题的部分（见第 6 节）；以及第十二、十三波的诊断（窄数据记忆、插值优于轨迹、提交与感知的分解）。

## 4. 三个方法（预登记，一个设置，不扫参）

### 4.1 第十五波：CV-LA，跨视角一致提交（推理期，不训练；卡 4–5）
- **视角：**
  - v0 = 原始音频；
  - v1 = 用一个开源的、预训练的语音增强模型处理后的音频。执行者在实现说明里写明用的是哪个，不训练、不调参，并逐读窗地只用已读到的音频（因果）。
- **规则：** 第 t 次读入时，对两个视角各做一次贪心续写，两个视角在 vLLM 里同批计算。设 LA2 原有的一致前缀为 A_t = LCP(d_{t−1}^{v0}, d_t^{v0})，CV-LA 提交 LCP(A_t, d_t^{v1})，即时间上一致且跨视角也一致的前缀。读到句尾时与 LA2 相同，提交 v0 的完整草稿。
- **新意：** 增强音频不再替换输入（第七波已证明没用），而是作为一致性的见证。规则里没有阈值，也没有后验。
- **评测：**
  - 先在底座 Thinker 上评：cvla_base 对 la2_base，可以立即开始；
  - 再在 unist_wise05 上评：cvla_unist 对 unist_wise05，等第十四波合并完成后开始；
  - 链与打分同第五波（la2 w1 → T1c → ASR；3 次底座运行、噪声底、bootstrap）。
- **主判定（两组各自独立判定）：**
  - 所有 (a)/(b) × 干净/带噪单元，text BLEU 和 ASR-BLEU 相对对照的点估计 ≥ −0.3，且 CI 上界 ≥ 0；
  - 至少一个带噪单元 text 增益的 CI 下界 > 0，且超过噪声底。
- **辅助：** LAAL（D1、D2）；提交统计（提交后被参考否定的比例）；增强模型每个读窗的计算时间。

### 4.2 第十六波：NCWI，噪声条件的权重插值（推理期；拟合在 CPU 上，评测等卡 0–3 空出）
- **端点：** α ∈ {0, 0.5, 1}，分别是 base、unist_wise05、unist，都来自第十四波在 dev 上的输出，不新增任何 α 点。
- **噪声估计：** 只用每条输入的前 1 s（流式开始时就要定下 α）。用一个开源预训练 VAD 区分语音帧和非语音帧，b̂ = 非语音帧能量 / 语音帧能量，是闭式计算，不训练。
- **分箱：** 每个方向 4 个箱：b̂ 在 dev 上的四分位，每箱约 75 条 (a) 条目。
- **拟合：** 每个方向 × 每个箱，用 3 个端点的句级 BLEU 均值拟合二次曲线 f(α) = a0 + gα − cα²（三点精确拟合）。α* = clip(g / 2c, 0, 1)；若 c ≤ 0，就取三个端点中最好的一个。
- **交叉拟合（避免在同一批 dev 上既拟合又评估）：** 按 sha1(id) 把 dev 条目分成两半，用一半拟合，在另一半上评，再交换。主判定用两半合并后的结果。
- **推理：** vLLM 多 LoRA，同一个 UniST LoRA 按 α* 缩放成不超过 8 个适配器，每条请求按 b̂ 所在的箱选一个。仍是一个模型，没有额外前向。
- **主判定：**
  - 对 unist_wise05：没有任何 (a)/(b) 单元的 text BLEU 或 ASR-BLEU 点估计 < −0.3 且 CI 上界 < 0；
  - 至少一个单元 text 增益的 CI 下界 > 0，且超过噪声底。
- **辅助：** 每个箱的 α*；b̂ 与真实 BVR 的相关；LAAL。

### 4.3 第十七波：感知层 LoRA（训练；卡 6–7）
- 只在 Qwen3-Omni 的音频编码器里加 LoRA：每层注意力的 q/k/v/o，rank 16，alpha 32。LLM 文本层不加 LoRA，全部冻结。
- 其余与第十四波完全相同：同一份 UniST 数据和 8 个环境，Sampler 的 sha1 键相同，2300 步，全局批量 64，AdamW 1e-4，余弦调度，种子 20261119。
- 设备：world 2（卡 6–7），每个 rank 32 条，微批量按冒烟结果取最大值（只影响梯度累积）。
- **最终系统：** enc_wise05（alpha 减半）。enc（α = 1）作为辅助一并评测。
- **主判定：**
  1. enc_wise05 相对底座，用统一规则。
  2. enc_wise05 相对 unist_wise05：
     - 至少一个单元 text 差的 CI 下界 > 0，且超过噪声底；
     - 没有任何单元的点估计 < −0.3 且 CI 上界 < 0。
- **机理检验（辅助，写定的预测）：**
  - enc（α = 1）在中→英干净上不显著掉分；
  - 600 条训练子集上，enc − base 的提升远小于第十三波的 +13.31（编码器不记忆译文）；
  - 英→中带噪的提升应来自离线翻译，而不是提交（oracle 分解）。

## 6. 写成一篇论文：novelty 评估与需要补的东西
- **最终系统：** UniST-ERM-WiSE（若第十七波通过，就换成感知层 LoRA）+ NCWI + CV-LA，加上 V1 音色和 T1c。论文主线是第 3 节的"边缘化声学干扰变量"，三个方法分别对应参数、决策、表示三个层面。
- **只是把几个组件叠起来的风险：** 如果只报"每加一个组件涨多少"，审稿人会认为偏工程。要避免这一点，需要做到：
  1. 用统一的公式推出三个方法，而不是分别提出；
  2. 每个方法都有可检验的命题：
     - NCWI：在二次近似下 α* 的闭式解，以及它相对固定 α 的期望增益下界；
     - CV-LA：跨视角一致时，提交错误率上界随视角间错误的独立程度而下降；
     - 感知层 LoRA：可以记忆译文的参数子空间与可以抗噪的参数子空间分开（用第十三波的记忆量来衡量）；
  3. 诊断分析作为科学贡献：提交与感知的分解，窄数据记忆，插值优于训练轨迹；
  4. 在 RealSI 干净版和带噪版、真实噪声的分布外测试上，给出与 LA2 基线的同口径比较，以及消融。
- **够不够 ICLR：**
  - 现在不够：只有 ERM-WiSE 一个通过的方法，而且加噪训练加 WiSE 是已知做法；
  - 如果第十五到十七波中至少两个通过，并且能用第 3 节的框架统一起来、配上命题和诊断，可以作为 ICLR 的有竞争力的投稿，但仍属边缘；更稳的目标是 ACL、EMNLP 或 Interspeech。
  - 决定性因素是 CV-LA 和 NCWI 在 RealSI 带噪版和真实分布外测试上是否有显著增益，以及理论部分是否站得住。
