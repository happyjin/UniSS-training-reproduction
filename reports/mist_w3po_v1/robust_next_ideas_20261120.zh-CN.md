# 鲁棒单说话人同传：下一轮 novel idea 方案（2026-11-20 晚，布拉格）

写于任何下一轮数字之前。约束沿用 memory：
- 训练只用同一批 UniST 数据（wave14/data）；
- 不做蒸馏，不用 QABC 的组件（ABC 后验、SDR、belief commit）；
- 一个模型同时做两个方向，每个方法只跑一个设置；
- 不跑 AMI / AliMeeting；先看点估计做筛选，bootstrap 只对有效的方法补做；
- 不用 K 倍计算的方案，两路视角同批计算可以接受（CV-LA 已用）。

## 0. 已经知道的事实（idea 都从这里推出来）
1. **噪声主要伤在流式前缀的提交上，不在整句翻译上。**
   - 整句读完时，底座的噪声损失只有 0.18（英→中）和 0.89（中→英），都不显著（第三波 T 组）；
   - LA2 流式下，中→英的噪声损失有 3.22；
   - 中→英带噪损失约 71% 来自提交（第三波）。
2. **输入侧去噪全部无效：** K3、K7（在线 SEEN）、K8（观测叠加）、HDemucs 替换输入（第七波），以及对比解码 K2（显著变差）。
3. **CV-LA 有效，但它的作用是"按噪声分配提交预算"，不是"截在跨视角不一致处"：**
   - 两种截法在提交量相同时质量一样（±0.25）；
   - 总量相同、但不随噪声变化的预算比 CV-LA 差 0.8–1.6（英→中）；
   - 代价是 D1 多 0.2–0.3 s。
4. **测试点估计：** C 相对 EW 在 RealSI 和 OBSI 上 10/10 个单元为正，+0.2 到 +1.5。
5. **dev 有偏：** dev (a) 是 CoVoST validation，对 UniST 训练的模型是跨域，"UniST 失败"的结论有一部分来自 dev 本身。

## 1. 基础设施（先做，CPU 为主）
- **D-U：UniST 同域 dev。** 用 UniST 留出子集（crc32(id) % 50 == 0，第十四波已排除出训练）每方向取 300 句，做干净版和带噪版。带噪版用第十四波训练噪声池的 dev 划分（不能用测试的留出背景）。以后的选择和判定在 D-U 与 bench_dev (b) 上做，CoVoST (a) 只作参照。

## 2. 五个可以并行的 idea

### N1. 见证代数：用"跨干扰视角一致"代替"时间一致"（推理期，零参数）★ 首选
- **动机：** LocalAgreement 用时间上的一致作见证：等下一次读，前缀不变才提交，这正是 1 s 延迟的来源。事实 3 说明增强视角是另一种见证：它不需要等待，只需要同一时刻对干扰变量的不变性。
- **规则族**（v0 = 原始音频，v1 = 增强视角，d_t 为第 t 次读的草稿）：

| 规则 | 提交 | 预期 |
|---|---|---|
| LA2（时间见证） | LCP(d_{t−1}^{v0}, d_t^{v0}) | 现有基线 |
| CV-LA（两种见证都要） | LCP(LA2, d_t^{v1}) | 质量最高、最慢（已测） |
| **AoV**（只用视角见证） | LCP(d_t^{v0}, d_t^{v1}) | 不用等下一次读，预期延迟比 LA2 低 0.5–1 s |
| **EITHER**（任一见证即可） | 两者中较长的前缀 | 最快 |

- **新意：** 把同传的提交写成"不变性见证"的代数：时间不变性与干扰不变性可以相与、相或、互相替代。这样无参数地得到一条延迟和质量的 Pareto 曲线，可以和 wait-k、LA-k 的曲线对比，正好回答审稿人"等长一点是不是也一样"。文献里 LocalAgreement（Polák et al.）只用时间见证；把增强或干扰视角当作一致性见证，没有看到先例。
- **筛选：** dev 上只跑 Thinker：text BLEU、text LAAL 的点估计。先在底座上跑（每条规则约 5 min × 2 卡），再在 UE 底座上跑。
- **有效标准（点估计）：** AoV 或 EITHER 在同等或更低的 D1 下，text BLEU 不低于 LA2；或者在 Pareto 图上严格优于 LA-k / wait-k 的插值线。

### N2. 无标签的保形提交：给出可靠度保证（推理期，校准用 CPU）
- **动机：** 事实 3 说明要做的是"每句该保守多少"。CV-LA 的分配是隐式的，可以把它显式化，并给出保证。
- **做法：**
  1. 每次读的候选提交长度 ℓ，用"视角一致长度、时间一致长度"这两个已有信号打一个分数；
  2. 在 D-U 上，用模型自己整句读完后的终稿当标签（无需参考译文）：一个提交单元后来被终稿推翻就算错。用保形风险控制（Conformal Risk Control，Angelopoulos et al., ICLR 2024）求阈值，保证"提交后被推翻的比例 ≤ ε"；
  3. ε 事先写定为底座 LA2 在干净输入上的推翻率。这个目标叫"噪声下保持干净时的可靠度"，不扫 ε。
- **新意：** 同传提交的无分布可靠度保证，标签来自模型自身的终稿，与噪声条件解耦。它不是后验，也不是 belief commit：没有 ABC，没有 SDR，没有置信度后验，只有分位数校准，符合 QABC 约束。
- **筛选：** 校准在 CPU 上做（用 N1 和第十五波已有的草稿日志）；评测时 Thinker 只跑一次 dev。看推翻率是否 ≈ ε，以及 BLEU / D1 点估计。

### N3. 带噪前缀到前缀训练（训练，UniST 数据，卡 6–7）
- **动机：** 事实 1：噪声伤的是部分前缀上的翻译，而 ERM-WiSE 只在整句上训练。
- **做法：** 同第十四波的 UniST 数据、8 个环境、LoRA 和步数，但每条样本以概率 0.5 截成音频前缀，长度在 [1 s, 全长] 均匀取，目标是按时长比例截断的参考译文前缀（STACL 式的 prefix-to-prefix 训练）。最终用 WiSE α = 0.5。
- **新意：** 中等。前缀训练本身已知，新意在于"把噪声鲁棒性放到流式前缀上训练"，并用第三波的提交与感知分解来解释。不是蒸馏：目标是参考译文，没有教师模型。
- **筛选：** D-U 和 (b) 上的 LA2 text BLEU 点估计，与第十四波 unist_wise05 比。

### N4. 等待后追回语速：把 CV-LA 的延迟代价还回去（推理期，Talker 侧）
- **动机：** CV-LA 在噪声下晚提交 0.2–0.6 s，而主延迟指标是语音 LAAL（memory）。Talker 可以把这段等待在说话时追回来。
- **做法：** 每次写出时，计算这句累计"相对 LA2 晚了多少"（CV-LA 的运行里有 la2_new 和 cv_new，可以直接算），按闭式规则调 T1c 的 block 语速：speed = clip(1 + 晚到时长 / 剩余预计时长, 1, 1.25)。上限 1.25 写定，不扫。
- **新意：** 中等。"按声学可靠度分配等待、再用语速追回"在 SimulS2ST 里没有看到先例，并且把 Thinker 的提交策略和 Talker 的韵律连成同一个延迟预算。
- **筛选：** 复用 C / UE 的 Thinker 块，只重跑 Talker 和 ASR：语音 LAAL 和 ASR-BLEU 的点估计相对 C。

### N5. 参数视角：把"模型扰动"也当作见证（推理期）
- **动机：** 第十三波和测试结果都显示，适配后的模型会在部分领域漂移；适配前后的模型对同一前缀的分歧，提示了"这个前缀不可靠"。
- **做法：** vLLM 多 LoRA，同一请求在同批里分别用 α = 0（底座）和 α = 0.5（UE 或 UW）各生成一个草稿，作为第二个见证，规则同 N1（与、或）。终稿仍取适配模型的输出。
- **新意：** 把输入干扰（增强视角）和参数干扰（适配前后）统一成同一个见证代数。与 N1 共用代码。和"两路同批"的计算量相同，但不能与 N1 的两路视角同时开，否则就是三路。
- **筛选：** 同 N1。

## 4. 论文可能的形态
- **主线：** "Agreement under nuisance：同传提交的不变性见证与可靠度保证"。N1 是方法核心（见证代数，配 Pareto 曲线），N2 是理论（保形保证），N4 是语音端的延迟预算闭环；第三波和第十三波的诊断，加上 CV-LA 的两个对照，作为分析。
- **ICLR 的可能性：** 如果 N1 在同等延迟下严格优于 LA-k / wait-k，并且 N2 的保证在 RealSI 带噪和 OBSI 上成立，这条线比现在的"三个部件叠加"更像一个通用的方法贡献，有冲 ICLR 的可能，但仍属边缘。N3、N5 是增强项。
