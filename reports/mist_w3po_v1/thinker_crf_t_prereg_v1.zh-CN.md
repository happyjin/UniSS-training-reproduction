## T0：Thinker 自己的写出时机标签（2026-11-11 07:45 UTC 登记，在任何 T0 结果之前）

### 定义（唯一设置）

- **模型**：A′ 的 Thinker，与 B-2 完全相同（v8 merged + 内存中合入 v2′ `crf_v2p_20261110T075131Z/ckpt/step_03000`；2 卡显式层映射，Engine.dev 固定在 cuda:0）。
- **块与读**：与 B-2 相同。参考目标按训练行（S0-3 / v2′）的规则构造；标点块再切成 ≤ 4 词的块；块按 κ（S_prop 的标签顺序：(min(源端终点 + 1.0 s, 窗口长度), 源端起点)）串成 S；每 0.5 s 读一次，再加最终读。
- **每次读的输入**：与 B-2 相同。每次读对整个 S 做一次教师强制前向：音频到 t_r，说话人后验到 t_r − 1.04 s，上下文为空，不做扰动；最终读在 softmax 前屏蔽 `<wait>`。
  - dev：最终读的后验按 `final_cut_ms(t, close_detect)` 截断（B-2，= A′ 解码的 `--final-read-post close_detect`）；
  - train：最终读的后验到 t // 80（训练窗口没有关窗检测时刻；= v2′ 训练的 `--final-read-full-post 1`）。
- **一致数**：读 r 时块 j 的 a_j(r) = 块 j 的**文本 token** 中，教师强制下 argmax 预测（全词表，最终读屏蔽 `<wait>` 之后）等于参考 token 的个数。
  - 每块的 token 结构是 `<|spk k|><|t a|>文本<|t b|>`：第一个（说话人）、第二个（起始时间）、最后一个（终止时间）不计入，其余都是文本 token。代码按 token id 范围断言这一结构。
- **最早可写读**：e_j = 最小的 r，使得对所有 r′ ≥ r 都有 a_j(r′) ≥ a_j(R)（R = 最终读），即从 r 起一直稳定在完整上下文的一致水平。
- **边界情况（登记在任何结果之前）**：若 a_j(R) = 0（完整上下文下也没有一个文本 token 一致），按字面 e_j 会是第一次读，但这只是因为条件"不低于 0"恒成立，块里没有任何可写性证据。登记的处理：这种块的 e_j 取它的 S_prop 读 u_j（源端终点 + 1.0 s 之后的第一个 0.5 s 读，否则最终读），即用户指定的 NOT GO 退路标签。受影响的块数照实报告；字面读法（e_j = 第一次读）的两条判定线数字也一并报告，不作判定。
- **然后**：同一说话人内按 κ 顺序取累计最大值；再过在线夹紧（不早于开窗检测；落在最终读的按关窗检测时刻计），与 B-2 的 `schedule` / `online` 完全相同。

## T1 与 T2（2026-11-11 08:34 UTC 登记，在两者的任何训练与评测结果之前）

  - S 按 (d_j, 源端终点, 源端起点) 排序。
- **配方与 v2′ 相同**：
  - 初始化：v8 merged + 新 LoRA r32 / α64 + 投影器 + 259 个新 token 行；

### T1：工程基线

- `train_crf_sft.py --objective serial_v2p --sched sched_piece_t0_v1`，即 v2′ 的格原样不动：每块可以晚 1 次读（0.5 s），最终读的块不可推迟；读内顺序隐变量；退火后验 EM。
- 槽位 A（0–3），T0 标注一结束就开始。

### T2：隐写时 CRF（方法）

- `train_crf_sft.py --objective latent_write`（`crf/latent_write_crf.py`、`crf/latent_write_train.py`），其余与 T1 完全相同。
- **格**：v2′ 的集合状态链，可行集放宽为
  - 块 i 的写出读 ρ_i ∈ [e_i, h_i]，h_i = min(R−1, max(u_i + 1, e_i + 1))，u_i 是 S_prop 的截止读（源端终点 + 1.0 s 之后的第一个 0.5 s 读，否则最终读）；
  - 也就是 {i : h_i ≤ r} ⊆ A_r ⊆ {i : e_i ≤ r}；每个说话人内前缀闭合；A_R = I。
  - **与用户原文的差别**：用户写的是 {i : u_i ≤ r−1} ⊆ A_r。在 e_i > u_i + 1 的块上（dev5 有 28%），这个集合是空的。登记的处理：取并集 {e_i, e_i + 1}（即 v2′ 的集合）。这是让格可行、并且包含 T1 的格的最小改动。
- **势函数**：ψ_r = τ·log p_θ(新写块 ⊕ e_r | x_{≤t_r}, κ(A′)) − λ·Σ_{i∈A_r∖A_{r−1}} W_i·(t_r − τ_i)，τ = 0.5，W_i 是块的词数，τ_i 是块的比例源端终点。延迟项在文本时间线上。
  - 历史 κ 和读内的 canon / newfirst 顺序沿用 v2′。carried = 本读写出且 e_i ≤ r−1 的块。
- **λ（后验正则的对偶，按步求）**：目标 E_q[Lat] / ΣW = 同一步、同一批窗口、同一模型参数下 **T1 格（v2′）后验的期望延迟**。
  - 约束不绑定时 λ = 0；否则从 1 倍增括出区间（上限 1e3），再二分 50 次。
  - **与用户原文的差别**：用户写的是"等于 T1 固定标签的延迟"。但 T1 的标签路径 ρ = e 恰好是 T2 格里最早的那条路径，要让 E_q[Lat] 等于它，只能 λ → ∞，T2 就退化成标签路径上的 SFT，格不起作用。所以改用 T1 训练目标自己的期望延迟（同一参数、同一批窗口）。这样两者的期望延迟相同，T2 只多了"把写出放在哪一读"的自由，正是"同样延迟、更好的位置"这一比较。
- **EM**：τ = 0.5 的退火后验，q 不回传梯度，后验加权交叉熵（与 v2′ 相同）。
- **测试**（CPU，提交 d2e1aeb0，全部通过）：
  - 前向-后向与暴力枚举一致（1e-13）；
  - 收缩成 v2′ 时，计划与后验与 v2′ 逐位相同；
  - 只剩标签路径时，loss 和梯度与 C0 逐位相同；
  - λ 求解单调、能命中目标。
- 槽位 B（4–7），等另一执行者的评测结束（约 09:30）且 T0 标注完成后开始；否则在 T1 之后用槽位 A。

## T3：联合 CRF（方案 3）（2026-11-11 08:40 UTC 登记，在任何 T3 检查数字、训练与评测结果之前）

### 要回答的问题

T2 把延迟算在**文本时间线**上。真正的主指标是**语音时间线**上的每条流 LAAL：一块写出后要排在同一说话人的播放队列后面，播放时长又取决于 talker。T3 让 Thinker 的写出计划与 talker 的播放格组成一个联合 CRF，延迟项直接算在语音时间线上，后验是（写出计划，talker 候选）的联合后验。

### 因子图（一个训练窗口；读 r = 1..R，说话人 k = 每个说话人一条输出流）

- **Thinker 链**（与 T2 完全相同）：状态 A_r（每个说话人的前缀计数，h_i ≤ r 的块必须已写，e_i ≤ r 的块才可写），读内顺序 o_r ∈ {canon, newfirst}，边势 τ·ψ^T_{r,o}(A_{r−1}→A_r)，τ = 0.5。
- **talker 隐变量**：读 r 上说话人 k 写出的块 B_{k,r}（W_r 里属于 k 的块，按 κ 顺序）非空时，有一个语速类 v_{k,r} ∈ V = {0, +2}，即 PL-EM 候选格的两个语速档（A′ 规则语速、再快 2 档）。
- **播放状态**：每个说话人一个积压 b_k(r)（ms），确定性转移：
  - b′_k = max(0, b_k(r−1) − (t_r − t_{r−1}))（读 r 写出时的队列剩余）；
  - b_k(r) = ⌊b′_k + D(B_{k,r}, v_{k,r})⌉_Δ（块为空时 D = 0），Δ = 80 ms 网格、最近点取整、上限 8 s；b_k(0) = 0。
  - 可用时刻 a = t_r（训练窗口没有检测器时刻，见近似 A3）。
- **因子**：
  - talker 因子 log π(v_{k,r} | bin(b′_k))；
  - 延迟因子 −λ·l_{k,r}，l_{k,r} = Σ_{i∈B} W_i(t_r − τ_i)/1000 + W_B·b′_k/1000 + (W_B+1)/2·D/1000（秒 × 词）。第一项是 T2 的文本项，后两项是 PL-EM 的播放项（块内的词在播放期间均匀展开，与 `speech_latency_lit` 相同），合起来就是每个词"说完的时刻 − 源端终点"。
- **联合后验**：q_λ(z, v) ∝ exp(Σ_r [τψ^T_{r,o_r} + Σ_k (log π(v_{k,r} | bin(b′_k)) − λ·l_{k,r})])。

### 精确推断

- 增广链：读 r 的状态 = (A_r, b⃗_r)，b⃗ 是窗口内所有说话人的积压向量。转移由 (A_{r−1}→A_r, v⃗_r) 确定，所以 (A, b⃗) 上的前向-后向是这个联合后验的**精确**和积。状态按读哈希，只保留可达状态。
- 边数组按读向量化：边结构和不含 λ 的势只建一次；λ 二分时只重跑和积。
- Thinker 的边-顺序边际 = 增广边边际对 (b⃗, v⃗) 求和，然后乘读内顺序的条件（与 T2 相同），得到 cend，再交给 `serial_v2p_train.set_coefs`。
- 单元测试：与不经过格的暴力枚举（ρ × 读内顺序 × 语速）对拍：log Z、Thinker 边-顺序边际、cend、E_q[语音延迟]，容差 1e-9。去掉 talker 因子、把播放项置零时，必须与 T2 的后验一致。

### λ（与 T2 同一原则）

- 按步求的后验正则对偶：Σ_w E_{q_λ,w}[l] = Σ_w E_{q_T1,w}[l]。右边是同一步、同一模型、同一播放与 talker 因子下，T1 子格（状态满足 c_k ≥ #{e_i ≤ r−1}）上 λ = 0 的期望语音延迟。不绑定时 λ = 0；括区间与二分同 T2（从 1 倍增，上限 1e3，二分 50 次）。
- 这样 T3 与 T2 的差别**只有一处**：延迟算在语音时间线上（含 talker 和排队），而不是文本时间线。

### 编号的近似与检查（阈值在任何数字之前定下）

- **A1 时长模型**：一块在语速类 v 下的时长 D(B, v) = a_v·n(B) + c_v。
  - n(B) 是块文本的长度，从 {英文音节数（`si_infer.spoken_units`）、词数、字符数} 中选 train 上拟合 R² 最高的一个。
  - 拟合目标：train 候选（`speech/train16_crf_v2p_s3000_finalpost_c2g06/talker_cands`）上，PL-EM E 步后验 q(c | b_n^{A′}) 在该语速类内加权的候选时长期望。
  - 不用 dev 调参。
  - **检查**：在 A′ + PL-EM 的 dev 输出（`speech/dev_crf_v2p_s3000_finalpost_s8_c2g06__plem_c1b1s2/talker/results.jsonl`）上，用 π 加权的期望时长 Σ_v π(v | bin)·D(B, v) 预测每块实际时长：R² ≥ 0.6，且平均相对偏差的绝对值 ≤ 10%。
- **A2 talker 因子**：π(v | bin) 只依赖积压分箱（0.5 s 一箱，8 箱，同 `backlog_bin`），不依赖文本。
  - 取 train 上 PL-EM E 步条件后验在语速类上的边际 q(v | b_n^{A′})，按箱平均，加 1 平滑（每箱每类加 1 个伪计数块）。
  - 候选的内容分（talker 对数概率、CTC NLL）已经包含在 PL-EM 的后验里，这里不另加。
  - **检查**：train 上每块的 q(v | b_n) 与它所在箱的 π 之间的平均 KL ≤ 0.15 nats。
- **A1+A2+A4 合起来的检查**：在 A′ + PL-EM 的 dev 输出上，保持文本写出时刻与在线夹紧不变，把每块的实际时长换成模型的期望时长（按模型自己的积压逐块推进），重跑 `speech_latency_lit`：
  - 每条流语音 LAAL（all）与实际值之差的绝对值 ≤ 0.30 s；
  - 单元级 Pearson 相关 ≥ 0.8。
- **A3 训练时不夹紧**：训练窗口没有开窗 / 关窗检测时刻，所以训练时取 a = t_r。
  - **检查**：在 dev5 上（有检测器时刻），用 T0 标签路径和 S_prop 路径各算一次每词语音延迟代理（A1 的期望时长）。比较"有夹紧"与"无夹紧"两种算法下两条路径的差 Δ：|Δ_无 − Δ_有| ≤ 0.25·|Δ_有|。
- **A4 网格**：Δ = 80 ms，最近点取整，上限 8 s（PL-EM 的网格；最近点而不是向上取整，因为每读都要取整，向上取整会累积漂移）。
  - **检查**：在 A′ + PL-EM 的 dev 流上，按块推进网格积压与精确积压，每词延迟代理之差的平均绝对值 ≤ 0.05 s。
- **A5 状态上限**：每读增广状态上限 K = 4096。
  - 某个窗口任一读超过 K 时，该窗口的网格加粗为 2Δ（必要时 4Δ、8Δ…），直到不超过 K。这样处理仍是精确推断，只是网格更粗，而且与 λ 无关。
  - **检查**：在 T1/T2 训练数据的 3000 步计划窗口上，被加粗的窗口占比 ≤ 2%（超过只报告，不改设置）。
- **A6 读内顺序与块**：同一读同一说话人写出的块作为 talker 的一块，播放顺序与 κ 顺序相同（不随 o_r 改变）。推理时 talker 按 Thinker 的段播放，一读一说话人通常就是一段，所以这一近似只影响罕见的一读多段。
  - 只报告一读内同一说话人写出多段的占比，不设阈值。

**任何一项检查不过**：照常训练（用户要求实验都要跑），在结果里写明是哪项、差多少。

**T3 实现补充（2026-11-11 08:44 UTC，写代码时发现，仍在任何检查数字之前）**：积压的取整改为"只在加入新块时取整，取的是队列结束时刻在绝对 80 ms 网格上的最近点"，即 E_k ← ⌊t_r + b′_k + D⌉_Δ，b_k(r) = max(0, E_k − t_r)；空块的读不取整。原因：读间隔 500 ms 不是 80 ms 的整数倍，原文"每读都取整"会让没写块的说话人每读系统性地多出 +20 ms，造成漂移。改动后，取整误差每块 ≤ 40 ms 且无偏，与 PL-EM 每块取整一次的做法一致。A4 的检查与阈值不变。
