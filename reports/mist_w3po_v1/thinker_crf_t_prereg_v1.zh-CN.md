## T0：Thinker 自己的写出时机标签（2026-11-11 07:45 UTC 登记，在任何 T0 结果之前）

### 定义（唯一设置）

- **模型**：A′ 的 Thinker，与 B-2 完全相同（v8 merged + 内存中合入 v2′ `crf_v2p_20261110T075131Z/ckpt/step_03000`；2 卡显式层映射，Engine.dev 固定在 cuda:0）。
- **块与读**：与 B-2 相同。参考目标按训练行（S0-3 / v2′）的规则构造；标点块再切成 ≤ 4 词的块；块按 κ（S_prop 的标签顺序：(min(源端终点 + 1.0 s, 窗口长度), 源端起点)）串成 S；每 0.5 s 读一次，再加最终读。
- **每次读的输入**：与 B-2 相同。每次读对整个 S 做一次教师强制前向：音频到 t_r，说话人后验到 t_r − 1.04 s，上下文为空，不做扰动；最终读在 softmax 前屏蔽 `<wait>`。
  - dev：最终读的后验按 `final_cut_ms(t, close_detect)` 截断（B-2，= A′ 解码的 `--final-read-post close_detect`）；
  - train：最终读的后验到 t // 80（训练窗口没有关窗检测时刻；= v2′ 训练的 `--final-read-full-post 1`）。
- **一致数**：读 r 时块 j 的 a_j(r) = 块 j 的**文本 token** 中，教师强制下 argmax 预测（全词表，最终读屏蔽 `<wait>` 之后）等于参考 token 的个数。
  - 每块的 token 结构是 `<|spk k|><|t a|>文本<|t b|>`：第一个（说话人）、第二个（起始时间）、最后一个（终止时间）不计入，其余都是文本 token。代码按 token id 范围断言这一结构。
- **最早可写读**：e_j = 最小的 r，使得对所有 r′ ≥ r 都有 a_j(r′) ≥ a_j(R)（R = 最终读），即从 r 起一直稳定在完整上下文的一致水平。
- **边界情况（登记在任何结果之前）**：若 a_j(R) = 0（完整上下文下也没有一个文本 token 一致），按字面 e_j 会是第一次读，但这只是因为条件"不低于 0"恒成立，块里没有任何可写性证据。登记的处理：这种块的 e_j 取它的 S_prop 读 u_j（源端终点 + 1.0 s 之后的第一个 0.5 s 读，否则最终读），即用户指定的 NOT GO 退路标签。受影响的块数照实报告；字面读法（e_j = 第一次读）的两条判定线数字也一并报告，不作判定。
- **然后**：同一说话人内按 κ 顺序取累计最大值；再过在线夹紧（不早于开窗检测；落在最终读的按关窗检测时刻计），与 B-2 的 `schedule` / `online` 完全相同。

### dev5 预检（判定）

范围与 B-2 相同：`windows_zh2en_c2g06_v1_dev5` 的 944 个 kept 窗口，直接用 B-2 的 `cpu/targets.jsonl`（同一批块、S、读），1564 个完整参考单元。

**GO** 当且仅当同时满足：
1. 在有 ≥ 2 块的话语里，非末块中 ≥ 30% 的 e_j（累计最大值与夹紧之后的写出时刻）早于话语结束；
2. T0 的标签路径文本 LAAL（B-2 的定义：参考词即输出词，按单元，夹紧后）≤ S_prop（≤ 4 词块，比例 + 1.0 s，0.5 s 读）。

**附带报告**（不作判定）：
- T0 对 B-2 的 S_lik：LAAL（all / ov / 1spk）、逐块 e_j 的差；
- e_j 落在最终读的块占比、最终读写出的词占比；
- e_j − 比例源端时刻（中位数 / p90；末块与非末块分开）；
- a_j(R) = 0 的块数与字面读法的数字；
- 标签时刻早于该块源端起点的块占比（"未听先写"）。

**NOT GO 时**：照常继续（用户要求实验都要跑），T1、T2 改用 S_prop 标签，并记录这一决定。
