## 5. 实现中的选择（按"最接近原文"处理，均已写入代码文档）

**1. "第一次读的前一项记作 −∞"**
- 照字面理解，就是 s_j(r₀−1) = −∞。那么第一次读的跳变是 +∞，所有 e_j 都会落在第一次读，与模型无关，规则退化。测试里验证了这一点。
- 采用的读法：第一次读的**跳变项**记作 −∞。也就是说，第一次读永远不会被选为 argmax，除非窗口只有这一次读。
- 跳变相同时取较早的读。

**2. 每次读的输入**
- 非最终读与登记一致：音频到 t_r，后验到 t_r − 1.04 s。
- 最终读：后验按 `online_decode_finalpost.final_cut_ms(t, close_detect)` 截断。
  - 这与 A′ 解码（`--final-read-post close_detect`）以及 v2′ 训练（`--final-read-full-post 1`）一致，也就是登记里"finalpost"的意思。
  - 最终读在 softmax 之前屏蔽 `<wait>`，与 Engine.read、v2′ 的 pass 1 一致。
- 不做后验扰动；上下文为空，与 A′ 解码的 `--context 0` 相同。

**3. 短语块的格式**
- 每块是一个闭合的 G-STAR 段：`<|spk k|><|t a|>文本<|t b|>`。
- 每块的源端起止时刻，按话语内的字符比例计算，与 `utt_chunks` 同一规则。每个标点块的末块终点，与 `utt_chunks` 给出的完全相同（已断言）。
- s_j 是该块全部 token 的平均对数概率，包括说话人 token 和时间 token（登记原文是"各 token"）。

**4. 规范顺序**
- 用 S_prop 的标签顺序：(min(源端终点 + 1.0 s, 窗口长度), 源端起点)。
- 这与 sched_v1 的 S 用的是同一个排序键。

**5. 窗口与参考**
- 用 S0-3 的规则：重叠话语都要 ≥ 0.9 落在窗口内，至少有一句，且都过 §11.5 门。
- 实现与 `build_windows_zh2en` 的 windows_train_diar 逐窗一致。测试 (g) 在 train16 的 2 个会议上对比过，只读元数据，不碰音频和模型。
- 槽位用会话映射 `slot_map.json["lowlat"]`，与 sched_v1 / v2′ 相同。

**6. LAAL 的单元**
- 单元沿用 `metric_headroom.assign` 的划分：同一说话人间隔 < 1 s 的话语合并。
- 每个参考词归入它自己话语所在的单元，不经过假设段的分配。
- 只平均"完整"单元，即单元里每句话都在 kept 窗口中：1564 个，另有 208 个不完整单元未计入。

**7. 模型加载**
- 权重与 A′ 相同：v8 merged，再在内存中合入 v2′ step_03000（`decode_crf_ckpt.apply_ckpt`）。
- 为了满足每卡 ≤ 60 GiB 的要求，模型拆在两张卡上，每卡峰值 32.9 / 29.8 GiB。A′ 解码当时用单卡。
- 数值上的差别只在 bf16 批次噪声量级。

## 6. 事后诊断（未预登记，不作判定）

文件：`analysis/diagnostics.json`。

**跳变里约一半来自块头 token**
- e_j 处均值的跳变 = 块头部分 + 文本部分：
  - 块头（说话人 + 起止时间 token）：均值 1.09；
  - 文本 token：均值 0.92。
- 所以 e_j 有一部分反映的是"时间戳和说话人什么时候可以预测"，不完全是"译文内容什么时候确定"。
- 时间 token 的值来自比例估计，这也部分解释了为什么 e_j 正好落在比例源端时刻附近。

**模型没见过句中切块**
- 非末块的终止时间 token，在最终读的对数概率中位数是 −16.0。
- A′ 只在标点处结束过段，≤ 4 词的切块对它是分布外的。
- 这是一个大致恒定的偏移，对 argmax 影响不大，但说明重训必须学会这种新格式。

**部分块在内容还没把握时就写了**
- e_j 处达到的收益占"首读到末读总收益"的比例：中位数 0.97；但 p10 只有 0.40。
- 也就是约 10% 的块在模型只拿到不到一半的最终把握时就写出。

**整体判断**
- S_lik 基本是"源端听到比例位置就写"，几乎不留 lag，也不为中英语序调整等待。
- 因此 0.81 s 和 B-1 一样是偏乐观的标签上界，不能当作重训后能达到的 LAAL。
- 重训时建议：
  - 保留 v2′ 的推迟隐变量（允许晚 1–2 次读），由似然吸收比例对齐和块头带来的过早；
  - 逐级过 ASR-BLEU 门槛。
