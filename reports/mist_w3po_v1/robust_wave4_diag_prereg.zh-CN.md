# 鲁棒第四波：三个前向诊断（路由翻转 / 注意力 sink / 视图翻转）预登记

2026-11-19 晚（布拉格），写于任何诊断数字之前。用户："开始启动"（对 `robust_paper_ideas_v2.zh-CN.md` 中 #2、#3、#4 三个诊断）。

## 共同设定
- **模型：** 底座 Thinker，即原始 Qwen3-Omni-30B-A3B-Instruct，不加适配器。在 HF bf16 下运行，加载方式与提示同 T 组（`voicecond/wave3_T_thinker.py`，si_thinker_stream 的基础提示）。只做前向，不训练，每个诊断一个设置。
- **数据：** CoVoST 2 validation 的干净 / 带噪孪生对，每方向 300 句（S1 的数据集 (a)，`wave1_K2K3K5/data/manifest.jsonl`）。
- **句级损失变量（预先定好）：**
  - 主：S1 的 LA2 句级 chrF 下降（干净 − 带噪；S1 输出，BLEU 前先做 `normalize_for_bleu`）；
  - 次：T 组整句读完的句级 chrF 下降。
- **混杂控制：** 同时报告控制每句 BVR（`bvr_db`）后的偏 Spearman。
- **判读：** 主变量上两个方向都达到门槛，才认为这一环"放大了噪声"，再为对应方法写预登记。不通过就停止，不改设置重试。
- **卡位：** #2 用卡 0–1，#3 用卡 2–3，#4 用卡 4–7。
- **输出：** `eval_outputs/mist_w3po_v1/wave4_diag/{route,sink,views}/`，日志 `logs/mist_w3po_v1/wave4/`。

## #2 MoE 路由翻转（依据：NeurIPS 2022，On the Adversarial Robustness of MoE）
- 用参考译文做教师强制，干净和带噪各前向一次。记录 LLM 每个 MoE 层每个位置的 top-k 专家集合（k = 模型配置的激活专家数）。
- 翻转率 = 1 − Jaccard(干净集合, 带噪集合)。
  - **目标文本位置**为主；音频位置另报（两边音频长度相同，逐帧对齐）。
  - 句级翻转率 = 所有 MoE 层、所有目标位置的均值；另报分层曲线。
  - 同时记录每层路由 margin（第 k 与第 k+1 个路由 logit 之差）在干净输入上的分布。
- **门槛：** 两个方向上，Spearman(句级翻转率, 主 chrF 下降) ≥ 0.3，且 p < 0.01。

## #3 注意力 sink / 离群 token（依据：NeurIPS 2025 test-time registers；ICLR 2025 VAR）
- 用参考译文做教师强制前向，取 LLM 每层残差流中的音频位置。
  - 离群 token：范数 > 该句该层音频位置范数中位数的 **10 倍**。
  - 每层记录离群 token 比例，以及目标文本位置对离群 token 的注意力质量（各头平均）。
  - 另记录音频编码器输出层的离群比例。
- 句级量 = 各层均值。
- **门槛（两项都要满足）：**
  - 带噪的离群注意力质量高于干净：配对 Wilcoxon p < 0.01；
  - 两个方向上，Spearman(句级"带噪 − 干净"注意力质量增量, 主 chrF 下降) ≥ 0.2。

## #4 固定视图下已提交 token 的翻转率（依据：MEMO / TPT / ZERO）
- 对象：S1 LA2 在带噪和干净输入上的每个**非最后**提交块。
- 复现提交时刻：音频截到该块的 `write_ms`，教师强制此前已提交的文本，再教师强制该块文本，取每个 token 位置的 argmax。
- K = 8 个固定视图（看数前定死）：
  - 时移 +20 ms / −20 ms（开头补零或裁掉）；
  - 变速 0.95 / 1.05（重采样）；
  - 增益 +3 dB / −3 dB；
  - 低架 +3 dB @ 300 Hz；
  - 高架 −3 dB @ 3 kHz。
- 块的翻转率 = 该块 token 中，有至少一个视图下 argmax ≠ 已提交 token 的比例。
- 块的标签：块内 token 有一半以上落在与 T 组整句译文（同一条件）的 LCS 之外 → "错"，否则 → "对"。分词规则同 `wave3_d_cpu.py`。
- **门槛：** 带噪中→英上，翻转率区分"错 / 对"块的 AUROC ≥ 0.65。其余方向和条件照列。
- 这只是诊断，不会成为提交规则（提交策略仍是 LA2，不碰 QABC）。
