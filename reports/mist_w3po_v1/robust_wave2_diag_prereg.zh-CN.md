## 问题

## S1 单说话人基线（对照，不混用组件）
- 系统：用户原单说话人同传基线（QABC 论文系统，Thinker + T1c），按论文的默认设置（b0=1、Δ=1）原样运行，不做修改。
- 数据：第一波已建的 CoVoST 2 validation 干净 / 带噪对（`eval_outputs/mist_w3po_v1/wave1_K2K3K5/data/manifest.jsonl`），每方向 300 句；另在 OpenBroadcast-SI dev 的带噪 / 干净流上逐说话人切成单说话人流各跑一次。
- 指标：翻译文本 BLEU、ASR-BLEU（两个 TTS 种子）、LAAL（单说话人论文的 D1 与本项目的 D2 都报）、PESQ。
- 判读：单说话人带噪损失 < 0.5 BLEU → 损失主要不在翻译模型。

## S2 多说话人：真实说话人分离对照
- 在 OpenBroadcast-SI dev 带噪（id2-dev）上，把说话人分离后验换成由真实标注生成的后验，其余与 B 相同，两个种子。
- 与同一 dev 上的 B（日志器后验）和干净版 B 比较：真实分离收回的比例 = (BLEU_oracle − BLEU_B,noisy)/(BLEU_B,clean − BLEU_B,noisy)。
- 判读：收回 ≥ 50% → 损失主要来自说话人分离 / 切分，下一步方向转向抗噪流式说话人分离与切分。

只做诊断，不选方法、不调参；test 不读。

### 判读（按本预登记）
- **单说话人带噪损失不小于 0.5 BLEU**，四格中有三格是这样。
  - 英→中 OB-SI dev 文本 −2.81，CI 不含 0。这比多说话人链上的 1.5–1.9 还大。
  - 中→英 CoVoST −3.22、OB-SI −2.79。
  - 只有英→中 CoVoST 是 0.24，CI 跨 0，与第一波 P2a 的 0.20 一致。
- 结论：**OpenBroadcast-SI 上的 BLEU 噪声损失主要在翻译模型（Thinker 听带噪语音）本身**，不能归给多说话人链路（分离、窗口、归属）。在同一批 dev 句子上，单说话人基线按参考切段后照样损失约 2.8 BLEU。
- 无串音子集的点估计更小（+1.96 / +1.15），CI 跨 0，说明串音和噪声叠加时损失更大。但样本少，不作结论。
- 附带发现：
  - **输出语音的 PESQ 掉 0.8–0.9**，所有格 CI 都不含 0。T1c 用本句带噪源音频做音色提示，把背景噪声也"克隆"进了译文语音。
  - 延迟上带噪只慢 0–0.1 s。
- 与第一波的区别：第一波 K2 测的是多说话人 Thinker B，CoVoST 中→英 −0.42。本次是基础 Qwen3-Omni LA2，中→英 CoVoST 掉 3.2。两个系统不同，不可直接合并。
