# 鲁棒新论文：跨领域 idea 调研 v2（ICLR / ICML / NeurIPS / CVPR）

2026-11-19 晚，布拉格。约束见 memory `robust-paper-constraints`：
- 底座严格不含 QABC（LA2 + 原始 Qwen3-Omni + T1c）；
- 中→英、英→中只用一个模型 / 一套设置；
- 不用蒸馏，不用 SEEN；
- 提交策略固定为 LA2。

调研方式：3 个代理并行（训练侧 / 推理时 / 音色与流式稳定性）。引用由代理在线核对；语音领域的"新颖性"只做了 1–2 次检索，没检到不等于不存在。

## 依据（诊断结论，见 `robust_wave3_la2diag_prereg.zh-CN.md`）
- 中→英：噪声损失 3.22，oracle 提交后剩 0.94。约 70% 来自带噪前缀上相邻 draft"一致地错"。根源是前缀阶段靠语言先验去猜，本质仍是前缀感知问题。
- 英→中：整句读完也会掉，无串音切段上 4.28。属于感知问题。
- 免训练的输入侧方法都已失败：
  - 噪声与语义线性不可分；
  - logit 对噪声水平不是线性的；
  - 噪声水平估计不能预测句级损失。
- 输出音质每格掉 0.8–0.9 PESQ。V 组三个音色臂把 PESQ 拉回约 +1.1 到 +1.4。

## 排除及理由
- **MBR 草稿**：QABC 论文附录（`bayes_simul_s2st_v6` 的 Extensions that did not help）已报告，搭配 LocalAgreement 时 BLEU 更低、提交更晚。
- **采样草稿 + LA2**：同上，采样 draft 更难达成一致；它本质上是蒙特卡洛稳定性检验，离 QABC 太近。
- **熵最小化 TTA（TENT / SAR / MEMO 式）**：会让"自信的错误"更自信；SUTA、SLM-TTA 已做过。
- **扩散净化**：−14 dB 下会把音素细节一起抹掉；HDemucs 伤害干净输入的结果已预示失败。
- **常量激活 steering**：等价于已失败的均值差 / 线性子空间方法。
- **对比解码**：Whisper-CD 已做过，我们这里也掉了 3.7 BLEU。
- **churn / 草稿一致性正则**：方向相反，问题是 draft 太一致而非不稳；而且多数做法基于蒸馏。
- **AugMix-JSD、R-Drop 式一致性**：有变相蒸馏之嫌。
- **噪声条件 adapter**：噪声估计不能预测损失（ρ = −0.04）。
- **等待 / 弃权 token 训练**：实质是读写策略，与"LA2 不变"冲突，SimulMT 里也已有大量工作。
- **负条件引导、音色候选的输出空间平均（TDSM）**：前者新意不足，后者与已有流式音色后验太像。

## 建议顺序
1. 并行跑三个前向诊断（#2 路由翻转、#3 sink、#4 视图 AUROC）。都不训练，一个设置。
2. 至少一个诊断与 chrF 下降显著相关时，才写对应方法的预登记。
3. #1 Fishr 双向 LoRA 是唯一能同时覆盖 (a)、(b) 的训练方案，但相对纯数据增强的边际收益没有把握，必须同时训练 ERM-LoRA 作对照。
