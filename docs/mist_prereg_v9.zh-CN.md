## 1. 系统（全部为整场会议在线运行；读取间隔 1 s，分离器前瞻 1.04 s；窗口与 v8 相同）

| 代号 | 模型 | 提交方式 |
|---|---|---|
| **S** | MIST-Simul（v8 的 seed1 前缀模型） | 学到的 wait |
| **LA2** | 同一前缀模型 | LocalAgreement-2（v8 B3） |
| **Lag1 / Lag2 / Lag3** | 同一前缀模型 | 固定滞后：只提交预测结束时间 ≤ t − L 的完整片段，L = 1 / 2 / 3 s |
| **Blk2** | 同一前缀模型 | 整段提交：每 2 s 读取一次，每次解码到结尾，提交预测结束时间 ≤ t 的完整片段（即 `--policy lag --lag-ms 0 --window 2`） |
| **Rel** | v8 的 speaker-blind 前缀模型（C1），`--zero-sd` | 学到的 wait，因果重标（prereg_v8 第 3 节） |
| **D1** | Rel 的同一份输出 | 多标签拆段，规则见第 3 节 |
| **D2** | 同一个 speaker-blind 前缀模型 | 按轮次切分输入，规则见第 3 节 |

Lag2 已在子集上解码过的窗口直接复用，按 window id 合并，不重复解码。

## 2. 指标

与 prereg_v8 第 2 节相同：
- tcpBLEU（全部 / 重叠区 / 非重叠区），按时间比例拆分；
- 并发说话人召回（CR）、塌缩率、重复率、短插话召回；
- 文本完成延迟（提交时刻 − 参考单元结束时刻）。

**"计算量"**：每次读取是否解码到结尾（LA2、Lag、Blk 是；S、Rel、D1 否）。另报 v6 实测的单次读取耗时中位数；只作描述，不进入检验。

## 3. 对照的构造（先定死）

**D1 多标签拆段**：对 Rel 的每个输出片段 [a, b]：
- 取提交时刻已能看到的分离器帧（只用 ≤ 提交时刻 − 1.04 s 的帧），在 [a, b] 内求每帧活跃槽位（后验 > 0.5）。
- 段内活跃过的槽位只有一个时：贴这个槽位。
- 段内有两个以上槽位各活跃 ≥ 0.24 s 时：
  - 在主导槽位切换的帧上把时间切开；
  - 文本按时长比例切分（中文按字、英文按词）；
  - 每个子段贴各自的主导槽位。
- 没有可用帧时：按 Rel 的回退规则处理。
- 去重：同一槽位 5 s 内 chrF ≥ 50 的子段只保留第一个。

**D2 按轮次切分输入**：
- 轮次的生成：
  - 用在线（lowlat）分离器的每个槽位单独生成轮次，规则与 v7 级联相同：活跃 > 0.5，< 0.4 s 的空隙合并，最短 0.24 s，两侧各补 0.1 s；
  - 不同槽位的轮次允许重叠；超过 20 s 的轮次按 20 s 切开。
- 每个轮次：
  - 作为一个在线窗口，送进 Rel 用的同一个 speaker-blind 模型，用学到的 wait 策略，`--zero-sd`；
  - 开窗时刻 = 轮次开始 + 1.04 s，关窗时刻 = 轮次结束 + 1.04 s；
  - 窗口内的所有输出片段都贴这个轮次的槽位。
- 混合音频不做分离，即同一个翻译模型的轮次级联。

## 4. 确认性检验（11 项，统一做 Holm 校正）

**统计方法**：
- 按会议做精确符号翻转置换检验（16 场或 20 场会议）；
- 10k 次会议重抽样 bootstrap 区间，BLEU 差值每次叠加一次解码噪声 N(0, σ_dec(n)²)；
- 判为"成立"必须同时满足 p_Holm < 0.05 且区间不含 0。

| 编号 | 集合 | 假设 |
|---|---|---|
| **E-pareto-{en2zh, zh2en, ali}** | 3 | S 不被 {LA2, Lag1, Lag2, Lag3, Blk2} 中任何一个支配 |
| **E-ovcap1-{en2zh, zh2en, ali}** | 3 | tcpBLEU-ov(S) > tcpBLEU-ov(D)，对 D1 和 D2 **都**成立 |
| **E-ovcap2-{en2zh, zh2en, ali}** | 3 | CR(S) > CR(D)，对 D1 和 D2 **都**成立 |
| **E-far** | AMI SDM 远场，En→Zh | tcpBLEU-ov(S) > tcpBLEU-ov(Rel)，两者都用在 SDM 音频上重跑的在线分离器 |
| **E-ali-hum** | AliMeeting，DiariST 公开的人工英文参考 | tcpBLEU-ov(S) > tcpBLEU-ov(Rel) |

**E-pareto 的检验方法**：
- 对每个竞争者 C，S"不被 C 支配"要求在两个维度中至少有一个显著更好：
  - 质量：tcpBLEU-all(S) > tcpBLEU-all(C)，单侧；
  - 延迟：每会议文本完成延迟中位数 S < C，单侧。
- 该对的 p = 2 × min(p_质量, p_延迟)（两维的 Bonferroni）。
- E-pareto 的 p = 所有竞争者对的 p 中的最大值（交集-并集检验），再进入 Holm 校正。
- 计算量不进入检验；作为第三个维度单独描述。

**E-ovcap 的检验方法**：p = max(p_对D1, p_对D2)。

## 5. 失败或持平时怎么写（先定死）

- **E-pareto 失败**（某个集合上 S 被支配）：
  - 主张改为"可学习的、效果相当的提交方式"，不再说"更好的策略"；
  - 在正文写出支配它的那个对照。
- **E-ovcap1 / E-ovcap2 失败或持平**：
  - 承认 decoder 内融合的增量主要体现在归属上，或者只在部分条件下成立；
  - CR 输给 D2 时，如实写"轮次级联召回更多并发对"。
- **E-far 失败**：写进 Limitations：远场条件下优势不成立。
- **E-ali-hum 失败**：AliMeeting 在人工参考上也没有重叠区优势，摘要写成"归属改善、质量持平"。
- **人工参考与机器参考方向不一致**：两者都报告，以人工参考为主。

## 6. 探索性分析（不进入 Holm 校正）

- **AliMeeting 人工参考**：全部指标的重新打分；对齐率；与机器参考的方向是否一致。
- **P1-1 敏感性**：
  - 重叠阈值 10/20/30%；collar 0/0.5/1/2 s；重叠对最短时长 0.2/0.5/1.0 s；
  - "多对一"约束：同一参考单元以外，泛化的短译文（≤2 个词或字）不能同时匹配多个参考单元。
- **P1-2**：在线去重（同一说话人 5 s 内 chrF ≥ 50）× 短插话兜底（prereg_v8 修正 1 的规则），2×2。
- **P1-3**：Zh→En 和 AliMeeting 的全覆盖补评，以及分母流转表。
- **P1-4**：speaker-blind 前缀模型的另外 3 个种子（En→Zh 2 个，Zh→En 1 个，配置与 C1 相同），报告 E-ov 在各种子上的范围。
- **P1-6**：SDM 远场的全部指标、DER。
- **P1-8**：成本。
- **P1-9**：8 个翻转窗口在 fp32、batch 1 下成对重解码，比较时间戳、说话人和提交时刻。
- **M10**：每人一个声道时，最慢说话人的延迟。
- **M15**：分层报告。
- **其余**：Lag1/Lag3/Blk2 的全部指标，Pareto 图。
