## 0. 审稿结论与对照 v10 核实的事实

审稿人认可的部分：问题定义、Assumption 1 的严谨化、同 Thinker/Talker 的主对照、负面结果的公开。拒稿的三条 P0：
1. 连续播放时钟下 QABC 不领先 LA2（Table 41），Talker 积压严重；
2. 连续阈值 τ(q) 没有赢二值队列门（Table 37，C2 预注册为零结果）；
3. 五 seed、按 talk 重采样后，RealSI En→Zh 不稳健，而摘要的主表述仍是单 seed。

对照 v10 代码和正文核实后，有三点审稿人没看到、但决定方案走向：

| 事实 | 出处 | 含义 |
|---|---|---|
| Table 41 的"一条时钟"是**事后重排时间**：用句级运行已有的块和时长，放回录音时间轴上播放。决策时每句的队列从 0 开始，QABC **从没看到跨句积压** | `scripts/v10_talk.py` 头注释 | Table 41 没有测到 QABC 的机制本身。真正的连续实验要让解码时的 q_k 带上前一句留下的积压。这是 v11 最关键的新实验，也必须在 rebuttal 里说清楚 |
| 积压对两种策略都存在：Talker 说话比讲者慢，句级协议把这个问题对两边都藏住了 | appendix_v10 "One clock per talk" | 需要吞吐控制（对两边一样），否则任何策略都追不上 |
| τ(q)=1−(1−τ₀)·max(0,Δ−q)/Δ，只在 q∈[0,Δ] 上连续变化，q≥Δ 后等于上限 0.9975 | method.tex:173 | 句级重置时 q 大多很小，连续阈值和二值门在多数决策上相同，C2 难有差别；连续时钟下 q 分布宽得多，两者才可能分开 |
| 已有 Talker 提速策略 `--speed-policy queue`（按积压升 speed token，最多 6 步） | si_infer.py:356 | 吞吐控制可以直接复用，不必新写 |
| `main.tex` 首行注释仍写 v9 | main.tex:1 | 次要意见，v11 修正 |
| 本地没有 COMET（两个环境都没装 `comet`，evaluation_models 里也没有） | — | M4 的参考译文语义指标需要你决定（见 §5） |

标记：**[A]** 用已有输出分析，不需要 GPU；**[B]** 需要新的 GPU 运行；**[W]** 写作/理论。

## 1. P0 问题

### M1 [Critical] 连续时钟下的优势 → 真正的连续实验 + 吞吐控制，预先写好"失败就收窄范围"的规则

- **[B] 连续解码驱动**：RealSI 每段录音按句顺序解码，每句开始时的队列状态 q 等于上一句播放后剩下的积压（用 Talker 实际时长或速率 r 推进），决策时就看到真实积压。QABC 和 LA2 用同一驱动、同一 Talker、同一吞吐控制。
- **[B] 吞吐控制**（对所有策略一致，参数只在非测试数据上调）：
  - (a) 现有的 `--speed-policy queue` 按积压提速；
  - (b) 去掉块间停顿；
  - (c) 可选：积压超过上限时压缩或跳过最旧未播块，并报告被跳过的比例。
  
  调参用非测试的长语音，例如把 dev 句子拼成伪 talk。RealSI 和 ACL 一律不调参。
- **[A/B] 报告**：等延迟 ASR-BLEU（连续 LAAL 轴）、平均和 95 分位积压、尾延迟、积压增长斜率（s/min）、实时因子、talk 结束后的播放尾巴。同时报告 v10 的事后重排结果，作为"不让策略看到积压"的对照。
- **预注册 H1（prereg_v6）**：连续时钟、带积压决策、同一吞吐控制下，QABC 对 LA2 的 E1>0，两个方向，Holm 校正。主重采样单位是整段 talk。每方向只有约 10 段 talk，功效低，预注册里写明。
- **预先写好范围规则**：两个方向 H1 都不成立，就把标题、摘要和引言的适用范围收窄为"句级重置的流式 S2ST"（sentence-reset streaming），并在引言里删掉会议/讲座等连续场景的动机；只有一个方向成立，就按方向分开写。
- **[W] rebuttal Q1/Q9**：说明 v10 Table 41 是事后重排；给出吞吐控制方案和"实时部署边界"（Talker 速度/讲者语速之比、可持续的最大积压）。

### M2 [High] 连续阈值 vs 二值门 → 先解释零结果，再在连续时钟下重测，否则如实降级

- **[A] 解释**：用 v10 已有日志统计 RealSI 决策时 q 的分布，以及连续阈值和二值门做出不同决定的比例。如果大多数决策两者相同，C2 的零结果是预期之内，论文要说清楚。
- **[B] 预注册 H2**：连续时钟下（q 分布宽），同一后验上比较四种规则：τ(q)、二值门、最简单的分段线性阈值、块内 D_k(u) 规则（seq-B）。用 2 个 adapter seed × 2 个 Talker seed，talk 级 bootstrap 区间，并报告各规则的部署成本（都是 O(1)，基本没有差别）。
- **[W] 写法**：如果 H2 还是零结果，贡献改写成"队列信息有用（Table 12 对常数风险显著）；推导出的 τ(q) 给二值门提供了理论解释，二者是同等证据下可部署的替代"。rebuttal Q2 明确承认这一点，不再说连续形式本身有独立的实用收益。

### M3 [High] 统计主张的层级 → 主表述改用多 seed + talk 聚类

- **[W] 统计协议表**：每个检验写明推断单位（句子/talk/adapter seed/Talker seed）、泛化对象、单侧还是双侧、Holm 族、是否预注册、首次看测试集的版本。
- **[W] 主文提升**：五 seed 和 talk 聚类的结果从附录移到正文，和预注册单 seed 结果并列。摘要改成：
  > 预注册单 seed 三项显著；在五个 adapter seed 和整段 talk 重采样下，RealSI Zh→En 和 ACL60/60 稳健，RealSI En→Zh 不显著。
- **[W] Table 2 的表面矛盾**：CI 下界 +0.00 而 Holm p=0.030，在表注里说明这是单侧检验加双侧区间加四舍五入。
- **[W] rebuttal Q5**：唯一的主要声明是"对新 talk 和新 adapter seed 的泛化"，用 talk × seed 的层级 bootstrap 作为严格版本。

## 2. P1 问题

### M4 [High] 语音分数与"正确且及时的提交文本" → 三条时间轴 + 语义/不可撤销错误

- **[A] 三条时间轴并列**：提交时刻、听到时刻、词对齐 LAAL，各报一次文本质量。
- **[A] 不可撤销错误率**：已提交单位后来和整句全上下文输出不一致的比例；按源语序重排程度分层（复用 `tab_crossing` 的交叉统计）。Zh→En 单独列出。
- **[A] 严重错误自动检测**：否定、数字、主谓关系。数字和否定用规则检测，主谓关系用本地 LLM 判别并标明是自动结果。不做人工标注（按你之前的决定，写进局限）。
- **[A] 参考译文语义指标**：需要你决定是否安装 COMET（§5）。不装的话，用本地 LLM 做基于参考的判分，并在论文中注明这一局限。
- **[A] 可复听示例**：选几十段，配错误分类，作为匿名补充材料；它不能代替人工听评。
- **[W] 写法**：主张限定为"质量—延迟操作点上的收益"，删掉暗示"单位级校准等于语义正确"的句子。

### M5 [High] 冻结 Thinker 打标签、实际用适配 Thinker → 测量偏移，把偏移项写进界里

- **[A/B] 用适配 Thinker f_θ 重新打标签**：v10 只做了 dev 的 ECE，v11 在 dev 和一部分训练 read 上补齐，报告 posterior NLL、ECE 和 decision loss，分别相对 f₀ 标签和 f_θ 标签。
- **[W] 理论**：Theorem 2 加一项目标偏移。由耦合不等式，TV(p_{f₀}(·|o), p_{f_θ}(·|o)) ≤ P(S⁽⁰⁾≠S⁽θ⁾ | o)，所以对 f_θ 的 regret ≤ 原界 + 2·E[P(S⁽⁰⁾≠S⁽θ⁾|o)]。后一项可以直接用测得的 22%/16% 标签不一致率估计，界因此变成可测量的。另外写明联合 LoRA 下内容项和停止项共享参数，"不竞争"只是经验观察，不是优化上的保证。rebuttal Q3 直接回答"用的是哪个 S_k"。
- **[B]（P1）参数对照**：在 dev 上比较三种设置：冻结内容参数只训停止项、独立停止头、联合 LoRA（现行）。dev 门槛和 v10 相同。
- **[B]（P2，可选）**：用 f_θ 标签再训一轮 adapter（自训练），测试是否收敛。费时（4 卡约数小时），只在算力允许时做。

### M6 [High] 延迟模型与实际播放有差距 → 统一计时模型，三层策略在同一条件下并列

- **[W] 统一计时模型**：块内 D_k(u)、预估语音时长、buffer、加速、合成开销放进同一个模型。
- **[B] 三层并列**：理论策略（Eq.13 精确阈值）、可部署近似（贪心 + logit bias）、最终 FR 策略，在连续时钟和词对齐延迟两条轴上同条件报告。
- **[B] seq-B（D_k(u) 规则）**：v10 中它过了 dev 门槛，但测试集结果已经看过，所以不能在原测试协议上改做确认性检验。v11 把它放进 H2 的连续时钟检验，连续时钟是新协议，测试结果还没看过。
- **[W] 写法**：Theorem 1 的"最优"只对 myopic 单位损失成立，不能用来给部署性能背书，正文里明确写出。

### M7 [Medium–High] 理论适用范围 → 加"理论对象 / 部署对象 / 评测对象"对照表，降调措辞

- **[W]** 正文加一张三列对照表：每个命题的对象、部署时实际用的规则、评测指标。Prop.1、Lemma 2、Prop.3 写明是标准结论（push-forward、Bayes odds 恒等式、proper log loss 分解），贡献改述为"系统性的统一解释"。Theorem 2 写明是单次 read 的 per-decision regret，不覆盖整段已提交前缀，也不覆盖 BLEU/LAAL。
- **[A]（可选）** Corollary 2 的 χ²(Q‖P)：用分类器估计训练 read 分布与 QABC 自身 read 分布之间的密度比，给出 χ² 的粗略估计。估不准就把它列为开放问题。
- **[W]** 有限步累计风险和队列稳定性写成开放问题，不当作延伸保证。

### M8 [Medium–High] 学习型停止策略对照

- **[B] 隐状态探针**：在完全相同的 (o_k, S_k) 样本上，用冻结 Thinker 隐状态训练线性或 MLP 停止头，二元和多类各一个。
- **[B] 带队列输入的分类器**：输入加上 q_k，目标是损失下的 oracle 动作，不做后验解释。
- **[B] 计算预算**：参数量和训练步数与 QABC 的停止部分对齐。先在 dev 上过门槛，再在测试集上和 QABC 比。
- **[W]（P2）** DAgger/行为克隆、另一套 Thinker/Talker、口音/噪声/跨域：默认不做，写进局限。噪声测试只改评测音频，不训练，可以作为便宜的可选项。
