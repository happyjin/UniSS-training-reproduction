## 0. 结论：是实验设置/写法的问题，还是方法本身的问题？

两项让审稿人认为"不 work"的结果（M1 连续时钟、M2 连续阈值对比二值门）主要出在**实验设置和写法**上，方法本身没有被这两项证伪。
但另外有四个真实存在的问题，需要靠改方法或改系统来解决。

| 审稿人认为"不 work"的点 | 核实结果 | 归类 |
|---|---|---|
| M1 连续时钟下 QABC 不领先（Table 41，E1 −0.07/−0.78） | ① 这是**事后重排时间**：句级解码得到的块，事后放到同一条录音时间轴上（`scripts/v10_talk.py`："ASR-BLEU unchanged"）。决策时每句的队列都从 0 开始，QABC **从没看到跨句积压**，所以 Table 41 没有测到它的队列机制。② E1 在两条曲线的"共同范围"上算，这里是 **LAAL 4–13 s 的积压主导区**，而注册检验的范围是 1–3 s。低延迟端 QABC 其实领先：Zh→En 在 3.4 s 有 21.6，LA2 最低只到 4.3 s，那里只有 20.3。③ 同一张表中，每个 Δ 下 QABC 的 LAAL、漂移和播放尾巴都更小（例：Zh→En Δ=3 s，LAAL 13.70→9.27 s，漂移 2.46→1.80 s/min，尾巴 17.6→11.5 s），正文没有提。④ 真问题：Talker 的语速比讲者慢，两种策略的积压都会持续增长 | **设置 + 写法**；④ 是**系统**问题（Talker 吞吐），两种策略都受影响 |
| M2 连续阈值不赢二值门（C2 零结果） | 统计了 v10 RealSI 自身的读取（qrp5 dump，Δ≤3 s，En→Zh 26738 次、Zh→En 30061 次）：68% 的读取 q=0，两种规则都用 τ₀；14–15% 的读取 q≥Δ，两种规则都 hold；只有约 17.5% 在两者之间。按 hazard 累乘估计，两种规则**真正做出不同决定的只有约 5.4%/5.1% 的读取**（未计 π 偏置，是近似值）。也就是说 C2 几乎没有区分能力，零结果在意料之中。另一方面，"用队列"本身很有效：Table 12 中 QABC 对常数风险 QABCΔ 的 10 组配对全部为正（+0.44 到 +2.96），4 组 Holm 显著 | **实验设计（功效不足）+ 主张写法** |
| M3 五个 seed 下 En→Zh 不稳健 | 摘要其实**已经写了**五 seed 均值和 En→Zh 不显著，审稿人"摘要说三项都显著"的说法有偏差。但 En→Zh 各 seed 的 E1 是 0.74/0.62/0.08/0.003/0.34，**两个 seed 接近 0**，这是真问题（s4 还偏离了配方：micro-batch 16 加 2 步累积）。表格写法也有矛盾：Table 3 写"Seeds>0: 5/5"，最差却显示 +0.00（实为 +0.003） | 一部分是**写法**；**En→Zh 的 adapter 训练方差是方法问题（训练稳健性）** |
| M4 提交时刻的文本 E1 不显著 | 审稿人理解正确。不过要说明：提交时刻这条时间轴**不计播放队列**，而利用队列余量正是 QABC 的设计目标，所以这条轴上看不到优势属于预期，不是方法失败。审稿人要求的不可撤销错误率、严重错误分析是合理的 | **写法 + 需要补分析** |
| M5 冻结 Thinker 打标签、实际用适配 Thinker | 审稿人正确：22%/16% 的读取稳定长度不同，对冻结标签 ECE 为 0.106/0.105，对适配标签为 0.083/0.092 | **理论与实现有缺口**（影响不大，但必须写进界里） |
| M6 D_k 与实际播放差距大 | 审稿人正确：D_k 高估约 2 倍，相关 r≤0.16；块内 D_k(u) 的相关 r≥0.91。seq-B 规则过了 dev 门槛，测试集上 +0.19/+0.37（不显著） | **方法组件确实不准**，而且已经有现成的改进 |
| M7 理论范围 | 合理，写法问题 | 写法 |
| M8 缺学习型停止策略对照 | 合理 | 缺实验 |

v10 中能证明方法有效、站得住的证据：
- 预注册的单 seed 检验三项都显著；
- 五个 seed 全部 ≥0；
- Zh→En 和 ACL60/60 在五 seed 和整段 talk 重采样下都稳健；
- 队列感知对常数风险全部为正。

真正需要靠改方法或改系统解决的有四点：
1. Talker 吞吐低于讲者语速；
2. 部署用的延迟代理 D_k 不准，要换成 D_k(u)；
3. En→Zh 的 adapter 训练方差大；
4. 冻结标签和适配 Thinker 之间的目标偏移。

## 1. 逐条：审稿意见是否合理、有没有误解

- **M1（合理，但对 Table 41 的解读来自我们的写法）**

  - 误解的部分：把 Table 41 当成"真实连续部署下 QABC 失效"。原因是我们写了"lets the queue carry over"，却没写决策看不到积压，也没写 E1 的延迟范围是 4–13 s。
  - Rebuttal Q1、Q9 要正面回答：v10 做的只是事后重排；v11 做了真正的连续实验，并加了吞吐控制。
- **M2（合理）**
  - 合理的部分："队列有用"和"连续形式本身更优"要分开，这个要求成立。
  - 审稿人没看到的部分：二值门的切换点"排队满一个读窗"正好等于理论里 D_k=0 的边界，所以二值门其实是 τ(q) 的离散化，不是独立的启发式。再加上两者只在约 5% 的读取上做出不同决定，C2 本来就测不出差别。
- **M3（基本合理）**
  - "主推断单位要明确"的要求合理。
  - "摘要没加限定"不准确：摘要已经写了五 seed 和 En→Zh 不显著。
  - 但正文和表格中"5/5 >0 / +0.00"、"CI 下界 +0.00 但 p=0.030"这两处，确实会让人怀疑。
- **M4（合理）**：没有误解。需要补上提交时刻、听到时刻、词对齐 LAAL 三条轴，以及不可撤销错误和严重错误分析。
- **M5（合理）**：没有误解。用耦合不等式可以把偏移项直接放进 Theorem 2。
- **M6（合理）**：没有误解。v10 已经测出 D_k 不准，却仍然用它做主阈值，这是我们的弱点。
- **M7（合理）**：写法问题。
- **M8（合理）**：要补学习型停止策略对照。

## 3. v11 修改方案

v11 写在新文件夹 `paper/bayes_simul_s2st_v11`（branch v11），v10 不动。新预注册 `prereg_v6` 在任何 v11 结果算出前提交。
标记：[A] 用已有输出分析，[B] 需要新的 GPU 运行，[W] 写作/理论。

### P0-1 真正的连续时钟（M1）
- [B] **连续解码驱动**：每段录音按句顺序解码，每句开始时的 q_k 等于上一句播放后剩下的积压（用 Talker 实际时长推进），决策时就能看到真实积压。QABC 和 LA2 用同一驱动、同一 Talker。
- [B] **吞吐控制**（对两种策略一样，参数只在非测试的拼接长语音上调）：
  - 现有的 `--speed-policy queue`（按积压升 speed token）；
  - 去掉块间停顿；
  - 可选：积压超过上限时跳过最旧未播块。这一项只放附录消融。
- **预注册 H1**：连续时钟下，QABC 对 LA2 的 E1>0。
  - 延迟范围事先写死：用 LA2 曲线的连续 LAAL 分位数，或固定的 1–5 s。
  - 主重采样单位是整段 talk，两个方向做 Holm 校正。
  - 同时报告：平均和 95 分位积压、漂移、尾巴、实时因子、各 Δ 的 BLEU。
- **范围（11-02 按你的意见修订，撤回"收窄为句级重置"）**：
  - 标题和主协议保持"同传 S2ST + 标准的逐句/逐段评测"，和其他同传论文在同一口径上比较。
  - 连续播放作为额外的部署分析，结果无论好坏都如实报告：不领先时写成 Talker 吞吐的局限（对所有策略都一样），不改标题。
  - 引言里"会议/讲座连续场景"的措辞，以实际得到的证据为准。
- **为什么值得做**：v10 中的积压漂移只有 0.3–2.5 s/min，而且 QABC 的漂移每档都比 LA2 小。现成的吞吐手段已经能提供约 1.1–1.2 倍提速：FR 的 speed token 最多 +10%，播放端最多 1.1×，再加上压缩停顿。所以积压很可能可以稳住，LAAL 会回到接近逐句评测的水平。
- **v10 的事后重排表**：不删，放附录，写明"决策时看不到积压，不检验队列机制"，并按 Δ 给出 BLEU。

### P0-2 延迟模型和阈值形式（M2、M6）
- [B] **主规则不换（11-02 修订）**：仍用注册时的 D_k 规则。D_k(u)（seq-B）作为附加对照，放进 P0-1 的同一批连续运行里，几乎不增加成本。M6 主要靠写法回应：Theorem 1 的最优性不用来给部署性能背书，并报告 D_k 的误差和 seq-B 的结果。
- [B] **预注册 H2**：在连续时钟下（q 分布宽，规则之间有区分能力），同一后验上比较 τ(q)、二值门、分段线性、seq-B 四种规则。用 2 个 adapter seed × 2 个 Talker seed，talk 级区间，并报告规则之间做出不同决定的比例。
- [W] **H2 仍为零结果时的写法**：贡献改为"队列信息有用（Table 12）；推导出的 τ(q) 和 D_k(u) 给出二值门的切换点和连续形式；在同等证据下，二值门是可部署的替代"。

### P0-3 统计主张和 En→Zh 的 seed 方差（M3）
- **主结论仍用单 seed（11-02 修订）**：主结论是预注册的单 seed（s0）检验，这和多数同传论文的做法一致。v10 已经公开过五 seed 结果，不删，作为稳健性分析如实报告："每个 seed ≥0；均值在 Zh→En 和 ACL60/60 上显著，在 En→Zh 上 +0.36，不显著"。不新训 adapter。
