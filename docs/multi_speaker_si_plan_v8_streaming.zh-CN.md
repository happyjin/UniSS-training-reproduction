## 1. 非流式"过关判据"(满足后才进入流式)

在 AMI test 的 2,375 个已审查窗口上:

| 判据 | 要求 |
|---|---|
| 格式 | ≥98% 的窗口输出能解析出片段;空输出 ≤2% |
| 翻译质量 | 不分说话人的 BLEU 不低于 B-off(原版 Thinker 整窗翻译)超过 2 BLEU |
| 说话人 | 整场 cpBLEU 显著高于 B-off;说话人数完全正确率 ≥ 0.8 |
| 时间 | 输出片段的 DER 不比 Nemotron 自身 DER 差超过 5 个点(同一参考口径) |
| 分离支有效 | O-G1 在 cpBLEU 或 DER 上显著优于 O-nosd(O-nosd 晚一些出结果;前三条满足即可先启动流式) |

不满足时的常见原因和对策(先看结果再定):

| 现象 | 可能原因 | 对策 |
|---|---|---|
| 说话人编号乱 | 说话人 token 信号弱;新 token 学习率偏低 | SD 投影器和新 token 用 5 倍学习率;训练更久;局部编号(段内按出现顺序)作为过渡 |
| 时间偏差大 | 时间 token 学得慢 | 时间 token 权重从 1.5 提到 2;训练更久 |
| 翻译质量明显下降 | LoRA 过拟合 AMI;单人数据比例不够 | 单人行比例提高到 30%;降低学习率 |
| 重叠区漏译 | 单路序列化的固有短板 | 记录下来,流式之后再上 SCOPE 的条件链 / BSSC |

## 2. 两条流式路线

| 编号 | 系统 | 训练 | 说明 |
|---|---|---|---|
| **S-LA2** | O-G1 原样 + LocalAgreement-2 | **不训练** | 每 Δ 秒读一次,续写到结束;本次续写和上次续写的最长公共前缀(token 级,包含说话人和时间 token)提交。最快拿到流式结果,也是"非流式模型直接流式化"的基线 |
| **S-T** | 以 O-G1 为底座继续训练的流式模型 | **训练** | 每次读取只输出可提交的片段,然后输出 wait 标记 `<\|box_end\|>`,段尾输出结束标记。模型自己学"什么时候说"(按参考时间表,非贝叶斯) |

先做 S-LA2(零训练,当晚可出),再做 S-T。

## 3. S-T 的训练

### 3.1 初始化(从训练成功的非流式模型继续)

| 部件 | 来源 |
|---|---|
| Thinker 权重 | O-G1 的合并模型 `eval_outputs/.../thinker_gstar_o1_*/thinker_merged`(LoRA 已合并) |
| 259 个新 token 的嵌入行和输出头行 | 从合并模型的 151676–151934 行读出,继续训练 |
| SD 投影器 | 载入合并模型目录下的 `sd_proj.pt`,继续训练 |
| 新 LoRA | r32,全部 48 层注意力,从零开始(叠加在合并后的权重上) |
| 合并 | `merge_thinker_gstar.py --base <O-G1 合并模型>`:新 LoRA 合进去,新 token 行和投影器写成流式训练后的版本 |

### 3.2 数据

**读取行**:来自已审查的参考窗口(train 21.6k 个,validation 3.2k 个)。
- 每 Δ = 1 s 读一次,外加窗口末尾一次。
- 每行的内容:
  - 音频:截至读取时刻 t;
  - 后验:用 Nemotron **流式配置**,并且**只用 t − 1.04 s 之前的帧**(分离器的前瞻还没到的帧置零,推理时也一样);
  - 前缀:截至上次读取已提交的片段;
  - 目标:本次新提交的片段 + wait 标记;最后一次读取为剩余片段 + 结束标记。

**片段粒度**:句子按中文标点切成块,每块是一个片段 `<|spk k|><|t a|>译文块<|t b|>`。
- a 和 b 是这块对应的源语音起止,用 AMI 词级时间确定;
- 块的提交时刻 = 源结束 + 1 s;
- 片段按提交顺序排列。

**比例**:
- 读取行:没有新内容的读取行保留一半;
- 整窗行占 20%,用的是非流式的数据,防止遗忘;
- 单人整句翻译行占 15%。

**规模**:约 13 万读取行。

### 3.3 训练配置

| 项 | 设置 |
|---|---|
| 框架 | Megatron 8 卡;GBS 64,MBS 8;全量 shuffle;`setsid nohup` 运行 |
| 步数 | 约 1 遍数据(约 2,000 步,约 1.5–2 h) |
| 学习率 | LoRA 1e-4;warm-up 50,cosine |
| 损失 | 交叉熵;时间 token ×1.5,说话人 token ×2,wait 和结束标记 ×1 |
| 后验扰动 | 以 0.2 的概率加噪或平移 ±1 帧(和非流式相同) |

## 4. 流式推理

```
音频流 → Nemotron(流式配置)→ 因果切窗(1 s 无活动关窗,≤20 s;测试先用参考窗口,再用 Nemotron 窗口)
窗口内每 Δ 秒读一次:
   音频[0:t] + 后验[0:t−1.04 s](其余置零)+ 已提交前缀 → 生成
   S-T  :生成到 wait 或结束标记,生成的内容全部提交
   S-LA2:生成到结束标记,和上次续写取最长公共前缀提交
提交的片段立即送对应槽位的 Talker 流 → 单通道(换人时停 0.2 s)
```

推理引擎沿用 `gstar_si_stream.py`(HF 批量,带 KV cache),新增 `--mode stream --policy {wait,la2} --window Δ`。

## 5. 实验

| 编号 | 内容 | 目的 |
|---|---|---|
| S-LA2 | O-G1 + LA2,Δ = 1 / 2 / 3 s | 零训练的流式基线;质量和延迟曲线 |
| **S-T** | 流式训练模型,Δ = 1 s | 流式主系统 |
| S-T-oracle | S-T 用参考后验 | 分离误差的上限 |
| B-LA2 | 原版 Thinker + LA2,不接说话人,同样的窗口和 Δ | 不做多说话人的流式参照 |
| S-single | S-T 在 RealSI 英→中上 | 单人能力是否退化 |
| (语音) | S-T 和 B-LA2 按说话人合成、合并单通道 | cp-ASR-BLEU、音色、fluency |

### 判据

| 对比 | 要求 |
|---|---|
| S-T 对 S-LA2(同 Δ) | cpBLEU 不低,延迟更低 |
| S-T 对 O-G1 | 整场 cpBLEU 损失 ≤3 BLEU |
| 延迟 | 文本 LAAL ≤3 s(含 1.04 s 前瞻和 Δ) |
| S-T 对 B-LA2 | 整场 cpBLEU 显著更高 |

## 6. 指标(在非流式指标基础上增加)

| 指标 | 定义 |
|---|---|
| LAAL(文本) | 每个译文字的提交时刻,对窗口时长和参考长度计算 |
| 首字延迟 | 窗口内第一个片段的提交时刻 − 第一句的开始 |
| 语音延迟 | 首包和尾包偏移;单通道队列的积压 |
