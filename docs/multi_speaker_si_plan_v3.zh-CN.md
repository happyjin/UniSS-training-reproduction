- 日期：2026-10-26（v1、v2 原文保留不动）
- 本版要求：
  1. 以 GitHub `tagspeech/gstar-nemotron` 分支的最好模型 SCOPE 的结构为参考；

## 0. 结论先行

| 问题 | 结论 |
|---|---|
| 当前方案满足要求吗 | **不满足**。E2E-v0 是"纯端到端、不接说话人分离"的 TagSpeech 式基线。它只借鉴了 SCOPE 的输出格式、切段方式和 cp 指标，**没有用 SCOPE 的核心结构**：流式说话人分离前端、STNO 置信度、BSSC、说话人活动 token、DSS、逐说话人条件链。v0 保留，作为"不用分离器"的下界 |
| SCOPE 的结构能做成端到端吗 | **能**。SCOPE 里属于模型图内的部分（分离前端、置信度、BSSC、活动 token、DSS、条件链）都是端到端的条件化；不属于的是推理后的贝叶斯后处理（束重排、MMS 强制对齐 + HMM 归属、序贯注册），按要求不用 |
| 新的主线 | **SCOPE-SI**：同一个模型从波形直接输出"谁说的 + 中文译文 + 中文语音"。说话人分离器（Nemotron-3）作为模型内的冻结子模块，按 SCOPE 的方式条件化 Qwen3-Omni Thinker，按说话人轮流译出，Talker 按说话人的音色发声 |
| 需要做的实验 | 基线 2 个（B0 m2 原样，E0 = v0）；结构递进 4 个（E1 → E4，逐步加上 SCOPE 的部件）；诊断和上限 4 个（参考分离、去掉编码器 LoRA、音色对照、单人回归）。见第 6 节 |
| 先做哪些 | E1（序列化输出 + 分离条件）和 E4（SCOPE-SI 全结构）先训。E2、E3 是解释性消融，排在后面 |

## 1. "端到端"在本方案里的定义

**满足以下四条就算端到端：**
1. **单一模型、单一推理图**：波形进，带说话人的译文和译音出。中间没有"先转写、再翻译、再合成"这类文字接口。
2. **说话人信息在模型内部使用**：分离器是模型的一个子网络（冻结），它的后验作为特征进入编码器和 LLM，决定"听谁、译谁"，不做独立的规则决策。
3. **决策都由模型做**：要不要说、说什么、属于谁，都由网络输出。不做推理后的统计后处理，即不用贝叶斯重排、HMM 归属、序贯注册。
4. **严格流式**：每次读取只用已听到的音频，以及分离器 1.04 s 前瞻范围内的后验。

**明确排除的（SCOPE 里的非端到端部分）：**
- 束搜索 + 分离似然重排 D(h)；
- MMS 强制对齐 + HMM 逐词归属（A5 / A6b）；
- 说话人序贯注册。

**说明**：分离器冻结不影响端到端。这与"冻结的音频编码器"同理，整个模型仍然是一个可微的前向图（分离后验 → 置信度 → 编码器调制 → LLM），可训练部分联合训练。

## 2. 参照对象：SCOPE（分支当前最好模型）的结构

### 2.1 SCOPE 的数据流（论文 `paper_icml_v2` §3）

```
单通道会议音频
 ├─► Nemotron-3 流式分离(冻结):后验 P ∈ [0,1]^{T×8},80 ms/帧,前瞻 1.04 s,AOSC 缓存保持整场槽位一致
 │      ├─► 因果切窗:≤8 s,遇 1 s 无人说话关窗
 │      ├─► Platt 校准(2 个标量/数据集)→ 目标 k 的四状态置信度 STNO b_t^(k) = [静音, 独自说, 他人说, 重叠]
 │      └─► sd_proj:后验插值到音频 token → Conv5 + MLP → 2048 维活动 token
 ├─► Qwen3-ASR 音频编码器(24 层 × 1024,冻结 + LoRA r32)
 │      每层 FFN:BSSC  y = (W+ΔW)x + U_r diag(σ_r ⊙ Gᵀb_t^(k)) V_rᵀ x,G ∈ R^{4×32} 零初始化
 │      → 投影到 2048 → DSS:按活跃槽位做特征软划分,突出目标 k
 └─► LLM(28 层,冻结 + LoRA r64):输入 = prompt(前 30 词 + 先轮到的说话人的结果)
        + 音频 token(每 5 个插 1 个活动 token)+ 目标嵌入 u_k
        → 条件链:窗口内活跃槽位按活动量降序,一个说话人一轮
 (后处理,本方案不用)束重排 D(h)、MMS + HMM 归属、序贯注册
```

### 2.2 训练配方和结果

**训练配方**
- 只用真实会议:AMI-SDM train 加 NOTSOFAR train,共 134 h,无模拟重叠。
- 20k 步,batch 16 轮,4 GPU,lr 2e-5。编码器适配器和 DSS 用 5 倍 lr,门控用 50 倍 lr。
- 训练技巧:
  - 以 0.1 的概率选"弱活动且无参考"的槽位,目标为空,教模型对误开的槽位保持沉默;
  - prompt 词以 0.1 的概率丢弃;
  - 后验以 0.2 的概率扰动。

**结构递进的效果**(cpWER,AMI-SDM / NSF / IHM,未用贝叶斯部分的数字取自同一张表):

| 结构 | 效果 |
|---|---|
| SOT-LLM+ctx(单路序列化 + 分离 token) | 22.61 / 29.94 / 15.66 |
| 只做逐说话人条件链(Q0,无 BSSC) | **变差** +1.47(删除变替换,插入增加) |
| 条件链 + BSSC(S1) | 22.17 / 26.67 / 14.85(贪心),比强基线低 1.5 |
| + DSS + 跨窗上下文 + 束宽 4(S12c,SCOPE) | 20.63 / 24.79 / 13.75 |

**关键结论**:起作用的是"每人一路 + 编码器逐帧知道该听谁(BSSC)"的组合。只做每人一路反而更差。

### 2.3 哪些能直接搬、要改什么

| SCOPE 部件 | 搬到 Qwen3-Omni 同传 | 改动 |
|---|---|---|
| Nemotron-3 分离 | 原样,冻结 | 本机建一个 NeMo 环境;模型 `nvidia/Nemotron-3-Diarization` 在 HuggingFace 公开(已查) |
| STNO + Platt | 原样 | Platt 两个标量改为可训练参数 |
| BSSC | 挂在 AuT 的 32 层 × {fc1 1280→5120, fc2 5120→1280} 上 | 参数 64 × 4 × 32 = **8,192**;SVD 在初始化时对冻结权重算一次 |
| sd_proj 活动 token | 形状不变(Conv5 + MLP → 2048) | 默认**加到音频特征上**,不插入新 token,保持序列长度和 M-RoPE 位置不变;"插入式"作为消融 |
| DSS | 形状不变(2048) | 无 |
| 目标嵌入 u_k | 2048 | 加到音频特征上;同时 prompt 文本写明"目标:说话人 k" |
| 条件链 | 每次读取内,对活跃槽位按活动量降序逐个续写 | 每人有自己的已提交前缀和 wait/提交决策(沿用 m2 的 selfwait) |
| 跨窗上下文 30 词 | 最近 30 个已提交的译文字 | 无 |
| 编码器 LoRA r32 + LLM LoRA | AuT LoRA r32 + Thinker 注意力 LoRA r32(全部 48 层) | 底座用 m2 的 Thinker |
| 说话人标签 | **直接用分离槽位编号**(整场一致) | 不再需要模型自己按出现顺序编号 |
| 贝叶斯后处理 | 不用 | — |

## 3. 当前方案(v2 / E2E-v0)检查

| 要求 | v2 / E2E-v0 | 是否满足 | v3 的处理 |
|---|---|---|---|
| 端到端 | 单模型、无外部模块 | ✅ | 保持(§1 的定义) |
| 参考 SCOPE 结构 | 只借鉴输出格式、切段和 cp 指标 | ❌ | 主线改为 SCOPE-SI(§4) |

| 按人音色 | 用模型时间锚取混音片段,带他人声音 | ⚠️ | 按槽位的音色记忆,证据只取 STNO "独自说"概率高的帧 |

| 只用 IHM-mix、审查通过的数据 | 是 | ✅ | 保持 |
| 严格流式 | 是 | ✅ | 保持;分离前瞻 1.04 s 计入延迟 |
| 评测 | 段内(局部)cp 指标 | ⚠️ | 增加整场口径、参考分离上限 |

**结论**:v0 作为基线照常完成(正在训练,完成后自动测试),主线换成 SCOPE-SI。

## 4. 修改后的主线:SCOPE-SI(端到端)

### 4.1 结构

```
IHM-mix 单通道流(16 kHz)
 │
 ├─[冻结子模块] Nemotron-3 流式分离 → P ∈ [0,1]^{T×8}(80 ms,前瞻 1.04 s,整场槽位一致)
 │      ├─ 因果分段:≤20 s,1 s 无人说话就关段(SCOPE 是 ≤8 s;同传需要更长上下文,§6 中作为消融)
 │      ├─ 可训练 Platt → STNO 置信度 b_t^(k) ∈ Δ³(按目标槽位 k)
 │      └─ sd_proj:Conv5 + MLP → z_t ∈ R^2048
 │
 ├─ Qwen3-Omni AuT 编码器(32 层,冻结 + LoRA r32)
 │      每个 fc1 / fc2:+ BSSC(Gᵀ b_t^(k) 调第 1–32 个奇异值)
 │      → 投影到 2048 → e_t;e'_t = DSS(e_t; 活跃槽位, 目标 k) + W_z z_t + u_k
 │
 ├─ Thinker LLM(48 层 MoE,m2 底座 + 注意力 LoRA r32)
 │      prompt = 指令 + "目标:说话人 S_k" + 最近 30 个已提交的译文字(带槽位)
 │               + 本次读取中先轮到的说话人刚提交的内容 + S_k 自己已提交的前缀
 │      输出:S_k 本次新提交的译文 + wait 标记;或段末收尾 + 结束标记
 │
 └─ Talker(UniSS T1c,冻结):每个槽位一路,音色 = 该槽位的音色记忆(只用 b^T 高的帧)
        → 按提交顺序合并成单通道译音(换人时停 0.2 s)
```

### 4.2 每次读取的流程(时刻 t,间隔 Δ = 1 s)

1. 分离器给出到 t 为止可用的后验。没到前瞻期的最后约 1 s 用暂定值,训练时也按同样方式截断。
2. 活跃槽位:本段已有 ≥0.2 s 的活动,且上次读取以来有新活动,按活动量降序排列。
3. 对每个活跃槽位 k,依次做一次条件化前向:编码器用 b^(k) 做 BSSC,DSS 突出 k,prompt 带上前面槽位刚提交的内容。贪心续写到 wait 标记为止,读到段尾时续写到结束标记。
4. 提交的块带槽位编号,送进该槽位的 Talker 流。
5. 每场会议的产物:
   - `transcript.json`:每块的槽位、提交时刻、译文、播放时刻;
   - 单通道译音;
   - 左原声右译音的立体声;
   - fluency 包。

### 4.3 为什么这样仍然是端到端

- 分离器、BSSC、DSS、活动 token 和 LLM 是一个连续的前向图。
- 从说话人后验到译文没有任何规则或统计后处理;"属于谁"由条件链的目标槽位决定,"说不说"由模型的 wait 或结束标记决定。
- 误开的槽位靠训练中"空目标"样本学会保持沉默,而不是靠注册检验。

## 6. 实验矩阵

全部在 IHM-mix 上进行,数据审查口径相同,测试集为 AMI test(16 场标准划分)和 dev。

### A 组:基线

| 编号 | 系统 | 状态 |
|---|---|---|
| B0 | m2 原样(单人同传,不分说话人) | 排队中(v0 训练结束后自动跑) |
| E0 | v0:纯端到端,不接分离器,模型自己编号 | 训练中,第 1650 / 2700 步 |

### B 组:沿 SCOPE 的结构递进(都是端到端)

| 编号 | 结构 | 对应 SCOPE 的哪一行 | 回答的问题 |
|---|---|---|---|
| **E1** | 单路序列化输出 + 分离条件(活动 token,槽位作标签) | SOT-LLM(+ctx) | 只把分离结果喂给模型,能带来多少 |
| E2 | 逐说话人条件链,不加 BSSC、DSS | Q0 | 只拆成每人一路有没有用(SCOPE 里变差) |
| E3 | 条件链 + BSSC | S1 | 编码器逐帧知道该听谁 |
| **E4** | 条件链 + BSSC + DSS + 30 字上文 = **SCOPE-SI 全结构** | S12c(不含贝叶斯和束搜索) | 主系统 |

### C 组:诊断与上限

| 编号 | 内容 | 目的 |
|---|---|---|
| E4-oracle | E4 用参考 0/1 分离后验 | 分离误差的上限 |
| E4-noenc | E4 去掉 AuT LoRA | 编码器适配的贡献 |
| E4-voice | 按槽位音色记忆:"只用 b^T 高的帧" vs "直接用整段" | 音色是否更干净、不串 |
| E4-single | RealSI 英→中、ACL60 英→中 | 单人能力是否退化 |

### D 组:可选(视 B、C 组结果再定)

- 活动 token 用"插入式"代替"相加式";
- 分段上限 8 s(和 SCOPE 一致)vs 20 s;
- STNO_IMPROVE 的 b6d 和 spk 自注册;
- 多说话人版 ABC 自适应提交;
- Talker 会议适配。

### 判据

**E1 对 E0**:
- 整场 cpBLEU 显著提高;
- 说话人数正确率和归属准确率明显提高;
- 不分说话人的 BLEU 不降超过 0.5。

**E4 对 E1**:
- 多说话人段和重叠段的 cpBLEU 显著提高(按 SCOPE 的经验,预期次说话人提升最大);
- 单人段变化在 ±0.3 以内。

**E4-single**:与 m2 的差在 ±0.5 BLEU 以内。
