# 同传提交的 Bayes 信念追踪与后验驱动 talker：完整方案

状态：方案（2026-10-22，Prague 时间）。系统：冻结 Qwen3-Omni Thinker（vLLM）+ UniSS 流式 talker T1c@1500；评测集 RealSI 句级（en2zh 346 句，zh2en 431 句）。

## 0. 一句话

同传的"提交"是对**未来源语音**的 Bayes 决策：先验来自单次读取，似然来自后续读取中逐步累积的证据，演讲级先验在测试时在线更新，损失函数里包含 talker 的代价；同一个后验再作为前瞻输入给 talker。LocalAgreement-2（LA2）是这个框架的严格特例。

## 1. 动机：现有结果说明了什么

### 1.1 现有方法与问题

| 方法 | 做法 | 已证实的问题 |
|---|---|---|
| LA2 | 连续两次读取都同意的前缀才提交 | 没有概率，不能调节风险；开口晚（2 s）；没有记忆（只看相邻两次） |
| RALCP 投票 | 同一音频上采样 8 次，共识前缀提交 | 估计的是"同一输入下目标端的一致性"，而不是"未来音频来了是否稳定"；块末单位错误率高 6–9 个百分点 |
| CRISP 头 | 17 维单次读取特征 → MLP，学投票共识 | 学错了事件（共识而非稳定）；先早开口再把 60–70% 内容拖到句末，结束延迟比 LA2 晚 0.5–1.0 s，LAAL 看不到 |
| 融合（CRISP × 跨读取一致 ±β） | 头当"先验"，一致当"似然" | "先验"的第 13 维就是跨读取一致，等于重复计数；±β 手调、未训练；先验不更新；损失里没有 talker 代价 |

### 1.2 诊断出的三个瓶颈

1. **块边界**：同一音频上的多个样本会一致地在已听部分的末尾收尾，但这个边界换一次读取就会变。跨时间证据能修正这一点（融合把块末不一致率从 27% 降到 20–24%）。
2. **talker 处理碎片**：早开口策略从文本到语音多损失 0.8–0.9 BLEU；首片段 ≤2 单位的句子漏读率高 1.3–1.9 个百分点；APCP 从 2.78 降到 2.63–2.68。
3. **评测伪影：ASR 在时间轴静音上的幻觉**（2026-10-22 更正）：原 ASR-BLEU 转写的是按时间轴铺开、含长段静音的 `*_simul.wav`。Whisper 在静音上幻觉出重复文本（例：sport_003 的纯语音只有 2.72 s、talker 正常收尾，铺开后 22.45 s，转写成"the advantage of the 5-back"数十遍），3 句就能让 zh2en corpus BLEU 掉 3 分；静音越多的策略（早开口）受害越重。改为对纯语音 `*_speech.wav` 做 ASR 后，zh2en 种子方差从 ±1.1–1.7 降到 ±0.2–0.4。下文 5.1 的"纯语音"表为更正后的结果。

## 2. 严格的 Bayes 公式

### 2.1 隐变量

源语音 x_{1:T}；第 r 次读取已听 x_{≤t_r}，已提交前缀 c_r，冻结 Thinker 的贪心草稿 d_r。对每个暂定单位 u：

```
Z_u = 1[ d_u = y*_u ],   y* = Thinker(x_{1:T}, c_r)
P(Z_u = 1 | x_{≤t_r}) = ∫ 1[d_u = y*_u(x_{1:T})] p(x_{>t_r} | x_{≤t_r}) dx_{>t_r}
```

不确定性完全来自未来源语音。Z 是"相对冻结 Thinker 的稳定性"，不是"相对参考译文的正确性"，在 Thinker 冻结的前提下这是正确的决策目标。

### 2.2 观测与递推

单位 u 首次出现在读取 r₀，之后每次读取 s 的观测 o_s(u) = (a_s 是否仍在原位置, Δlp_s, Δrank_s, Δt_s 新听时长, e_s 新听源词数)。

链式法则（精确）：

```
P(Z | o_{r0:r}) ∝ P(Z | o_{r0}) · ∏_{s=r0+1}^{r} p(o_s | Z, o_{r0:s-1})
```

假设 A2（一阶 Markov）：p(o_s | Z, o_{r0:s−1}) ≈ p(o_s | Z, o_{s−1})。对数优势递推：

```
ℓ_{r0}(u) = g_φ(x_{r0}(u)) + b_k                                         prior
ℓ_s(u)    = ℓ_{s-1}(u) + Λ_ψ(o_s, o_{s-1})                                likelihood
Λ_ψ       = log p(o_s | Z=1, o_{s-1}) − log p(o_s | Z=0, o_{s-1})
P(Z_u = 1 | o_{r0:r}) = σ(ℓ_r(u))
```

### 2.3 Prior

- **g_φ（单句部分，离线训练）**：单次读取的特征（lp、top1−top2、熵、是否 top1、位置、相对位置、单位序号、草稿长度、已听秒数、提交速率、最小 lp、平均 lp、是否末单位、方向、标点），即原 17 维**去掉跨读取一致**那一维，保证先验与似然不重叠。
- **b_k（演讲级部分，测试时更新）**：b_k ~ N(0, σ_b²)。每句结束时，该句之前各读取的 Z 已可计算，用 Laplace 近似做一次 Newton 更新：

```
b_k ← b_k + Σ(Z − σ(ℓ + b_k)) / (1/σ_b² + Σ σ(ℓ+b_k)(1 − σ(ℓ+b_k)))
```

形式类似 EMA，步长由后验精度给出；新演讲开始时 b_k 回到 0。对应 Adaptive Conformal Inference 的在线校准，用来在 RealSI 的分布偏移下维持风险控制。

### 2.4 Likelihood

Λ_ψ 是一个小网络，输出对数似然比。用密度比方式训练：对每次读取，以递推得到的 σ(ℓ_s) 对 oracle 标签 Z 做 BCE，梯度穿过递推同时更新 g_φ 和 Λ_ψ：

```
L(φ, ψ) = Σ_items Σ_u Σ_{s≥r0} BCE( σ(ℓ_s(u)), Z_u )
```

加性递推结构下，模型校准良好时 Λ_ψ 收敛到真实对数似然比。oracle 标签：对训练集每个读取状态，用完整音频、同一已提交前缀再做一次贪心续写，看 d_u 是否保留。

### 2.5 Bayes 决策（测试时，闭式）

```
k* = argmin_k  C_err · (1 − P_k) + C_lat · W(k) + C_frag · φ(k)
P_k ≥ max(0, 1 − Σ_{j≤k} (1 − σ(ℓ(j))))          Bonferroni 下界，不需要独立性
W(k)  = 未提交单位数 × 读取间隔
φ(k)  = talker 对该片段（长度、是否在短语边界）的期望损失，从已有完整系统数据查表
```

C_lat / C_err 决定延迟档位。开口阶段（尚未提交、也无先前草稿）没有似然项，后验等于先验；φ(k) 自然惩罚短片段。

### 2.6 LA2 是特例

令 g_φ ≡ 0、b_k ≡ 0、观测只取 a_s、Λ = ±∞、C_frag = 0，则上式退化为 LA2。论文中写成命题。

### 2.7 后验驱动的 talker

理想输出是对未知后续文本的 Bayes 平均，不可计算：

```
p(s | c, x_{≤t}) = Σ_ỹ p(s | c, ỹ) P(ỹ | c, x_{≤t})
```

改为让 talker 以信念状态摘要 q = (暂定尾巴 ỹ, 各单位后验 σ(ℓ)) 为条件，训练 p_θ(s | c, q)，只为已提交部分发声。训练时 ỹ 取 Thinker 真实草稿的尾巴（含错误），因此最大似然下近似上述后验平均（摊销近似）。严格地说，这一部分是"以信念为输入的生成器"，不是 Bayes 推断本身。

### 2.8 严格与近似的边界

- 严格：隐变量定义、链式法则、对数优势递推、层级先验（Laplace 为标准近似）、Bayes 决策、LA2 特例。
- 近似：A2 一阶 Markov；P_k 用下界；Λ_ψ 仅在校准良好时等于真实似然比（需报告可靠度图 / ECE）；talker 为摊销近似。

## 3. 训练与测试的分工

| 组件 | 角色 | 离线训练 | 测试时 |
|---|---|---|---|
| g_φ | prior（单句） | 是：oracle Z，Megatron 小模型 | 前向 |
| b_k | prior（演讲级） | 否（只设 σ_b） | 每句后 Laplace 更新 |

| k* | Bayes 风险最小化 | 否（C 定档位，φ 查表） | 闭式 argmin |
| talker p_θ(s \| c, q) | 以信念为条件的生成器 | 是：Megatron，从 T1c@1500 继续 | 前向 |

### 5.2 解读（以下基于原口径，保留作对照）

- **zh2en**：去掉 talker 循环后，"融合 + 开口 0.8"在同一 LAAL（3.62 对 3.61）、同样的开口和结束延迟下比 LA2 高 **+0.8**，且种子标准差只有 0.08–0.26。这是迄今为止最有力的证据，说明 Bayes 融合在语音层面有效；之前的结论被 talker 循环掩盖了。
- **en2zh**："融合 + 开口需证据"在同一 LAAL 和结束延迟下与 LA2 持平（+0.15，不显著）；早开口的版本延迟更低但质量更低，沿 LA2 曲线插值约 +0.3，不显著。en2zh 的瓶颈是 talker 处理碎片（文本侧 +0.5 在语音里丢失）。
- **注意**：循环替换是事后近似，而且我们的策略循环更多（替换对我们更有利）。必须在阶段 0 用真实的防重复保护让所有系统重跑，才能作为结论。

### 5.3 对新方案的预期

| 组件 | 针对的损失 | 已测得的可回收空间 | 预期 |
|---|---|---|---|
| 阶段 0 防重复 | zh2en 循环 | 种子方差 ±1 → ±0.2；融合相对 LA2 显露 +0.6–0.8 | 高把握（工程修复，所有系统同等受益） |
| A 信念追踪（g_φ + Λ_ψ + b_k） | 块边界错误、重复计数、领域偏移 | 块末不一致 20–24% 对块内 15–17%；同等已听比例下与 LA2 的单位错误率已相近 | 文本侧小幅提升（估计 +0.2 到 +0.5），主要价值是公式严格、风险保证可在 RealSI 上成立、可解释 |
| φ(k) 写进损失 | 碎片导致的 talker 损失 | 早开口策略多损失 0.8–0.9 BLEU | 中等把握，可能回收一部分；代价是开口稍晚 |
| B talker 前瞻 | 碎片漏读、韵律、循环 | 同上 0.8–0.9 BLEU；APCP 差 0.1–0.15 | 收益最大也最不确定；若回收一半，en2zh 可达 LA2 +0.4 到 +0.6 |

综合预期（相对 LA2 m1，同延迟，有防重复保护）：

- **zh2en**：当前融合已约 +0.8；加上 A 与 φ，预期 **+0.8 到 +1.3**。
- **en2zh**：当前约 +0.15 到 +0.3；主要依赖 B，预期 **+0.3 到 +0.8**。B 不成功时，en2zh 大概率只能与 LA2 持平。

与目前的 Bayes 尝试（融合 ±β）相比，新方案在 zh2en 预计再增加 0–0.5，在 en2zh 的增量取决于 B。它最确定的提升不在单一数字上，而在于：结束延迟不落后于 LA2、开口更早、风险控制在 RealSI 上可验证、公式严格并把 LA2 作为特例。这些是顶会审稿最看重的部分。

### 5.4 风险与应对

| 风险 | 应对 |
|---|---|
| A2 Markov 假设不成立，Λ_ψ 校准差 | 报告 ECE；必要时把 o_{s−1} 扩展为最近两次观测 |
| oracle Z 依赖完整音频续写，与 RealSI 的真实口语分布不同 | b_k 在线更新；报告 RealSI 上实际风险与 ε 的偏差 |
| talker 把前瞻念出来 | 训练数据里加入错误尾巴和明确的"不发声"标记；评测插入率 |
| 防重复保护本身改变 baseline 数值 | 所有系统同一保护、同一种子，旧结果保留并标注 |

## 6. 建议的执行顺序

1. 阶段 0（防重复保护，所有系统重跑）——它决定 zh2en 的 +0.8 是否成立，代价最小，必须先做。
2. 阶段 1–3（信念追踪）与阶段 4 的代码同时推进；阶段 1 的 vLLM 数据生成与 talker 代码编写并行。
3. 阶段 5 完整评测，主表加入 StreamLAAL/YAAL 与结束延迟。

## 8. 实验结果（2026-10-23 更新）

### 8.1 有效的组成部分

### 8.2 无效（作为分析写入论文）

- 学习式信念追踪（oracle 未来稳定性标签，前缀 / 子序列两版）：离线 AUC 0.822、ECE 0.011，但 RealSI 上不如融合（同延迟 −0.9~−1.5）。原因：稳定 ≠ 正确，且未来稳定性随领域变化。
- 按 oracle 稳定性估计的似然比很弱（β⁺≈0.7，β⁻≈0.5），远小于经验最优 β=4，同一原因。
- 演讲级 prior 在线更新：修复自我确认标签后仅小幅正面。
- VOI 发声调度：与硬性最小片段在同一条曲线上（±0.1）。
