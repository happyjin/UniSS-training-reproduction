# v4 对第二轮审稿意见（`docs/review_of_v2.md`）的逐条回应

v4 是 v3 的完整复制（`paper/gstar_si_v4`，git 分支 `v4`），v1–v3 没有改动。按作者要求，v4 不再使用贝叶斯成分（ABC 阈值、SDR、FR）：
- 同传主系统改为非贝叶斯的截止期标签模型 **MIST-Simul**（v2 的做法），每个方向一个；
- 自标注的稳定前缀标签只作为附录里的读目标消融，不作为卖点；
- 正文突出框架设计：持久的说话人流、说话人在前的时间戳输出、模型内部的提交策略、来自分离器的音色。

表格和正文数字都由脚本从评测输出生成：
- `scripts/make_tables.py`、`scripts/bootstrap.py`、`scripts/analyze.py`；
- 系统清单在 `scripts/systems.py`。

## 诚实说明：哪些不如基线

- **AliMeeting 离线：** MIST 与同数据级联持平，没有赢。多说话人窗口上 MIST 更好（13.56 对 12.14），单说话人窗口上级联更好（18.11 对 16.54）。论文 §5.3 如实写明。
- **中译英 DER：** MIST 16.0%，级联 15.5%，几乎相同（英译中 MIST 明显更低）。
- **中译英同传：** MIST-Simul 与 LA2 持平（24.78 对 24.81），延迟还多 0.35 s，比离线 MIST 低 1.08（p<0.01）。论文如实写为“英译中明显胜出，中译英持平”。
- **中译英训练步数：** MIST-Simul 只训练了 1,000 步（英译中 3,000 步）。3,000 步的训练要到截止之后才能结束，已按 PID 停掉，局限性写明。
