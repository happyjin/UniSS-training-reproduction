## 0. 通用规则（沿用 prereg_v6 §0，以下为变化处）

- AMI test（16 场：EN2002a–d、ES2004a–d、IS1009a–d、TS3003a–d）、AliMeeting test（20 场：R8002_M8002、R8002_M8003、R8004_M8005、R8004_M8006、R8005_M8007、R8005_M8008、R8005_M8009、R8006_M8012、R8008_M8014、R8008_M8015、R8008_M8016、R8008_M8017、R8009_M8021、R8009_M8022、R8009_M8023、R8009_M8024、R8009_M8025、R8009_M8026、R8009_M8027、R8009_M8028）只做测试，不训练、不调参。新取值只在 AMI validation（dev）上定。
- 统计（每个比较报告四项）：效应量；按会议的簇 bootstrap 95% 区间（1,000 次，每次在重采样的会议上重新做说话人匹配）；按会议差值符号翻转的双侧置换检验 p（16 场与 20 场都精确枚举 2^16 / 2^20 种）；确认性检验另报 Holm 校正后的 p。p < 0.001 写作 p<0.001。另报 leave-one-meeting-out 的最小/最大差值与最敏感的会议，以及每场会议差值的点图。
- **解码噪声**：同一系统两次解码之差的标准差 σ_dec(n) ≈ 12.3/√n（n 为窗口数；由 v6 的 T13 估计：96 窗差 0.46，按窗口数换算）。§1 的 N-check 用更大的样本重新估计；两者取较大者。每个比较另给「加噪声区间」：簇 bootstrap 方差 + σ_dec(n)²。
- **判定**：只有当 Holm 校正后 p < 0.05（确认性）或置换 p < 0.05（探索性），**且**加噪声区间不含 0 时，才写「更好/更差」；否则写「在解码噪声与会议抽样范围内持平」。
- **确认性检验族**（合并 Holm 校正，共 8 项）：§1 的 E-on1、E-on2、E-on3；§2 的 E-cas1、E-cas2、E-cas3；§4 的 E-seed-en、E-seed-zh。其余都是探索性分析，文中标明。
- 计算资源：同事的作业每卡约占 50–55 GB；我方每卡不超过 120 GB（硬上限 126 GB，由看门狗按 PID 只停我方解码/语音进程）。Thinker 分到两张卡（每卡约 35–45 GB）解码。

## 2. 级联基线（第 0、0b 项；M04、Q3）
