# 第三轮审稿：v4（严格审稿人视角，ACL/EMNLP 标准）

审稿对象：`paper/gstar_si_v4/main.pdf`（git 分支 `v4`，a3ead1b），并参考了换服务器后补跑的新实验结果（见文末附录）。审稿人与前两轮相同，按主会标准从严评价。

## 总体判断

论文提出 MIST：把一个全模态语音 LLM 改造成"带说话人归属的会议同传"。框架有四个设计：持久的说话人流、说话人在前的时间戳输出、在解码器内部学到的提交策略、用分离器的独白片段生成音色。

- **离线部分站得住。** 两个方向都显著优于同数据级联，消融也清楚地说明了说话人流的作用。
- **同传部分的结论只在英译中成立。**
  - 中译英补训到 3,000 步后，MIST-Simul 仍然只和 LA2 持平（24.30 对 24.81），延迟还更高。
  - 真实会议 AliMeeting 上，离线不比级联好；同传只在更高延迟下高出 LA2。
- **结论：** 论文目前能可靠支撑的是"联合建模 + 说话人流优于级联"；"模型内提交策略优于 LocalAgreement"只在一个方向成立，正文需要相应收窄表述。

## 主要问题

**M1. 同传的核心主张在中译英上不成立，论文没有解释原因。**
- 英译中：MIST-Simul 比 LA2 高 11.0 分（p<0.001）。
- 中译英：1k 和 3k 两个模型都与 LA2 持平或略低，LAAL 还高 0.35–0.43 s。
- 两个方向差距这么大，需要分析：
  - LA2 在英译中为什么会退化成重复（输出长度是参考的多少倍），在中译英为什么不会？
  - 中译英的截止期标签是在重配音语音上按时长比例估计的，这会不会让标签本身不准？
  - 这是方法的限制，还是数据构造的限制？至少要给出时长估计误差的分析，或者一个上界实验（例如 oracle 时间戳）。

**M2. 同传比较的延迟不一致，缺少完整的质量–延迟曲线。**
- 中译英 MIST-Simul 的 LAAL 是 2.85–2.93 s，LA2 是 2.50 s，"持平"的说法偏乐观：同等延迟下 MIST 可能更差。
- 应该给两个方向在多个读入间隔下的质量–延迟曲线（Δ=0.5/1/2 s，MIST-Simul、MIST-Simul-M 和 LA2 都画上），按曲线比较，而不是只比单点。

**M3. 基线的强度与公平性。**
- LA2 用在离线模型上；离线模型从没见过不完整的窗口，所以 LA2 在英译中退化。这让英译中 +11 分的一部分来自"基线不适配"，而不完全来自学到的提交策略。建议加一个更强的同传基线，例如：
  - wait-k / 固定延迟策略；
  - 在前缀数据上微调过的 LA2 基线。
  至少要在文中承认这一点。
- 提示式基线不输出时间戳，DER 因此接近 100%，是"按构造必输"的基线，不应作为主要对比对象。
- 没有和已发表的同传系统比较（例如 StreamSpeech、Seamless Streaming）。虽然它们不做说话人归属，但可以比较 BLEU$_\text{blind}$。

**M4. 参考译文与训练目标同源。**
- 英译中的参考和训练目标都来自同一套机器翻译流水线。经过微调的系统（MIST、C-ft2）会因此占优，绝对分数不可比。论文已承认，但英译中的大幅优势需要更谨慎地表述。
- 中译英用的是人工参考，这一点很好，可以作为主要证据，应该在摘要和引言中强调。

**M5. 真实会议的泛化证据偏弱。**
- AliMeeting 离线 14.90 对级联 15.25，不显著，级联在单说话人窗口上还更好。
- 同传 12.97 对 LA2 12.10，但延迟高 0.25 s。
- 论文对"真实会议"部分的结论应该保持谨慎。建议分析错误来源：说话人分离错误、ASR 难度，还是翻译领域差异。

**M6. 没有训练方差。**
- 每个模型只训练了一次。中译英 1k 和 3k 两个模型相差 0.5 分，说明单次训练的波动和一些"显著"差异是同一个量级。
- bootstrap 只反映测试集抽样误差，不反映训练随机性。至少应在局限性里写明；关键模型最好有 2–3 个种子。

**M7. 读入间隔的鲁棒性。**
- Δ=0.5 s 在英译中失效（23.31 cpBLEU），中译英也出现失控生成（输出不断变长）。
- 混合间隔训练（MIST-Simul-M）是审稿人第二轮的主要建议，必须给出结果；如果没有改善，也要如实报告。

## 次要问题

1. 说话人分离器自切窗口的评测原来只用了 v2 的英译中模型；应该换成 v4 的模型，并说明这些窗口只包含完整话语。
2. LAAL 不计算耗时，听众端延迟也只在窗口内测量；建议至少报告实时率。
3. 语音只有自动评测（ASR、WavLM、UTMOS），没有 MOS；而 WavLM 余弦相似度在不同说话人之间也有约 0.75，"音色混淆"指标的区分度有限。
4. 中译英的源语音是重配音，不是真实中文会议语音，这个方向的语音条件偏理想。
5. 表格里的粗体和 † 标记，要和 bootstrap 的比较一一对应；中译英同传不应该加粗。
6. 摘要里"attribution survives synthesis"只有英译中语音支撑；中译英语音结果补全后再下结论。

## 统计严谨性

- 优点：配对 bootstrap 同时按窗口和按会议做（16 场会议），单侧 p 值，给出了置信区间。
- 不足：
  - 多重比较没有校正：主要比较约有 20 对；
  - 没有训练种子方差；
  - 按会议的 bootstrap 只有 16 个簇，功效有限，文中应说明。
